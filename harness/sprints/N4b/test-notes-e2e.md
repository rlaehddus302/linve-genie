# N4b test-notes (e2e)

라운드 0 — `tests/e2e/n4b/` (support · flow · screens · attacks · probes). 실행: `E2E_PORT_OFFSET=1700 pnpm e2e`.

## 실패로 남긴 것
- TE-N4b-001 (flow.spec.ts): 기본 묶음(Vite 미리 보기 + E2E 서버)에서 링크 `<화면 주소>/r/<토큰>`이 E2E 서버로 가지 않는다.
  `apps/web/e2e/serve.ts`가 미리 보기 프록시에 `/api`만 E2E 서버로 넘기고, `vite.config.ts`의 `'^/r(/|$)'`는 설정 파일의
  `LIVEJJIM_API_URL` 기본값(http://localhost:3000)을 그대로 쓴다. 이 기계에서는 3000번의 다른 서비스가 404를 준다.
  같은 흐름은 서버가 화면을 내는 묶음(@served)에서 통과한다.
- TE-N4b-002 (attacks.spec.ts): 영수증 보내기 화면을 연 뒤 다른 기기에서 가게 이름을 바꾸면 줄은 다시 받지만
  복사·공유 글의 가게 이름은 `/api/me`를 처음 받은 값 그대로다(구매자 문서는 새 이름).
