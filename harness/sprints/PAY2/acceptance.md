# PAY2 수용 기준 — 결제는 웹에서만, 앱 심사 대비, 결제 대기 자동 재확인, 포트원 현금영수증, 공개 요금 안내

- 스프린트: PAY2 · spec ID: **BIL-03**(새), 연결: BIL-01·BIL-02·SYS-01·SYS-05·APP-01·§7 화면 12·17·18 · 근거 결정: **D-PAY-01~D-PAY-12**(AUTO 2026-10-31)
- 규칙: `docs/spec/BILLING_RULES.md` v0.1.3 — BL-6 9(자동 재확인)·BL-6 10(시간 한도·멱등 키)·BL-7 2·5 한 줄·BL-8 5(포트원 현금영수증)·BL-11(휴대폰 앱에서)·BL-12(공개 요금 안내)·BL-INV-1 한 줄·BL-INV-9. 화면: SPEC §7 화면 18.
- 개발 영역: **server**(`apps/server/**` — 자동 재확인, 포트원 요청 시간 한도·멱등 키, 포트원 현금영수증 어댑터, 공개 요금 입구, 운영자 목록 기준), **web**(`apps/web/**` — 앱에서 연 탭 숨김, `/pricing` 화면, 소개·로그인 화면 링크 / `apps/mobile/**` — `NO_PASS` 앱 문장, `from=app`, 앱 정적 검사. SRV1과 같이 앱은 web 영역) · 테스트: **domain**(`tests/adversarial/pay2/**`), **e2e**(`tests/e2e/pay2/**`) · **core 없음**. 순서 **server → web**(화면이 공개 요금 입구를 쓴다).
- 골든: 없음. 판정·정산·파서 규칙과 요금 골든(`tests/golden/billing/*.json`, 82사례)은 바뀌지 않는다. 자동 재확인 일정·현금영수증 판단은 아래 사례대로 서버 단위 시험으로 본다.
- 낱말: **앱** = 휴대폰 앱(`apps/mobile`, APP-01). **앱에서 연 탭** = `from=app`이 붙은 주소로 열린 브라우저 탭(BL-11 3). **칸** = 자동 재확인 시각(주문 만든 시각 + 1분·5분·30분·3시간·24시간). **공개 요금 입구** = 로그인 없이 부르는 서버 입구(BL-12 1 — 경로 이름은 dev 몫, `dev-notes.md`에 적음).
- 포트원 V2 현금영수증 API(결제 건 현금영수증 조회·현금영수증 발급·취소)와 `Idempotency-Key` 머리말의 실제 경로·필드는 포트원 V2 문서대로 쓰고, 가짜 포트원 서버(`apps/server/src/billing/fake.ts`)에 같은 모양으로 더한다. 쓴 경로·필드는 `dev-notes.md`에 적는다. 실제 포트원·토스·스토어로 나가는 연결은 없다.
- 시간이 드는 시험(60초 한도, 24시간 칸)은 주입한 시계·타이머로 흉내 내도 된다. 실제로 1분을 기다리지 않는다.
