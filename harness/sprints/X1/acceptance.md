# X1 수용 기준 — 크롬 확장으로 유튜브 라이브 채팅 읽기 + 감사 채팅 올리기(선택) (보조 경로)

- 스프린트: X1 · spec ID: **YT-10**(새), 연결: YT-02·YT-03·YT-04·YT-06·YT-09·ORD-08·SYS-04·NFR · 근거 결정: **D-X1-01~D-X1-28**(AUTO, D-X1-17이 D-X1-01을 바꿈 — 사용자 새 요구 2026-10-23) · 사람 확인: **HG-X1**
- 개발 영역(제안 — backlog.yaml에 X1 항목이 아직 없음): **device**(`apps/extension/**` 크롬 확장 MV3), **server**(`apps/server/**`), **web**(`apps/web/**`) · 테스트: **domain**, **e2e** · **core 없음** — 판정·정산 규칙·엔진은 바꾸지 않는다.
- 새 폴더 `apps/extension`이 보호 경로 게이트의 접두어 규칙에 없으면 `scripts/harness`를 고치지 말고 보고한다.
- 골든 변경 없음: 확장 채팅은 기존 '채팅' 이벤트로 들어가 기존 파서·엔진 골든을 그대로 탄다. 중복 판단(D-X1-06)은 수집 경로 규칙이라 server 단위 시험과 E2E로 고정한다.
- 자동 시험은 유튜브 채팅 DOM 모양을 본뜬 가짜 페이지로(D-X1-15). 실제 유튜브는 HG-X1.
