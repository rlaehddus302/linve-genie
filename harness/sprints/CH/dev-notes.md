# CH dev-notes (채팅 보관·틱톡)

## CH-20 · 틱톡 서명 요청 수 경보
- AUTO: 연결 시도 1번 = 서명 요청 1번으로 보수적으로 센다(지난 24시간). 실제 무료 한도를 확인하지 못해 기본 500, `LIVEJJIM_TIKTOK_SIGN_DAILY_LIMIT`로 바꾼다.
- AUTO: 한도를 넘어도 연결을 막지 않는다 — 막으면 방송 중 댓글 수집이 끊겨 판매자에게 더 위험하다. 대신 운영 로그(수만)와 판매자 화면 문장(`collection.signNotice`)으로 알린다.
- 80%에 닿으면 NEAR, 넘으면 OVER. 로그는 수준이 바뀔 때 한 번만, 수만 남긴다.
- 웹: 틱톡 칸 경고 줄에 `signNotice`를 보인다(없으면 안 보임). 기존 시험의 연결 보기 기대값에 `signNotice: null`만 더했다(약화 아님).
