# APP1 통합 보고

2026-10-30 · 상태: 자동 구현·통합 검증 범위 완료. HG-APP1과 실방송 지연·정확도는 미확인.

## 결과

기존 APP1·APP1b·APP2 구현을 `codex/livegenie-resume-20261029`에 통합했다. 인증된 기기 WebSocket, 판매자 한 흐름, 일꾼 인증·한도·끊김, 실제 PCM 캡처와 Python 받아쓰기 실행을 연결했다. 기본 Cohere와 기존 대안 Whisper를 각각 실제로 실행하고 상품 등록까지 확인했다. 사용자 실행 도우미의 기본값도 Cohere다.

사용자는 기존 받아쓰기 서버가 없다고 답했다. 이 맥에 격리한 Python 3.12와 고정 requirements, Cohere Transcribe·Whisper large-v3-turbo·silero VAD를 설치했다. Whisper 캐시 우선 로딩의 Transformers 5 호환 오류와 Cohere 필수 전처리 의존성 `librosa` 누락을 수정했다. Cohere는 사용자가 로그인한 브라우저의 모델 접근 승인을 확인하고 공개 승인 모델 읽기 권한만 사용해 내려받았다. 토큰은 파일로 저장하지 않았다. 원격 운영 배포 또는 기존 맥 미니에 설치한 것으로 보고하지 않는다.

## 실제 연결 증거

합성 한국어 `15번 핑크프릴 이만 원` → 16kHz mono PCM16 51틀(각3,200바이트) → 실제 일꾼 → Node WebSocket 중계 → 기존 읽기 → 기존 HTTP 등록 → PGlite에 **15번·핑크프릴·20,000원 1건**을 두 모델 각각 확인했다.

| 모델 | 결과 글 | 단일 조각 처리 | 전체 입력/등록 확인 |
|---|---|---|---|
| 기본 Cohere Transcribe | `15번 핑크 프릴 2만 원.` | 409ms | 5,165ms |
| 대안 Whisper large-v3-turbo | `15번 핑크프릴 2만원` | 707ms | 5,213ms |

각각 한 표본이다. 다수 표본 p95·실제 판매자 음성 정확도·모델 성능 우열을 판단하지 않는다. 전체 시간에는 실시간 음성 전송이 포함된다. 고객 자료·사용자 마이크를 쓰지 않았고 두 검증의 서버·일꾼은 종료했다.

## 로컬 브라우저 확인

동일 출처 `localhost:9790`에서 로그인 → 리허설 생성 → 15번 핑크프릴 20,000원 등록 → 합성 시청자 채팅으로 1등 판정 → 새로고침 후 보존 → 종료 후 음성/빠른입력 제거 → 영수증 합계(기본 배송비 포함24,000원)를 직접 확인했다. 브라우저 warning/error0. 별도로 사용자 실행용 Cohere 일꾼과 서버를 열어 두었으며, 실제 마이크/유튜브/B1을 검증한 것으로 보지 않는다.

추가 실제 브라우저 관통 검증에서 Blob AudioWorklet 로딩의 AbortError(PCM0)를 발견했다(TE-APP1-013). PCM 계산을 보존한 동일 출처 JS 자산으로 바꾸고, 엄격한 CSP와 켜기 전 지연 로딩을 유지했다. 기존 보안 포함 @served6/6·일반 PCM/지연 로딩3/3·단위/빌드19/19 통과. 최초 AbortError가 CSP 때문에 발생했다고 단정하지 않는다.

최신 서버로 재시작한 뒤 **실제 브라우저→실제 Cohere→서버 등록→DB 확인**까지 통과했다. 375px Chromium의 합성 WAV 장치1회 → native48kHz AudioContext → 제품 Worklet → PCM45틀(크기 오류0) → Cohere `15번 핑크프릴 2만 원.` → 등록POST1/HTTP200 → DB15번·핑크프릴·20,000원1건. 끄기 뒤 트랙 ended/소켓 closed, CSP 위반0. 총5,600ms는 합성 음성 재생을 포함한 단일 실행 시간이다. 실제 사용자 마이크와 모의 인식 결과 주입은 사용하지 않았다. 최신 사용자용 서버와 Cohere 일꾼은 계속 실행 중이다.

후속 대조에서 마이크 처리 옵션을 강제하던 두 값을 제거해 D-APP1-10의 브라우저 기본값을 복원했다. 실행 중인 서버·DB를 유지하고 최신 웹 자산만 반영한 뒤 실제 Cohere를 재검증했다. 요청 인자 `{audio:{channelCount:1},video:false}` 그대로, PCM106틀·등록POST1/HTTP200·DB1건·끄기 후 종료·CSP0을 확인했다. 전체11,919ms는 합성 재생을 포함한 단일 실행이며 성능 백분위나 정확도 평가가 아니다. 기존 연습 자료와 충돌하지 않도록 10월31일 별도 리허설을 사용했다.

최종 실행 도중 긴 자막 시험의 모의 말끝이 서버 읽기보다1ms 미래여서 기존 안전 경로로 처리되는 시각 오류를 확인했다. 정상 시험 결과에 실제 VAD400ms 쉼을 반영하고 늦음 시험·제품 방어·원래 단언을 보존했다. 같은 시험10회와 관련 Safari·PCM·보안16개가 통과했으며 전체 게이트는 다시 실행한다.

기존 품종 덮어쓰기 수정(`bab85239`)까지 반영한 Node 서버와 Cohere를 다시 시작해 실제 브라우저 관통을 재확인했다. 최신 실행은 기본 마이크 인자 그대로 PCM45틀·등록POST1/HTTP200·DB1건·종료/CSP0, 전체5,805ms다. 앞선 일꾼 상태에서는 두 합성 조각 처리284ms/6,506ms도 관측했다. 느린 표본을 증거에서 제외하지 않으며 원인은 미확정이다. 이 소수 표본으로 실방송 지연1.5초 목표나 다수 표본p95 통과를 선언하지 않는다.
