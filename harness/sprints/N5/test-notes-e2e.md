## 상태를 쌓는 순서
요금 E2E 서버는 실행마다 빈 메모리 DB이고 시험 계정이 하나라, `billing.spec.ts` → `round0-attacks.spec.ts`(파일 이름 순) 선언 순서대로 상태를 쌓는다.
각 시험은 시작할 때 `GET /api/billing`으로 전제(이용권 없음·사업자 정보 없음·방송 일권 0 등)를 단언한다 — 앞 시험이 실패하면 뒤 시험은 전제 단언에서 바로 실패하고 원인을 숨기지 않는다.
- 이용권 없음이 필요한 시험(처음 판매자·주문 건권 방송)이 먼저, 열린 방송 일 창이 생기는 방송 일권 시험이 그다음, 모든 것을 앞서는 정액제는 마지막.
- 기대 문장·숫자는 BL-9 문장과 시험이 넣은 값(산 양, 시험용 부여의 `at`, 방송 일 쓴 시각 + 24시간)으로 계산한다.
- `round0-attacks.spec.ts`의 라벨 장 시험은 주문 건권 방송의 자동 출력 대기 4장(출력 기기 없음)을 출력 기기로 내보내 센다. 라벨 화면을 떠나면 시험용 프린터 연결이 끊기므로 정액 방송은 API로 만든다. 끝에 `cleanupPrint`.
