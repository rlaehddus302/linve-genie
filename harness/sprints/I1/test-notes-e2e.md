## 시험 방법 메모
- 출력 기기 탭은 `page.goto`·`reload`를 하면 프린터를 잃는다. 방송을 먼저 열고(`goto`) → 메뉴로 라벨 → 출력 기기 → `page.goBack()`. 다른 화면을 `goto`해야 하면 출력 기기를 다른 컨텍스트(스테이션)로 둔다.
- 다른 기기가 출력 기기인 걸 화면이 이미 알면 "이 기기에서 출력"은 서버에 묻지 않고 바로 바꾸기 창을 연다(첫 POST가 없다).
- 출력 이력 영역은 날짜 선택 칸이 있고 기본은 맨 마지막 날짜다(시험 날짜는 과거 무작위라 고른다).
- B 라벨 키에 출력함 작업이 셋(자동·다시 출력·다시 출력)인 채 그 1등이 끝나면 버릴 라벨은 3장이다(AC-I1-05 "출력함 작업 → 폐기 — 버려 주세요" 작업마다) — 시험은 3으로 본다.

## 일부러 실패하는 시험 (지적)
- TE-I1-001 `races.spec.ts` 느린 망에서 라벨 상태 조회(`/api/print/labels`) 응답이 늦게 오면, 그사이 받은 print 알림(출력함)을 옛 응답이 덮어 보드가 "출력 중"에 멈춘다(다음 범위 기록 전까지).
- TE-I1-002 `races.spec.ts` 받기(`/api/print/claim`) 응답이 오는 길에 끊기면(서버는 출력 중 기록) 같은 기기의 다시 받기가 늘 BUSY → 그 장도 뒤 장도 찍지 않는다. 다시 연결·그만하기로도 풀리지 않는다(출력 기기 바꾸기만 됨).
