# V2 dev-notes

## dev-device (packages/voice)

스펙이 비어 있거나 겹치는 곳에서 고른 것 (판매자에게 안전한 쪽):

1. **`라울`의 별칭 `라운`은 넣지 않았다.** D-V2-02 예시는 "`라울`: `라운`"을 별칭 예로 들지만, 사례 S8은 "별칭·배운 별칭에 `라운` 없음 → `LOW`"를 요구한다. 사례 표(시험이 그대로 옮김)를 따랐다. 스펙 쪽 정리 필요(spec-keeper).
2. **정정 덩어리의 신뢰도는 늘 `LOW`.** 스펙에 없음. 정정·칸 이름이 든 덩어리로 만든 카드는 자동 확정하지 않는다(판매자가 한 번 보게). 정정 없는 덩어리는 R-17 그대로.
3. **D-V2-06 (1) "덮은 결과에 번호가 있으면 새 카드"는 첫 조각(표시 앞)에 번호가 있을 때로 읽었다.** 그래야 AC-V2-27 "등록 뒤 `아니 16번` → 번호는 상품 목록에서 고쳐 주세요"와 맞는다. 번호가 표시 뒤에만 있으면 (2)·(3): 열린 카드면 번호를 고치고, 등록 상품이면 "번호는 상품 목록에서 고쳐 주세요". 고칠 대상이 없고 번호가 들렸으면 버리지 않고 새 카드로 만든다(판매자 말을 버리지 않음).
4. **후보 동점 "사전 순"은 이름 글자 순(코드 포인트)으로 했다.**
5. **취소 낱말도 조각을 나누는 자리다**(`21번 핑크문 만원 취소` → 마지막 취소 뒤 조각에 칸이 없으면 취소). 칸 이름(`품종은` 등)도 조각을 나눈다.
6. **`voice.quietMs`는 `VoiceSettings`(자동 확정 설정) 모양에 넣지 않고 `resolveQuietMs`로 따로 읽는다** — 지금 설정 모양을 쓰는 곳·시험을 바꾸지 않게. `checkVoiceSettings`는 이 키도 검사한다.
7. 별칭은 공백 뺀 모양이 같을 때만 맞춘다(비슷한 모양 찾기·후보는 이름만).
8. 루트 `tsconfig.base.json`에 `resolveJsonModule: true`를 더했다(데이터 파일 `import … with { type: 'json' }`).

## dev-web (apps/web)

스펙이 비어 있거나 겹치는 곳에서 고른 것 (판매자에게 안전한 쪽):

1. **조용한 시간은 자동 확정 설정과 같은 저장값**(`livejjim.voiceSettings`의 `voice.quietMs`)에 둔다 — D-V2-09 "음성 설정과 같은 곳". 기본값(1800)이면 키를 쓰지 않아 지금 저장 모양이 그대로다. 읽기는 `resolveQuietMs`(범위 밖 → 1800).
2. **배운 품종 이름 저장 키는 `livejjim.voiceLearnedAliases`**(`[{heard,name,usedAt}]`). 다 지우면 키를 지운다.
3. **배우는 때**: 후보 단추를 누를 때, 그리고 음성 카드를 등록할 때(등록·Enter·자동·고치기 칸) 그 카드 품종 창 글이 등록 품종과 다르면(S8 "라울로 두고 등록"). 판단은 `canLearnAlias`·`learnAlias`.
4. **기다림이 이미 끝난 카드는 말이 들려도 멈추지 않는다**(타이머가 늦었을 뿐 — 곧 등록된다). 그 밖의 열린 카드는 말이 들리는 동안 `pauseAutoConfirm`, 덩어리 처리 뒤 `resumeAutoConfirm`. 멈춘 동안 카드에 남은 초와 "말하는 동안은 기다려요".
5. **고칠까요 카드의 [고치기]**: 손 고치기와 같은 `product.update`. 찜(1등·대기)이 있는 상품의 가격을 바꾸면 손 고치기 창(PRD-01 — 적용 범위를 묻는 안내)을 열고 고칠까요 카드는 닫는다. [되돌리기]는 앞 값으로 같은 `product.update`, 10초.
6. **"되돌릴까요?"에 [그대로 두기]도 둔다**(누르지 않고 닫을 길). [되돌리기]는 지금의 등록 되돌리기(`queue.undo`) — 그새 5초가 지났으면 "되돌릴 시간이 지났어요…"로 바꾼다.
7. **이력을 기다리는 동안(D-I4-06, 2초)은 문장 대신 끝난 덩어리를 미룬다**(그때의 설정·번호 범위와 함께).
8. 지금의 "들리는 말: …" 한 줄과 "들린 말 기록"은 그대로 두었다(기존 E2E). 큰 "들은 말" 칸은 그 위에 따로.
9. 기존 단위 시험(`apps/web/test/voice-controller.test.ts`·`console-voice.test.tsx`)은 AC-V2-32대로 최종 결과 뒤 조용한 시간만큼 시계만 넘기도록 고쳤다(기대 글 그대로). 이력 기다림 시험 셋은 2초 안에 말한 흐름을 지키려고 넘기는 자리만 옮겼다.
