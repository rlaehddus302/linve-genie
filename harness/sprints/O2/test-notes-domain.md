## 공격하고 통과한 것 (회귀로 남김)
- 번호 방송에 빈 `options: []`·`aliases: []`·`stocks: {}`·`qty: 1`·빈 고른 옵션·찜 조치의 `options`·새 이벤트 셋 → 400 "번호로만 받기" 문장, 로그·상태 그대로. 설정이 옵션이어도 `saleMode=NUMBERS` 방송은 번호 방송.
- `saleMode` 공백·대소문자·다른 열거값·숫자·객체(실제·리허설) → 400, 방송 없음.
- 설정: 옵션 방식이 저장된 뒤 겨루기만 실제 시각순 → 400, 설정 그대로.
- 판매자 경계: 다른 판매자 방송의 바로잡기·지우기·지금 상품 404, 같은 메시지 ID를 남의 방송에서 바로잡아도 원래 항목 그대로. 같은 판매자의 다른 옵션 방송을 적은 바로잡기·지우기는 no-op.
- 보조자 `/api/reviews?rehearsal=false`·방송 지정 → 403.
- 같은 요청 ID 15개 동시 → 1건 기록·같은 응답. 다른 요청 ID 15개로 같은 항목 동시 바로잡기 → 찜 1개.
- 지운 항목·없는 항목의 바로잡기·지우기 → 기록되고 changed=false, 상태 같음.
- HTML 닉네임·댓글 → 확인 필요 조회에 JSON 글자 그대로.
