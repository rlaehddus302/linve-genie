  - 1,000개 경계: 기준선 0 + 새 1,000개 → 빠른 읽기 한 번(50쪽)에 1,000개 차례대로, `BAND_FAST_UNREACHED` 없음. 기준선 5 + 새 1,000개(빠른 읽기는 본 댓글 쪽 직전에 1,000개를 넘음) → 같은 차례 전체 읽기 + 빠른 읽기 한 번 더로 1,000개 모두 차례대로, STUCK 0.
