# V3 실제 방송 받아쓰기 (2026-10-25, 유튜브 다육 라이브를 크롬 Web Speech ko-KR로 들은 최종 결과 그대로)
# 줄 하나 = 덩어리 하나(조용한 시간 1.8초로 모은 글). 고치지 않고 그대로 둔다 — 수용 기준 R1~R30·골든 voice-extract V3 사례가 이 글을 쓴다.
# 오른쪽 "→"는 V3 규칙(D-V3-01~)으로 기대하는 결과다. 판매자가 실제로 말했을 것으로 보이는 답과 다를 수 있는 줄은 (확인)으로 적었다.

1. 네 108번 bts 어 요한이 10만 원까지 안토 일단 색감 안쪽 봐주세요
   → 108번 · bts(품종 확인 필요) · 100,000원 바로 등록 ("10만 원까지"의 '원'이 들린 순간)
2. 자 bts는 자 bts 요거 그대로 보냅니다 요 아이 자 10만 원 108번
   → 1 뒤면 이미 등록됨(카드 없음, 기록만). 1이 없으면 108번 · bts · 100,000원 바로 등록('108번'이 들린 순간)
3. 자 180번 상관 세금 자 요 아이 자 유아이 35만 원까지 네 요 아이는 35만 원까지 그대로 봅니다 색금 이렇게 잘 들었어요 자 3강색급 요 아이는 30 5만 원
   → 180번 · 삼광색금 · 350,000원 ("30 5만 원"은 삼십오만 원 = 350,000원, 나누지 않는다)
4. 자 파이텐트까지 나오는 상강색 게임 잘 들었어요 자 상강 색금 자 요 아이 자 28만 원 174번 자 174 자 이거 28만 원 자 3강색은 요 아이 28마리까지
   → 174번 · 삼광색금 · 280,000원 ('174번'이 들린 순간, 뒤의 '174'는 '번'이 없어 번호 아님)
5. 자 9cm에 자 9cm에 3번 자 3강 세금 뿌리 다 남았고요 얘는 자 25만 원 170 자 요런 색금 예쁘게 나왔습니다 이거 25만 원 3강 세금 170 자 이 703강 세금이 자 25만 원까지
   → 3번 · 삼광색금 · 250,000원 (확인: 사용자 규칙 "'번' 없는 수는 번호 아님"대로면 번호는 '3번' 하나. 판매자가 뜻한 번호는 170번일 수 있다 — 되돌리기로 고친다. D-V3-20)
6. 어 자 요거 지금 189번인데 뿌리가 있습니다 뿌리 있는데 컵이 너무 잘 들었어요 빅뱅 금 139번 얘 50만 원 들어요
   → 등록하지 않음. 카드 "번호 없음 · 빅뱅금 · 500,000원"과 "번호 확인 필요 · 들린 번호: 189·139" (서로 다른 'N번' 둘 — D-V3-05)
