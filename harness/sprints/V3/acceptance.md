## 실제 방송 사례 표 (단위·적대·E2E가 그대로 쓴다)

공통: 사전 = **실제 데이터 사전**(V3 별칭 포함) + 판매 이력 없음. `claim.maxNumber` 999. 설정 "번호와 가격이 들리면 바로 등록" 켬. **중간 결과 꼴**: 문장을 공백으로 나눈 토큰 `t1 … tn`에 대해 결과 k(1 ≤ k < n)는 `t1 … tk` 중간 결과, 결과 n은 전체 최종 결과(가짜 인식이 차례로 낸다, 결과 사이 200ms). "등록 때" = 처음 확정되는 결과 번호 k. 상품 등록은 `{ no, name, price }`.

**실방송 보강 뒤 읽는 법 (2026-10-27)**: (1) D-V3-86 — 실제 데이터 사전에 영수증 품종 `BTS`가 들어가 `bts`는 사전 이름 BTS로 맞는다(R1·R3의 품종은 BTS). 사전 밖 낱말의 추측·"이미 등록됨"을 보이던 사례(R16·R17)는 사전 밖 낱말 `ufo`로 바꿨다. (2) D-V3-83 — 이미 있는 상품의 **가격**을 바로 고치는 사례(R13·R14·R45·R47·R93·R98, AC-V3-30·31·67의 화면 예)는 같은 새 가격을 다른 조각에서 두 번 들었거나 정정 낱말이 있을 때의 기대다. 한 번만 들으면 묻기 카드(고침 후보)이고 쓰기 0이다. 품종만 고치는 사례(R15)와 정정 낱말이 있는 사례(R18·R60·R66)는 그대로다. (3) 새 사례 R99~R118은 실방송 보강(D-V3-80~89)이다.
