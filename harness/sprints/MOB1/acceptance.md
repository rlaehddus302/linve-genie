## 공통 전제

- 이미 합쳐진 모든 결과(`pnpm verify`)가 그대로 유지된다. 외부 계정·실기기 없이 돈다(시험용 프린터, 가짜 구글, 가짜 `SpeechRecognition`, 가짜 Wake Lock).
- **휴대폰 폭** = 48rem(768px) 미만. **PC 폭** = 48rem 이상(지금 `use-wide.ts` 경계). "휴대폰에서만"이라고 쓴 것은 PC 폭에서 지금 그대로다.
- **글자 150%** = 화면에 `html { font-size: 150% !important }`를 넣은 상태(점검과 같은 방법). **가로 넘침 0** = `document.documentElement.scrollWidth ≤ window.innerWidth`이고 보이는 버튼·칸·링크의 오른쪽 끝 ≤ 화면 폭, 왼쪽 끝 ≥ 0.
- 화면 문장 중 이 문서·DECISIONS·스펙이 따옴표로 정한 것은 글자 그대로 쓴다(E2E가 글자로 찾는다). 이름·닉네임이 든 문장은 이스케이프된 글로만 들어간다(절대 규칙 7).
- 기존 시험의 기대값 교체는 이 스프린트가 바꾼 문장·자리에 한한다 — 바꾼 곳마다 근거 결정 번호를 주석으로(`// MOB1 D-MOB1-0x`). 그 밖의 기존 시험은 바꾸지 않는다(절대 규칙 6).
- 각 dev는 바뀐 공개 모양(내보내는 이름·새 문장 상수·연습 모드 경로)을 `harness/sprints/MOB1/dev-notes.md`에 먼저 적고 시작한다.

### A. 누름 모양 (D-MOB1-02)

**AC-MOB1-01** [web] · UX-01·UX-04 · D-MOB1-02 — hover는 마우스 기기만, 알림 버튼 대비
- Then `apps/web/src/styles.css`에서 `:hover`가 든 모든 선택자는 `@media (hover: hover)` 블록 안에만 있다(블록 밖 `:hover` 0개). 잠긴 버튼 모양(`.button:disabled` — AC-S06-64)은 블록 밖에도 그대로 있다
- Given 412×915 터치 휴대폰(안드로이드 흉내 — `hasTouch`·`isMobile`), 콘솔에 빨간 알림 하나("출력 멈춤" 등). When 그 알림 버튼을 누르고 창을 닫는다(닫은 뒤 버튼에 초점·눌린 자리가 남은 상태). Then 그 버튼의 계산된 배경은 `rgb(179, 38, 30)`(`#b3261e`)·글자 `rgb(255, 255, 255)` — 회색 바탕이 아니다. 부드러운(노란) 알림도 같은 방식으로 배경 `#fef7e0`·글자 `#3d2b00`
- Given 1440×900 PC(마우스). When 빨간 알림 위에 마우스를 올린다. Then 배경 `#8c1d18`·글자 `#ffffff`. 노란 알림은 배경 `#fdeec2`·글자 `#3d2b00`. 보통·주·위험 버튼도 올렸을 때 글자·배경 대비 4.5:1 이상
