## 지적 (실패 시험 없음 — 스펙 확인 필요)
- **TD-A1-001** 규칙 제안의 "비슷함"이 한 글자 차이의 영문 사이즈를 다른 사이즈로 제안한다. 사이즈 S/M/L/XL에서 `반바지 XS` → "제안: XL", `반바지 XXL` → XL, S/M/XL에서 `반바지 L` → XL, S~XXL에서 `XXXL` → XXL. 판매 안 하는 사이즈를 쓴 댓글이 "비슷한 글자로 찾음"으로 정반대 사이즈 주문 제안이 된다. R-20 10이 정한 대로라 구현 버그가 아니다.
- **TD-A1-002** 가리기 구분자가 코어 `containsPhoneRun`(R-1)보다 좁다. 글자에 붙여 쓴 번호를 `ㅡ`·제로폭·`)` 등으로 끊으면(`반바지 엠사이즈010ㅡ1234ㅡ5678`, `…010​1234​5678`) 확인 필요(UNKNOWN_WORD)가 되고 번호가 그대로 AI로 간다. 띄어 쓴 모양(`010 - 1234 - 5678`, `010ㅡ1234ㅡ5678` 앞뒤 공백)은 대부분 언급이 되어 보내지 않는다 — 실제 노출은 좁다.
