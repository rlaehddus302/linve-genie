# APP2 독립 UX 검토

2026-10-30 · 역할 `ux-reviewer` · 제품 코드 변경 없음

**최종 판정: 확인한 화면 범위 PASS, 열린 지적 0건.** 실제 서버 연결 화면에서 발견한 CONFIRMED major 2건은 부모가 공통 버튼의 최소 폭·최대 폭·수축 규칙을 수정한 뒤 독립 재검증으로 닫았다. 375px에서 상품 요약은 잘리지 않고, 농도 버튼은 모두 44×44px다. 기기가 필요한 HG-APP2는 미확인 상태다.

1차에는 상품 보드의 긴 요약이 375px 밖으로 잘리고, 라벨 인쇄 농도 버튼의 폭이 44px보다 작았다. 상세 재현·담당 영역·해결 확인은 `findings.json`에 보존했다. 다른 blocker 또는 치명적 사용성 회귀는 발견하지 못했다.

## 환경과 증거의 범위

- `.claude/agents/ux-reviewer.md`, `docs/HARNESS.md`, APP2 `acceptance.md`·`dev-notes.md`를 기준으로 검토했다.
- 기존 `apps/mobile` Expo production 소스를 react-native-web으로 export하고 Chromium/Playwright에서 375×812 및 1440×900으로 실행했다. 앱의 공식 대상 플랫폼 설정은 iOS/Android 그대로 유지했다. 로컬 설치된 Expo CLI의 `EXPO_NO_WEB_SETUP=1`로 검토용 웹 출력만 만들었다.
- API/화면 주소는 모두 `http://127.0.0.1:15440`. 별도 `e2e-server.ts --port 15440 --origin http://127.0.0.1:15440 --web-dir <ux/.preview> --test-printer no`를 실행했다. 실제 Node HTTP 서버와 임시 PGlite, 저장소의 공개 시험 계정을 사용했다. 기존 사용자 서버·기존 데이터·다른 검증 포트를 사용하지 않았다.
- 브라우저 API 요청을 성공으로 대체하지 않았다. 실제 `POST /api/login`, `/api/broadcasts`, `/api/events`, `/api/days/2026-10-30/packing` 200 응답과 후속 GET 화면 반영을 관찰했다. 음성/프린터에 Fake 성공을 주입하지 않았다. 호스트 마이크·BLE 장치 접근은 없었다.
- **Expo web 화면 검토는 native 빌드의 설치·쿠키 저장소·마이크·BLE·백그라운드 동작 확인을 대체하지 않는다.** 기기 모듈 없음 오류는 이 검토 환경에서의 결과이며 iOS/Android 지원 여부를 판정한 결과가 아니다.

## 가독성·누름 영역

- 캡처한 16개 화면에서 실제 텍스트 노드의 최소 글자 크기는 모두 16px였다. 단순 색뿐 아니라 `판매 중`, `판매 종료`, `판매 완료`, `1등`, `라벨 대기`, `끊김`, `듣기 멈춤`, `포장 대기/완료`로 상태를 표시했다.
- 상품 보드의 긴 버튼을 제외한 측정 인터랙션은 375px 화면의 좌우 경계 안에 있었다. 농도 1~5를 제외한 측정 버튼은 폭·높이 모두 44px 이상이었다.
- 검토 중 브라우저 `pageerror` 0건. API 상태·DOM 치수·화면 텍스트는 `evidence.json`에 있다. 인증 쿠키/토큰/실제 고객 데이터는 저장하지 않았다.
- 원래 디자인과 용어를 유지하며 기능·규격 위반만 지적했다. 이 결과는 자동 테스트 수나 스냅샷만으로 만든 판정이 아니라 실제 화면 캡처를 직접 확인한 결과다.

## 미확인 항목

- 실제 Android/iPhone 권한·키보드·접근성 도구·화면 꺼짐 5분·앱 복귀·네이티브 세션 쿠키·외부 브라우저 로그인 연속성.
- 실제 B1 선택·연결·테스트 라벨 네 변/한글·30장 연속 출력·재연결. 여기서는 모듈 없음 안내와 실제 서버 대기열 표시만 확인했다.
- 정산·취소·택배는 APP2 내부 화면 범위가 아니며 기존 웹으로 여는 경로다. 그 업무 전체에 대한 최종 검증은 부모 E2E 결과와 HG에 따른다. 이 UX 검토에서 별도 통과로 주장하지 않는다.
- 실시간 1초/복귀 3초 등 성능 목표는 측정하지 않았다.

생성된 `.preview` 번들·임시 실행 스크립트·초기 자동화 탐색 실패 캡처는 제거하고 보고서·지적·측정 증거·정상 검토 스크린샷만 남겼다. 자체 15440 서버도 종료했다. 이 문서는 전체 `pnpm verify` 또는 HG 통과를 선언하지 않는다.
