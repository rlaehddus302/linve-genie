# APP2 통합 보고

2026-10-30 · 상태: 최종 자동 검증 진행 중. HG-APP2는 미확인.

## 결과

Expo 네이티브 화면의 로그인·방송·상품·문자찜·포장·음성/라벨 설정을 실제 HTTP/SSE 서버와 연결했다. 네이티브 오디오·BLE 어댑터를 production 기본으로 연결하고 모듈/권한/서버 실패를 가짜 성공으로 바꾸지 않는다. 라벨 그림은 서버가 현재 출력 시도에 고정된 데이터로 만들며 웹과 앱이 같은 그림을 받는다.

서버 읽기의 전체 카드·후보·폼·고침·문자찜과 종료 후 수동 조작을 보존했다. 바로 등록 설정을 음성을 켜기 전에도 저장하고 앱 재시작에 반영한다. 연결/복원 실패 때 마이크와 자동 쓰기를 멈추며, 실제 POST 전에 늦음과 연결 유효성을 다시 검사한다.

## 확인한 범위

- 실제 Node HTTP/WebSocket·PGlite 앱 통합: 로그인 쿠키/Origin → PCM → 전체 서버 읽기 → HTTP 상품 등록, 끄기 뒤 카드/폼 수동 처리와 idle 정리, 실제 서버 bitmap. 네이티브 캡처·쿠키 저장소만 플랫폼 경계 대역을 사용했다.
- 네이티브 오디오47시험, BLE의 실제 서버 그림→B1 protocol 바이트 교차 검증. 출력 권한·기기/시도 불일치·완료 작업 재조회 거절, 잘못된 그림은 print done 없음.
- Expo iOS/Android export 및 얇은 클라이언트/비밀 미포함 검사. 설치 가능한 서명 앱·실기기 검증과 구별한다.
- 독립 UX: 실제 서버와 Expo web preview에서 로그인·등록·되돌리기·문자찜·포장·설정 흐름을 375px/1440px로 직접 확인했다. 상품 요약 잘림·작은 농도 버튼2건 수정 후 최종17화면에서 16px 이상, 버튼44px 이상, 화면 넘침·브라우저 오류0. 증거는 `ux/report.md`와 전후 캡처에 있다.
- 수용 기준별 구현/시험은 `dev-notes.md`, `test-notes-domain.md`, APP1b 스펙/위험 감사에 연결되어 있다.

- APP2 라벨 미리보기·PNG/PDF/A4는 실제 출력과 같은 서버 그림을 받는다. 기다리는 포장 작업은 저장된 perPage를 보존한다. RA-APP2-003 해결 및 실제 파일 동등성 선택3개 통과.

## 게이트

최종 `pnpm verify` 결과는 확정 후 기록한다. 최신 코드의 Expo iOS·Android export는 각각3.8MB 번들로 완료했고, 얇은 클라이언트 검사4/4가 통과했다. 역할별 보호 경로 게이트는 통과했다. 판정 엔진·골든 기대값을 보존했다.
