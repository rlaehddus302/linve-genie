# KP1 사용성 점검 (ux-reviewer)

- 방법: E2E 서버·화면을 `CI=1 E2E_PORT_OFFSET=700 E2E_ONLY=chromium`(서버 3800·화면 5873)으로 띄우고, `tests/e2e/kp1/support.ts` 도우미로 새 판매자 → 방송 1(유튜브 손님 120,000원 입금) → 확인서 링크에서 배송지·동의 → 연결 코드 → 방송 2(같은 손님·새 손님·코드 채팅) → 묶음 자세히 → 리포트(방송 중·끝난 뒤) → 손님 자세히 → 엑셀 창 → 설정 → 공개 일정 페이지 → 링크에서 지우기를 차례로 밟았다. PC 1440px·휴대폰 375px(손님 쪽은 터치·모바일 문맥).
- 측정: 화면마다 보이는 글자의 계산된 글자 크기, 누르는 칸(버튼·링크·입력·체크)의 크기, 가로 넘침, 영어 상태값.
- 스크린샷: 이 폴더의 `pc-*.png`, `m375-*.png`. 임시 점검 스크립트는 커밋하지 않았다.

## 좋은 점
- 375px 모든 화면에서 가로 넘침 0. 화면 글에 영어 상태값(CONFIRMED·PENDING 등) 없음.
- 공개 일정 페이지는 글자가 모두 18px 이상이고 버튼이 넓다. 손님 링크의 동의 글·지우기 확인·코드 확인 문장이 쉽다.
- 판매자 손님 자세히는 받는 분 `홍*동`, 연락처 `끝 5678`만 보이고, 지우기 앞에 "지우면 되돌릴 수 없어요" 확인 창이 있다.
- 설정 "방송 알림"은 수만 보이고 번호는 보이지 않는다. 리포트에 손님 이름이 없다.
