# APP1b 통합 개발 노트

## 서버와 기기 경계

- `packages/voice-session/server`가 기존 `VoiceController` 전체를 실행한다. 읽기·카드·후보·정정·문자찜 규칙을 복제하지 않았다. 기존 파일 위치는 유지하고 DOM, 저장소, 시계, archive, 실제 쓰기는 host로 주입한다.
- 웹은 `remote.ts` 상태 표시와 지연 로드하는 `transport.ts`만 사용한다. 자체 받아쓰기는 AudioWorklet → 16kHz 모노 PCM16 3,200바이트/100ms → 인증된 WS, 명시 선택한 PC Chrome은 같은 서버에 최종 글을 보낸다.
- 모바일도 같은 wire 상태/효과를 받는다. 서버는 인증된 판매자·방송 상품/설정과 최근 실제 판매 10일의 이력을 공급한다. 시험용 history observer는 E2E 기동에서만 주입된다.
- 효과는 세션 ID/효과 ID로 구별한다. 기기가 기존 HTTP API를 호출하며 늦은 자동 쓰기, 옛 연결의 응답, 같은 효과의 재전달은 실행하지 않는다. 오프라인 수동 등록은 서버가 만든 카드 버전별 DTO와 최초 요청 번호를 유지한다.
- 꺼진 음성의 카드·폼·문자찜·고침 대기 내용은 서버 서명 토큰을 기기 메모리에만 둔다. 재연결 때 같은 계정/방송/기기에만 복원하고 자동 타이머는 재시작하지 않는다. 수동 조작만 할 때는 마이크를 열지 않는 임시 제어 연결을 사용한다.
- 계정 별칭은 `voice_aliases`에 저장한다. 최초 migration은 계정 값 우선, 사용자의 명시적인 `clearLearned`만 목록을 지운다. 판매 내역 복원은 계정 별칭을 보존한다.

## 기존 시험의 실행 경계 이전

- UI 카드/문자찜 단위 시험은 테스트 전용 `legacy-voice-ui-fixture.ts`로 기존 controller를 주입한다. 제품 fallback이 아니며 새 원격 단위·실제 WS·브라우저 PCM E2E가 서버 경계를 별도로 검사한다.
- I5 기본 모바일 경로의 전송 고지와 홈 화면 경고는 D-APP1b-05에 따라 LG 계약으로 이전했다. PC에서 명시 선택한 Chrome 문장과 기존 순수 Web Speech 규칙은 보존한다.
- `packages/voice/test/boundaries.test.ts`는 voice-session을 voice로 잘못 매칭하던 정규식을 바로잡고, 서버 읽기 영역과 웹의 세 전송 모듈만 허용한다. 다른 앱/코어/라벨/문서와 모바일 실행 코드의 추출기 차단은 유지한다.
- S00 타입 범위 공격의 작은 복사본에는 서버 읽기가 재사용하는 순수 웹 조회 어댑터만 추가했다. 타입 오류 공격과 성공 전제 단언을 그대로 유지한다.
- 기존 라벨 연결 화면 시험의 가짜 서버에도 새 bitmap 입구를 연결했다. 연결→테스트 인쇄→출력 기기 선택 순서와 주 버튼 단언은 동일하다.

## 다른 영역의 최소 수정

- `apps/server`는 공통 읽기 실행을 위해 DOM 타입을 포함하지만 브라우저 전역을 실행하지 않는다. TS 6의 `BodyInit` 검사와 함께 잡힌 파일 응답의 바이트는 `Uint8Array`로 복사해 같은 내용으로 보낸다.
- 루트 ws/@types/ws 의존은 실제 중계 및 독립 WS 시험용이다. 버전은 고정했다.
- 전체 검증 및 독립 감사의 최종 결과는 각 sprint report에 남긴다. 이 노트의 구현 완료가 모든 게이트/HG 통과를 뜻하지 않는다.

## 최종 브라우저 회귀 수정

- 기기 설정 변경을 즉시 저장하고 늦은 서버 저장 효과가 최신 선택을 덮지 않게 했다. Chrome 다시 시작 표시는 기존 1초를 유지하며, 치명 오류 뒤 끄기 응답을 받은 후 재시작한다. 캡처 중지와 읽기 연결 종료를 구분해 끄기 명령·최종 기록을 잃지 않는다.
- 지원 여부를 동의창보다 먼저 확인한다. 연결이 끊기면 카드·문자찜의 자동 대기를 멈추고 남은 항목에 수동 처리 안내를 남긴다. 복구만으로 새 문자찜을 보내지 않는다.
- 등록 DB 반영이 기기의 목록 갱신보다 먼저 도착하는 R66 경쟁을 고쳤다. 같은 상품의 가격 고침은 기존 등록 완료 `noteVoiceRegistered`의 번호·이름·가격·상품 ID가 맞을 때 이어 보낸다. 등록 실패/30초 응답 없음은 오류로 남기고 가짜 고침 성공을 만들지 않는다. 종료 시 대기와 타이머도 정리한다.
- 추가 회귀를 포함한 원격 웹/서버 세션 단위 30개 및 타입·린트·웹 빌드 통과. 실제 브라우저 검증 결과는 E2E 노트와 최종 보고에 기록한다.
