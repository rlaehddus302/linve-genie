# APP1b 통합 보고

2026-10-30 · 상태: 자동 구현·통합 검증 범위 완료. AC-APP1b-03 실방송 전후 재생 비교는 자료 부재로 미확인.

## 결과

웹과 Expo 앱이 인증된 같은 서버 읽기 세션을 사용한다. 기존 `VoiceController` 전체와 사전·이력·계정 별칭을 서버에서 실행하고, 기기는 카드·폼·문자찜·고침·기록을 표시하며 기존 HTTP 쓰기 API를 호출한다. 별도의 간소화 파서로 교체하지 않았다. 웹/앱 빌드에서 추출기·품종 사전 구현을 제거했다.

끄기·재연결 후 남은 항목은 서버가 서명한 한정된 복원표로 이어진다. 자동 기한과 미처리 소리는 되살리지 않는다. 음성이 꺼진 카드의 수동 조작은 마이크 없는 임시 제어 연결로 처리한다. 오프라인 수동 상품 등록은 기존 요청 번호·outbox 계약을 유지하며, 문자찜의 재연결 자동 재전송은 하지 않는다.
