# PRN2 사용성 검토 (ux-reviewer, 2026-10-31)

- 관점: 컴퓨터에 서툰 나이 든 다육이 판매자, 휴대폰만으로 운영(NFR-09). 기준: 글자 18px 이상, 누르는 칸 52~64px, 대비 4.5:1, 쉬운 한국어, 개발 용어·영어 상태값 없음.
- 방법: E2E 서버·화면을 내 포트(화면 5573·서버 3500, `E2E_PORT_OFFSET=400`)에 따로 띄우고 Playwright 크로미움으로 PC 1440px·휴대폰 390px(터치) 두 폭에서 흐름을 따라갔다. 시험용 프린터는 `window.livejjimTestPrinter.setTestProfile(...)`으로 B1·바우아토·Marklife P50·D110을 흉내 냈다. 앱 화면은 `apps/mobile/src/screens/{LabelsScreen,PrinterPickList}.tsx`·`ui/theme.ts`·`lib/words.ts`를 읽고 문장·크기만 평가했다.
- 스크린샷: 이 폴더의 `pc-*.png`·`phone-*.png` (번호 = 흐름 순서).

## 잘 된 점

- B1 연결에는 "(실험)"·안내 상자가 없고 바우아토·Marklife·D110에는 이름 뒤 "(실험)" + 노란 안내 상자가 붙는다(`*-02`, `*-03`). 영어 상태값·ID(BAUATO, EXPERIMENTAL 등)는 화면에 없다.
- 실험 프린터 칸(프린터 이름·안내·테스트 인쇄·예/아니요·이 기기에서 출력)은 휴대폰 390에서 글자 18px 이상·높이 52px 이상, 대비 4.5:1 이상, 가로 스크롤 없음(측정).
- 출력 기기에 실험 프린터를 이었을 때 멈춤 띠가 까닭과 할 일을 한 문장으로 말하고(`*-11b`), "예" 뒤 "좋아요. 멈췄던 출력을 이어서 해요."로 끝맺는다(`*-12`).
- 크기 목록이 출력 기기 프린터에 따라 바우아토 → 테이프 → B1로 바뀌고 테이프는 "테이프 12×40mm"처럼 이름이 붙는다(`*-07`, `*-10`).

## 지적

### UX-PRN2-001 · 높음 · 실험 프린터 테스트 "아니요" 도움말이 B1 전용이라 틀린 말을 한다
- 화면: 웹 라벨 › 프린터 › 테스트 인쇄 결과 "아니요". `phone-17-d110-test-no-help.png`
- 본 것: D110(테이프)·바우아토에서 "아니요"를 누르면 `라벨 크기가 50×30mm인지 확인해 주세요.` / `인쇄 농도를 한 단계 올려 보세요.` / `NIIMBOT 정품 라벨인지 확인해 주세요.` / `맨 아래 테두리가 빠지면 알려 주세요.`가 나온다(`LabelsPage.tsx` `TEST_HELP` 고정 목록). 테이프 프린터는 50×30을 찍을 수 없고, 바우아토는 농도 칸이 없으며, Marklife·바우아토는 NIIMBOT 라벨이 아니다. 실험 프린터에서 "아니요"를 누른 판매자에게 가장 필요한 "그림 파일로 제조사 앱에서 인쇄하기" 길이 이 목록에는 없다. 앱은 "아니요" 뒤 아무 도움말도 없다.
- 제안: 도움말을 이은 프로필에서 만든다. 크기 줄은 `라벨 크기가 {프로필 기본 크기 이름}인지 확인해 주세요.`, 농도 줄은 농도가 있는 프린터에만, 정품 줄은 NIIMBOT일 때만. 실험 프린터면 맨 위에 `잘 안 나오면 이 프린터로 찍지 말고, 라벨을 그림 파일로 저장해 {앱 이름}에서 인쇄해 주세요.` + "그림 파일로 저장하기" 단추. 앱도 같은 목록을 보인다.

### UX-PRN2-002 · 높음 · "그림 파일로 저장하기"를 눌러 가도 그림 파일 단추가 바로 보이지 않는다
- 화면: 웹 라벨 › 실험 안내 상자 "그림 파일로 저장하기" → 내보내기. `phone-09-after-export-link.png`, `pc-14-label-error.png`, `phone-14-label-error.png`(맨 아래)
- 본 것: 단추는 내보내기 칸으로 건너뛰지만, 거기 크게 보이는 것은 "1등 라벨 모두 A4 PDF로 저장"·"대기 중인 라벨 모두 A4 PDF로 저장"이다. 라벨별 그림 파일(PNG) 저장·공유는 접힌 `라벨마다 그림 파일로 저장`(글자만 있는 접기 줄이라 누르는 곳으로 보이지 않는다) 안에 있고, 실제 방송이 없으면 그 줄조차 없다(`phone-09`). 출력이 멈춘 "대기 중인 라벨"은 PDF로만 낼 수 있어, 지금 막힌 그 한 장을 그림 파일로 제조사 앱에 보내는 길이 없다. 방송 중 한 손으로는 찾기 어렵다.
- 제안: 실험 프린터가 이어져 있으면 접기를 펼친 채로 열고(지금 `noMethods`일 때만 펼침), 접기 줄을 단추 모양으로 바꾸고 이름을 `라벨 한 장씩 그림 파일로 저장·공유`로. 대기 중인 라벨에도 줄마다 "그림 파일로 저장"/"공유"를 둔다. 안내 상자 단추에서 건너뛸 때는 그 목록으로 바로 간다.

### UX-PRN2-003 · 높음 · 라벨 오류 멈춤 띠가 까닭(크기)을 말하지 않고, 고칠 곳이 두 화면 아래에 있다
- 화면: 웹 라벨 › 출력 대기열 멈춤 띠·작업 줄. `phone-14b-label-error-band.png`, `phone-14-label-error.png`, `phone-16-broadcast-label-error.png`
- 본 것: 띠 = `라벨을 만들지 못해 멈췄어요. 라벨 설정을 확인한 뒤 다시 시작해 주세요.`, 작업 줄 = `마지막 오류: 라벨 설정에 고칠 곳이 있어요.` 구체 문장(`이 프린터는 50×40 라벨을 찍을 수 없어요…`)은 휴대폰에서 두 화면쯤 아래 라벨 설정 안에만 있다. 방송 화면 알림은 `출력 멈춤 · 라벨을 만들지 …`로 잘려 까닭이 안 보인다. "다시 시작"을 먼저 누르면 같은 오류로 다시 멈춘다.
- 제안: 크기 때문이면 띠 문장을 `이 프린터는 50×40mm 라벨을 찍을 수 없어 멈췄어요. 아래 '라벨 크기 고르기'에서 50×30mm처럼 이 프린터 크기를 고르고 저장한 뒤 '다시 시작'을 눌러 주세요.`로, 띠 안에 라벨 설정 크기 칸으로 가는 단추 `라벨 크기 고르기`를 둔다. 작업 줄도 `마지막 오류: 이 프린터에 맞지 않는 라벨 크기(50×40mm)예요.`

### UX-PRN2-004 · 보통 · 크기 경고가 이미 라벨 설정 안에서 "라벨 설정에서 바꿔 주세요"라고 한다
- 화면: 웹 라벨 › 라벨 설정 › 라벨 크기. `phone-15-size-warning.png`, `pc-15-size-warning.png`
- 본 것: 라벨 크기 바로 아래 경고 `이 프린터는 50×40 라벨을 찍을 수 없어요. 라벨 설정에서 크기를 바꿔 주세요.` — 이미 그 칸에 있는데 어디로 가라는지 헷갈리고, 고른 뒤 "라벨 설정 저장"을 눌러야 한다는 말이 없다. "50×40"에 mm가 없어 위 선택지(50×30mm)와 모양이 다르다. 라디오가 하나도 선택되지 않은 상태라 무엇을 눌러야 할지 더 막막하다.
- 제안: 이 자리에서는 `이 프린터는 50×40mm 라벨을 찍을 수 없어요. 위에서 크기를 하나 고르고 아래 '라벨 설정 저장'을 눌러 주세요.` (출력 기기 쪽 문장 L-11 13은 그대로 두되 라벨 설정 안 문장만 다르게 — spec-keeper 확인 필요.)

### UX-PRN2-005 · 보통 · 실험 프린터 멈춤 띠에 할 일 단추가 없다
- 화면: 웹 라벨 › 출력 대기열 멈춤 띠. `phone-11b-pause-band.png`, `pc-11-paused-experimental.png`
- 본 것: 문장은 분명하지만(`테스트 인쇄를 하고 "예"를 누르면 다시 출력해요.`) 띠 안에 단추가 없다. "테스트 인쇄"는 위 프린터 칸에 있어, 다른 화면(방송·문자찜)에서 위 줄 "출력 멈춤"을 보고 들어온 판매자는 띠를 보고 위로 다시 찾아 올라가야 한다.
- 제안: 띠 안에 `테스트 인쇄` 단추(누르면 프린터 칸의 테스트 결과 "예/아니요"로 초점 이동)를 둔다. 앱도 대기열 카드 멈춤 알림 아래 같은 단추.

### UX-PRN2-006 · 보통 · "좋아요. 멈췄던 출력을 이어서 해요."가 다른 까닭으로 다시 멈춘 뒤에도 남는다
- 화면: 웹 라벨 › 프린터 › 테스트 인쇄 결과. `pc-14-label-error.png`, `phone-14-label-error.png`
- 본 것: "예" 뒤 상태 문장이 그대로 남아, 바로 아래 빨간 `라벨을 만들지 못해 멈췄어요`와 동시에 보인다. "이어서 한다"와 "멈췄다"가 한 화면에 같이 있어 무엇이 맞는지 헷갈린다.
- 제안: 멈춤이 새로 생기면(또는 몇 초 뒤) 이 문장을 감추거나 `테스트 인쇄 확인됨`처럼 지난 일로 바꾼다.

### UX-PRN2-007 · 보통 · 앱 "제조사 앱으로 보내기" 단추가 둘이고, 보이는 글이 같다
- 화면: 앱 라벨 화면(코드 평가) — 프린터 카드의 테스트 라벨 단추와 "찍는 중인 라벨" 카드의 작업 단추.
- 본 것: 둘 다 보이는 글이 `제조사 앱으로 보내기`(구분은 화면 읽기용 이름뿐). 찍는 중일 때 판매자가 위쪽(프린터 카드) 단추를 누르면 막힌 판매 라벨이 아니라 테스트 라벨이 넘어간다. 프린터 카드 단추는 프린터가 끊겨 있어도·B1이어도 늘 보이고, 무엇을 보내는지 말이 없다. 제조사 앱 이름(Luck Jingle·Marklife·NIIMBOT)도 단추에 없다.
- 제안: 프린터 카드 단추 글을 `테스트 라벨을 {앱 이름}으로 보내기`, 작업 카드는 `이 라벨(3번)을 {앱 이름}으로 보내기`처럼 무엇을·어디로를 보이는 글에 넣는다. 테스트 라벨 단추는 실험 프린터가 이어졌거나 연결 실패 뒤에만 보인다.

### UX-PRN2-008 · 보통 · 앱의 실험 꼬리표·안내 일부가 16px
- 화면: 앱 `PrinterPickList`의 "실험" `Tag`(FONT_SMALL 16), `LabelsScreen`의 `EXPERIMENTAL_WAIT_TEST`·`EXPERIMENTAL_WAIT_TEST_MINE`·`JOB_SHARE_HINT`(`Hint` 16px, 회색).
- 본 것: "이 기기에서 출력"이 왜 안 보이는지 알려 주는 핵심 문장과, 고르기 목록에서 실험 여부를 알리는 유일한 표시가 16px이다. 기준 18px 미달.
- 제안: 이 세 문장은 `Body`(18px)로, "실험" 꼬리표는 18px 굵게 + 글 `실험 중`으로.

### UX-PRN2-009 · 보통 · 휴대폰 라벨 오류 띠 "다시 시작"·내보내기 PDF 단추가 16px·높이 44px
- 화면: `phone-14b-label-error-band.png`, `phone-09-after-export-link.png`
- 본 것: 멈춤 띠 안 "다시 시작"(측정 16px·44px), "대기 중인 라벨 모두 A4 PDF로 저장"(16px·44px). 라벨 설정의 크기 라디오 줄도 44px. PRN2에서 크게 만든 프린터 칸(18px·52px)과 달리 이 흐름의 다음 단추들은 작다.
- 제안: 멈춤 띠 단추·내보내기 단추·크기 라디오 줄을 프린터 칸과 같은 18px·52px 이상으로.

### UX-PRN2-010 · 낮음 · 실험 프린터를 이었는데 크기 목록은 B1 그대로
- 화면: `phone-03b-bauato-connected-full.png`, `pc-11-paused-experimental.png`
- 본 것: 바우아토를 이었지만 아직 출력 기기가 아니거나 "예" 전이면 라벨 크기가 50×30/50×20/50×40(B1)로 보인다(스펙대로 출력 기기 기준). 50×20·50×40은 바우아토가 못 찍는데 이때 고르면 나중에 라벨 오류로 멈춘다.
- 제안: 라벨 크기 칸 아래 한 줄 `크기 목록은 출력 기기에 이은 프린터에 맞춰 바뀌어요. 지금은 NIIMBOT B1 기준이에요.`

### UX-PRN2-011 · 낮음 · "실험"이라는 말이 낯설다
- 화면: 연결 전 한 줄·이름 뒤 "(실험)"·안내 상자. `phone-01-labels-before-connect.png`, `phone-03-bauato-connected.png`
- 본 것: 판매자에게 "실험"은 "내가 실험 대상인가?"로 들릴 수 있다. 다만 다음 문장이 할 일을 말해 줘 이해에는 큰 문제가 없다.
- 제안(nit): `(확인 중)`·`아직 확인 중인 프린터예요.` 쪽이 더 쉽다. 스펙 문장(L-7)이라 spec-keeper 판단.

### UX-PRN2-012 · 낮음 · 방송 화면 멈춤 알림이 잘린다
- 화면: `phone-16-broadcast-label-error.png`
- 본 것: `출력 멈춤 · 라벨을 만들지 …` — 까닭이 잘려 라벨 화면에 가 봐야 한다(PRN2 이전부터 있던 모양이지만 실험 멈춤 문장도 같이 잘린다).
- 제안: 휴대폰에서는 두 줄까지 보이거나, 짧은 글 `출력 멈춤 · 라벨 크기 확인`/`출력 멈춤 · 테스트 인쇄 필요`를 쓴다.
