## 흔들림 방지 메모
- 리허설 채팅 구매자는 닉네임마다 같은 채널(`simChannel`)이라, 오늘 리허설 범위를 쓰는 시험(AC-O4-33)은 구매자 ID·상품 번호로 거른다.
- 실제 범위는 `uniqueDate()` 또는 새 판매자(@youtube·라벨 설정)로 나눈다 — 라벨 설정·출력 기기를 바꾸는 시험은 새 판매자.
- 확인서 데이터 조회의 문자 구매자 이름은 `문자찜(메모) / 끝자리 nnnn`이라 판매대장 구매자 칸은 메모만 뽑아 비교한다.
