### AC-P1-01 [device] 라벨 골든 전부 통과
- 근거: D-P1-01, `tests/golden/README.md` "라벨 골든", LABEL_RULES L-0 2
- Given `tests/golden/label/`의 `product.json`·`packing.json`·`sizes.json`
- When `pnpm test`(packages/label 단위 테스트)
- Then 폴더의 모든 `*.json`을 읽어 사례마다 라벨 패키지의 **글 계산 순수 함수**(캔버스 없이 도는 함수)로 돌리고 `out`과 **깊은 같음**으로 비교한다: `items`·`common`은 키 집합까지 정확히 같다(찍지 않는 항목은 키가 없어야 한다), `pages`는 순서·개수까지 같다, `error`면 그 코드이고 글·그림이 만들어지지 않는다. `size` 사례는 그 크기의 기본 상품 템플릿으로 실제 렌더한 그림의 점 수와 A4 배치 함수의 장 수를 본다.

- 확인: 단위(골든). spec-auditor는 기대값 하나를 일부러 바꾸면 실패하는지 확인한다.

### AC-P1-05 [device] 포장 라벨의 글과 쪽 나누기
- 근거: LBL-02, L-4, D-P1-05

- Then 농도 1~5는 그대로 보내고, 0·6·소수는 보내지 않고 오류다. 폭 385점 이상의 그림은 보내지 않고 `IMAGE_TOO_WIDE`. 연결 전 출력은 `NOT_CONNECTED`, 출력 중 또 출력하면 `BUSY`.
- 확인: 단위

### AC-P1-43 [device] 끊김·오류·시간 초과

## F. 출력 대기열 (LBL-08·11, LBL-09 폐기 표시, L-8·L-10)

> 아래 J는 작업, L은 라벨 키, t는 부르는 쪽이 넣은 시각이다. 화면 낱말: `WAITING` 대기 · `PRINTING` 출력 중 · `DONE` 출력함 · `CANCELLED` 출력 안 함 · 폐기 표시 "폐기"(출력한 것은 "폐기 — 버려 주세요"). 멈춘 까닭: 끊김 "프린터 연결이 끊겼어요." · 프린터 오류 "프린터 오류로 멈췄어요." · 판매자 "출력을 멈췄어요."

### AC-P1-50 [device] 순서와 중복
- 근거: L-8 1·2, R-13, D-P1-09
- Given 연결됨, 빈 대기열
- When J1(L1)·J2(L2)·J3(L3)를 넣는다
- Then J1 → J2 → J3 순서로 한 번에 하나만 출력 중이 된다. 어느 때든 J2를 다시 넣으면(내용이 달라도, 끝난 뒤여도) 아무 일도 없다.
- 확인: 단위, 적대(속성)

### AC-P1-51 [device] 멈춤과 이어서 — 라벨이 사라지지 않는다
- 근거: LBL-06 AC2, L-8 3, D-P1-09
- Given J1 출력 중, J2·J3 대기
- When 연결이 끊긴다
- Then 대기열은 멈춤(끊김)이고 J1은 대기 맨 앞(시도 1, 마지막 오류 `DISCONNECTED`), 순서는 J1·J2·J3. 멈춘 동안 J4를 넣으면 맨 끝에 들어간다. 다시 연결되면 J1부터 이어서 출력해 J1·J2·J3·J4 순서로 끝난다.
- When 연결된 채로 J2가 `PRINT_FAILED`로 끝난다
- Then 멈춤(프린터 오류), J2는 대기 맨 앞. 시간이 지나도·연결이 그대로여도 저절로 다시 출력하지 않는다. 판매자가 "다시 시작"하면 J2부터. 판매자가 멈춘 대기열도 "다시 시작"으로만 이어진다. 대기 중에 끊겨도 멈춤(끊김)이다.
- 확인: 단위, 적대(속성 — 어떤 순서의 끊김·오류·다시 연결·다시 시작에도 넣은 작업은 출력함·출력 안 함·대기 중 하나로 늘 남고, 같은 작업이 동시에 둘 출력 중이 아니다)

### AC-P1-52 [device] 폐기 표시
- 근거: LBL-09 "이전 라벨은 폐기 표시", R-13 VOID_LABEL, L-8 4
- Given L1의 J1 출력함, L2의 J2 대기, L3의 J3 출력 중
- When L2·L3·L1을 폐기한다
- Then J2는 출력되지 않고 출력 안 함 + 폐기, J3는 끝난 뒤 출력함 + 폐기, J1은 출력함 + 폐기다. 같은 라벨 키를 다시 폐기하면 아무 일도 없고, 폐기는 되돌릴 수 없다. 폐기한 라벨 키는 재출력할 수 없다(AC-P1-53).
- 확인: 단위

### AC-P1-53 [device] 재출력과 이력
- 근거: LBL-11, L-8 5·7, D-P1-09
- Given L1의 J1이 t1에 기기 "PC"에서 출력함
- When 새 작업 J1b·지금의 라벨 데이터로 L1을 재출력한다
- Then J1b가 대기 맨 끝에 들어가고, 출력하면 L1의 이력은 출력 횟수 2, 시각 [t1, t2], 기기 ["PC", (t2의 기기)]다.
- Then J1b가 대기·출력 중인 동안 L1을 또 재출력하면 아무 일도 없다(거절 이유를 돌려준다). 이미 있는 작업 ID로 재출력하면 아무 일도 없다. 출력 안 함(판매자가 뺀) 라벨은 재출력할 수 있고, 폐기된 라벨은 할 수 없다.
- 확인: 단위

### AC-P1-54 [device] 대기 작업 빼기
- 근거: L-8 6
- Then 판매자는 대기 작업을 뺄 수 있다 → 출력 안 함, 출력되지 않고 기록은 남는다. 출력 중·출력함 작업은 뺄 수 없다(아무 일도 없음).
- 확인: 단위

### AC-P1-55 [device] 재출력 필요(내용 키)

- 확인: 단위

### AC-P1-56 [device] 실행기 + 가짜 프린터 — 30장 연속

## HG-2 확인 목록 (I1 뒤 사용자가 실제 B1으로 — 자율 진행 중이라 P1은 모의 검증)
