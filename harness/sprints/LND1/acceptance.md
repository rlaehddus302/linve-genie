# LND1 수용 기준 — 공개 소개 화면

- 스프린트: LND1 (6단계, 출시 준비 — 구글 앱 확인용 공개 홈페이지) · spec ID: **SYS-01**(로그인 화면 주소), **SYS-05**(정책 페이지·보안 머리글 — 바뀌지 않음 확인), **UX-01**(쉬운 말), **UX-04**(휴대폰 화면), **UX-07**(홈 화면 앱·서비스 워커 — 바뀌지 않음 확인) · 규칙: **SPEC v0.1.42**, DOMAIN_RULES 그대로(판정·정산·파서 변경 없음 — **골든 변경 없음**)
- 근거: `docs/launch/GOOGLE-OAUTH-VERIFICATION.md` 1절 2·2절·5절 — 구글은 로그인하지 않아도 보이는 홈페이지(앱이 하는 일·정책 링크·운영자·구글 데이터를 쓰는 까닭)를 요구하는데 지금 `/`는 로그인 화면이다 → **D-LND1-01~D-LND1-09**(모두 AUTO), D-MOB1-01·03(휴대폰 기준), D-RN1-01(서비스 이름), D-L1-01(가입 없음), D-036
- 개발 영역: **web 하나**. 서버 코드는 바뀌지 않는다 — `/login`은 이미 `index.html`(200·`no-cache`·CSP·보안 머리글)로 나간다(D-LND1-07). core·device·server 없음. 테스트: **e2e**(`tests/e2e/lnd1/**`와 아래 적은 기존 파일 줄). domain 없음. 사용성 검토 없음(문장은 이 문서가 확정).
- 태그: `[web]` = dev-web, `[e2e]` = test-e2e, `[spec]` = spec-keeper.

## 공통 전제

- 이미 합쳐진 모든 결과(`pnpm verify`)가 그대로 유지된다. 외부 계정 없이 돈다(가짜 OAuth 서버 — D-L1-07).
- **로그아웃 상태** = `/api/me`가 401. **브라우저 탭** = `display-mode: standalone`이 아니고 `navigator.standalone`이 참이 아님.
- **휴대폰 폭·글자 150%·가로 넘침 0**은 MOB1 acceptance "공통 전제"와 같은 뜻(D-MOB1-03).
- 화면 문장 중 이 문서·DECISIONS가 따옴표로 정한 것은 **글자 그대로** 쓴다(E2E가 글자로 찾는다). 아래 "확정 문장" 표가 기준이다.
- 기존 시험의 기대값 교체는 이 스프린트가 바꾼 주소·자리에 한한다 — 바꾼 곳마다 `// LND1 D-LND1-0x`. 그 밖의 기존 시험은 바꾸지 않는다(절대 규칙 6).
- dev-web은 바뀐 공개 모양(새 경로 이름, 새 문장 상수, 운영 사업자 상수 파일 이름·모양)을 `harness/sprints/LND1/dev-notes.md`에 먼저 적고 시작한다.

## 수용 기준

**AC-LND1-01** [web][e2e] · SYS-01, D-LND1-01·03 — 로그아웃 상태 `/`는 소개 화면
- Given 로그인하지 않은 새 브라우저 탭(쿠키 없음) When `/`를 연다 Then 주소는 `/` 그대로이고, `h1` "라이브지니"가 하나, 한 줄 소개, 링크 "로그인"·"시작하기", 절 "판매자의 하루"(번호 목록 `ol` 다섯 줄 — 확정 문장 그대로, 이 순서), "시작하려면", "구글 사용자 데이터를 쓰는 곳", "운영 사업자"와 "상호: 틈(TEUM)", 링크 "개인정보처리방침"(`/privacy`)·"이용약관"(`/terms`)이 보인다
- And "아이디"·"비밀번호" 칸이 없고, 위 줄 메뉴(`nav[aria-label="메뉴"]`)·"로그아웃"이 없다. 그림(`img`) 없음
- And 이 화면을 여는 동안 401로 답한 `/api/` 요청은 `/api/me` 하나뿐이다(판매자 데이터를 부르지 않음)
- 확인: E2E(`tests/e2e/lnd1/landing.spec.ts`)

**AC-LND1-02** [web][e2e] · SYS-01, D-LND1-01·03 — "로그인"·"시작하기"
- Given AC-LND1-01의 화면 When "로그인"을 누른다 Then 주소가 `/login`이고 로그인 화면(아이디·비밀번호 칸, 버튼 "로그인", 정책 링크 — 지금 `LoginPage`)이 보이며 "아이디" 칸에 커서가 있다. 브라우저 뒤로 가기 → 다시 소개 화면
- When `/login`에서 판매자 아이디로 로그인한다 Then 주소가 `/`(방송 목록 — "새 방송 시작"이 보임)이고, 브라우저 뒤로 가기가 `/login`의 로그인 칸을 보이지 않는다(로그인 성공은 기록을 바꿔 감 — 뒤로 가면 소개 화면 주소 `/`이며 로그인한 상태라 방송 목록)
- When 보조자 계정으로 `/login`에서 로그인한다 Then 주소가 `/sms`(지금 AC-I3-63 그대로)
- When 소개 화면에서 "시작하기"를 누른다 Then 주소의 경로는 `/` 그대로이고 절 제목 "시작하려면"과 그 문장이 화면 안(뷰포트 안)에 보인다. 로그인 화면·가입 화면으로 가지 않는다
- 확인: E2E

**AC-LND1-03** [web][e2e] · SYS-01, D-LND1-01 — 로그인한 사람
- Given 로그인한 판매자 When `/`를 연다 Then 지금처럼 방송 목록(소개 화면 문장 "판매자의 하루"가 없음)
- When 로그인한 채 `/login`을 연다 Then 로그인 칸 없이 주소가 `/`로 바뀌고(기록을 쌓지 않음) 방송 목록이 보인다
- 확인: E2E

**AC-LND1-04** [web][e2e] · SYS-01, D-LND1-01 (4) — 다른 앱 주소는 지금 그대로
- Given 로그아웃 상태 When `/settings`·`/broadcasts/<있는 방송 ID>`·`/sms`·`/packing?date=2026-10-18`를 각각 연다 Then 소개 화면이 아니라 그 주소 그대로 로그인 화면이 보이고, 로그인하면 **그 화면**(주소·검색값 그대로)이 보인다(지금 S05·I3 동작 — 회귀 없음)
- 확인: E2E(한 주소는 새 시험, 나머지는 기존 시험이 그대로 통과)

**AC-LND1-05** [web][e2e] · SYS-01, D-LND1-02 (a), AC-L1-21 — 간편 로그인에서 돌아옴
- Given 로그아웃 상태, 가짜 OAuth 서버로 연결되지 않은 구글 계정 로그인 When 서버가 `/?login=NOT_LINKED&provider=google`로 돌려보낸다 Then 소개 화면이 아니라 로그인 화면과 지금 문장(`NOT_LINKED` 문장)이 보이고, 주소는 `/`로 지워진다(지금 AC-L1-21 그대로)
- And 같은 탭에서 `/login`으로 가지 않아도 바로 아이디로 로그인할 수 있다(로그인 칸이 그 자리에 있음)
- When 연결된 계정으로 간편 로그인에 성공한다(서버가 `/`로 보냄) Then 방송 목록이 보인다(소개 화면 거치지 않음)
- 확인: E2E(기존 `tests/e2e/l1/**` 통과 + 새 시험 한 개)

**AC-LND1-06** [web][e2e] · SYS-01, D-LND1-02 (b) — 로그아웃·풀림 뒤는 로그인 화면
- Given `/`(방송 목록)에서 로그인한 판매자 When 로그아웃한다(PC 위 줄 "로그아웃" / 휴대폰 "더보기" 맨 끝 — D-MOB1-05) Then 소개 화면이 아니라 로그인 화면(아이디 칸)이 보인다
- Given `/`에서 세션이 서버에서 끝난다(시험 경로로 세션 지움) When 화면이 API 401을 받는다 Then 로그인 화면과 "로그인이 풀렸어요. 다시 로그인해 주세요."가 보인다(소개 화면 아님)
- When 로그아웃한 뒤 같은 탭을 새로고침한다 Then 소개 화면(D-LND1-02 — 새로고침 전까지만)
- 확인: E2E

**AC-LND1-07** [web][e2e] · UX-07, D-LND1-02 (c) — 홈 화면 앱
- Given 홈 화면 앱처럼 연 탭(`matchMedia('(display-mode: standalone)')`가 참이 되게 `addInitScript`로 흉내, 아이폰은 `navigator.standalone = true`) When 로그아웃 상태로 `/`를 연다 Then 소개 화면이 아니라 로그인 화면이 바로 보이고 주소는 `/`
- 확인: E2E(크로미움 matchMedia 흉내 1, WebKit `navigator.standalone` 흉내 1) + 웹 단위 시험(판단 함수)

**AC-LND1-08** [web][e2e] · SYS-05, D-LND1-08 — 정책 페이지 버튼
- Given 로그아웃 상태 When `/privacy`를 열고 위 줄 "로그인 화면으로"를 누른다 Then 주소 `/login`, 로그인 칸이 보인다. `/terms`도 같다
- 확인: E2E

**AC-LND1-09** [web][e2e] · UX-01, D-LND1-05 — 구글 사용자 데이터 고지
- Given 소개 화면 Then 절 "구글 사용자 데이터를 쓰는 곳"에 점 목록 다섯 줄(확정 문장 그대로, 이 순서)과 제한적 사용 문장이 보이고, 그 문장 안의 링크(이름 "구글 API 서비스 사용자 데이터 정책")의 `href`가 `https://developers.google.com/terms/api-services-user-data-policy`이고 `rel`에 `noopener`·`noreferrer`가 있다
- And `lang="en"`인 문단 하나가 D-LND1-05 영문 단락과 글자 그대로 같다(앞뒤 공백 무시)
- And 화면 어디에도 "다른 곳에 넘기지 않아요"·"제3자" 같은 단정 문장이 없다
- 확인: E2E

**AC-LND1-10** [web] · D-LND1-04 — 운영 사업자 상수
- Given 운영 사업자 상수의 상호가 "틈(TEUM)"이고 나머지 값이 빈 글(지금 값) When 소개 화면을 그린다 Then "운영 사업자" 아래 줄은 "상호: 틈(TEUM)" 하나뿐이고, "시작하려면" 절에 "계정 문의:" 줄이 없다
- When 시험에서 상수에 값(예: 사업자등록번호 "000-00-00000", 문의 이메일 "help@example.com")을 넣고 그린다 Then 그 항목만 "사업자등록번호: 000-00-00000"·"문의 이메일: help@example.com"·"계정 문의: help@example.com"으로 더 나온다(이메일은 `mailto:` 링크여도 됨)
- And 어느 경우에도 소개 화면 글에 "[확인 필요]"·"[미정]"·"[검토 필요]"·"확인 필요"가 없다
- 확인: 웹 단위 시험(상수를 인자로 받는 그리기 — 상수 파일을 시험이 바꾸지 않는다)

**AC-LND1-11** [web][e2e] · D-LND1-06 — 자바스크립트 없이 읽히는 글
