# 가짜 라벨 프린터 (맥이 블루투스 프린터인 척하기)

실물 프린터가 없어도 **폰 앱이 진짜 블루투스로** 라벨을 보내 볼 수 있게, 맥이 라벨 프린터처럼 광고하고 답하는 도구입니다.
받은 라벨은 PNG 그림으로 저장하고, 장마다 걸린 시간을 기록합니다.

- 흉내 내는 기종: NIIMBOT B1 · Marklife S2 · Marklife P12
- 답하는 방식은 저장소의 시험용 가짜 프린터(`packages/mobile-ble`의 `createFakeB1`, `packages/printer`의 `createFakeBluetooth`)와 같습니다. 자체 시험이 같은 입력에 같은 답·같은 점이 나오는지 확인합니다.
- 맥의 Command Line Tools만 있으면 됩니다(Xcode 전체는 필요 없음).

## 1. 만들기

```sh
cd tools/fake-printer
./build.sh                 # .build/sc/fake-printer 와 .build/sc/fake-printer-selftest 가 생깁니다
.build/sc/fake-printer-selftest   # "통과: 확인 …개"가 나오면 됩니다
```

`swift build -c release`로 만들어도 됩니다(결과는 `.build/release/`).

## 2. 맥 블루투스 권한 허락

처음 실행하면 맥이 블루투스 사용을 물어봅니다. **허락**을 누릅니다.

- 창이 안 뜨고 "블루투스 권한이 없다"고 나오면: **시스템 설정 → 개인정보 보호 및 보안 → 블루투스**에서 이 프로그램을 실행한 터미널 앱(터미널·iTerm 등)을 켜고 다시 실행합니다.
- 맥의 블루투스가 꺼져 있으면 메뉴 막대에서 켭니다.

## 3. 실행

```sh
.build/sc/fake-printer --mode b1             # NIIMBOT B1인 척 (이름 B1-FAKE)
.build/sc/fake-printer --mode marklife-s2    # Marklife S2인 척 (이름 S2_FAKE_BLE)
.build/sc/fake-printer --mode marklife-p12   # Marklife P12인 척 (이름 P12_FAKE)
```

멈추려면 `Ctrl+C`. 받은 그림과 기록은 `./out/`에 생깁니다(`--out 폴더`로 바꿀 수 있음).

| 옵션 | 하는 일 |
|---|---|
| `--name 이름` | 광고 이름 바꾸기. 앱은 이름 앞자리로 고릅니다(B1은 `B1`, S2는 `S2_`, P12는 `P12_`) |
| `--no-credit` | (Marklife) 흐름 제어 크레딧(`01 04`, `01 01`)을 보내지 않음 — 크레딧 없는 기기 흉내(D-N1-12) |
| `--mtu auto` 또는 `--mtu 185` | (Marklife) 첫 크레딧 뒤에 MTU 알림 `02 lo hi`를 보냄 |
| `--no-ack` | (Marklife) 다 받아도 끝 알림 `AA`를 보내지 않음 — 시간 초과 흉내 |
| `--ack-delay 3000` | (Marklife) 끝 알림을 3초 늦게 보냄 |
| `--also-b1-service` | (Marklife) 광고에 B1 서비스(`e7810a71…`)도 실음 — B1 찾기 목록에 섞여 보이는 경우 흉내 |
| `--battery 30` | (B1) 배터리 값 |
| `--model-id 4097` | (B1) 모델 번호를 바꿈 — 앱이 "다른 기종"으로 거르는지 볼 때 |
| `--verbose` | 받은·보낸 바이트를 16진으로 화면에 찍음 |

## 4. 폰 앱에서 고르기

1. 맥에서 위 명령을 실행하고 "광고 중"이 나올 때까지 기다립니다.
2. 폰의 블루투스를 켭니다. 폰 **설정 앱의 블루투스 목록에서 맥을 연결하지 마세요** — 앱 안에서 고릅니다.
3. 앱에서 **프린터 연결 → 찾기**를 누르고 목록에서 `B1-FAKE`(또는 맥 이름, 아래 주의)를 고릅니다.
4. 라벨을 찍습니다. 맥 화면에 "쪽을 다 받았다 … → out/b1-….png"가 나오면 그 PNG를 열어 봅니다.

Marklife 모드(`S2_FAKE_BLE`·`P12_FAKE`)는 웹(크롬 Web Bluetooth)의 Marklife 연결로 고릅니다.

### 주의: 목록에 맥 이름이 보일 수 있어요

맥은 광고에 `B1-FAKE` 같은 이름을 싣지만, 한 번 연결되고 나면 폰이 **맥의 컴퓨터 이름**(예: "홍길동의 MacBook Air")을 기기 이름으로 기억해 보여 줄 수 있습니다.

- B1 모드는 이름이 달라도 B1 서비스(`e7810a71…`)로 목록에 나옵니다. 목록에 맥 이름이 보이면 그것을 고르면 됩니다.
- 이름 앞자리로만 고르는 경우(Marklife `S2_`·`P12_`)에는 맥 이름 때문에 목록에 안 나올 수 있습니다. 그럴 땐 **시스템 설정 → 일반 → 정보 → 이름**을 잠시 `S2_FAKE_BLE`처럼 바꾸고, 폰의 블루투스를 껐다 켠 뒤 다시 찾습니다. 시험이 끝나면 원래 이름으로 돌려놓으세요.

## 5. 받은 것 보기

- `out/<모드>-<날짜시각>-<번호>.png` — 프린터가 받은 그림 그대로(검정 점 = 검정). 203dpi로 적혀 있습니다.
  - P12(L11)는 앱이 시계 방향으로 90도 돌려 보내므로 그림이 세로로 서 있습니다(진짜 프린터가 받는 방향).
  - S2(YXQ)는 압축(zlib 창 10비트)을 풀어 저장합니다. 창이 10비트가 아니면 화면에 "주의"가 뜹니다(진짜 프린터는 그런 그림을 버립니다).
- `out/log.jsonl` — 한 줄에 하나씩:
  - `connect` / `disconnect`: 폰이 알림을 켬(이어짐) / 모두 끔(끊김). 다시 이으면 이어서 받습니다.
  - `job`: 장마다 `firstWriteAt`(첫 쓰기) · `lastWriteAt`(마지막 쓰기) · `endReplyAt`(끝 응답: B1은 인쇄 끝 답, Marklife는 `AA`) · `totalMs` · `writes`(쓰기 조각 수) · `bytes` · `png`.
  - `job-incomplete`: 다 받기 전에 끊긴 장.

## 6. 자체 시험과 골든

- `test/golden/*.json`은 TS 가짜 프린터가 같은 입력 바이트에 낸 답과 받은 점입니다. 다시 만들려면 저장소 루트에서:

  ```sh
  pnpm install
  node tools/fake-printer/test/make-golden.mjs
  ```

  몇 번 만들어도 같은 파일이 나옵니다. 파일이 바뀌었다면 TS 가짜의 동작이 바뀐 것이니 Swift 쪽도 맞춰 고칩니다.
- `fake-printer-selftest`는 블루투스를 쓰지 않습니다. 조각마다 같은 알림이 같은 순서로 나오는지, 받은 그림의 점이 같은지, 저장한 PNG를 다시 읽어도 점이 같은지 봅니다.

## 알아 둘 것

- 진짜 B1이 광고하는 이름의 꼴은 아직 확인하지 못했습니다(그래서 `--name`으로 바꿀 수 있게 했습니다).
- 맥은 연결·끊김을 직접 알려 주지 않아서, 폰이 알림을 켜고 끄는 것으로 이어짐·끊김을 판단합니다.
- TS 가짜와 다른 점 하나: 끊기면 반쯤 받은 B1 패킷을 버립니다(새 연결에서 처음부터 읽게).
