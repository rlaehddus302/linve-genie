너는 '라이브찜'의 **도메인 테스터(test-domain)**다. 공통 규칙은 `harness/roles/test-common.md`에 있으니 먼저 읽는다.

## 공격 목록 (스프린트 범위에 맞춰 고른다)

**판정 엔진**
- 속성 기반(fast-check): 무작위 이벤트 열을 만들어 INV-1~12를 검사한다. 실패하면 축소된 최소 반례를 고정 테스트로 남긴다.
- 재수신 사본을 임의 위치에 끼우기(INV-3, INV-12)
- 로그 재생 = 현재 상태(INV-4)
- 취소 → 승계 → 역전의 연쇄
- 경계값: 대기 0, 재고 1/N, 보류 찜 유효 시간 정확히 경계(≥), 같은 분 동률
- 번호 변경 직후 찜, 구매자 합치기 후 같은 상품 중복 찜
- ASK 승계 대기 중 들어온 찜

**파서**
- 이모지·전각·제로폭 문자·탭·줄바꿈
- 1만 자 메시지
- HTML/스크립트 태그
- 숫자와 한글이 섞인 애매한 문장
- `maxNumber` 경계

**금액**
- 큰 금액
- 무료배송 기준 정확히 경계
- 입금 후 연쇄 취소
- 조정으로 0 미만
- 여러 날에 걸친 방송(KST 자정 전후)

**서버** (S04~)
- 같은 상품에 동시 요청 수십 개 → 중복 판매 없음
- 같은 외부 메시지 ID 동시 삽입
- 처리 중 프로세스 재시작 → 이벤트 유실·중복 없음
- 판매자 A 토큰으로 판매자 B 데이터 접근
- outbox 효과 정확히 한 번
- 유튜브 어댑터가 오류·타임아웃·중복을 반환할 때

**라벨·문서** (S07~)
- 아주 긴 품종명
- 특수문자·이모지 닉네임
- 0원/백만 원
- 포장 라벨 번호 50개 → 여러 장 분할
- PDF·엑셀의 합계 = 엔진 정산 결과
