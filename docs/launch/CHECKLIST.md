# 출시 전 할 일 한 장 표

> **초안 — 법률·세무 검토 필요.** 라이브지니를 판매자 여럿에게 열기 전에 운영자(틈)가 할 일을 **오래 걸리는 것부터** 모았습니다. 기간·비용은 대략이고 회사 사정에 따라 바뀝니다 — 숫자 옆에 **[확인 필요]**가 있으면 공식 안내를 꼭 다시 보세요.
>
> 작성: 2026-10-25 · 함께 볼 문서: `docs/OWNER-GUIDE.md`(자세한 방법), `docs/DEPLOY.md`(서버 설정), 이 폴더의 `GOOGLE-OAUTH-VERIFICATION.md`·`KAKAO-NAVER-LOGIN.md`·`PRIVACY-POLICY-GAPS.md`
>
> 담당: **사장님** = 운영자 본인 · **개발** = 개발 쪽(코드·서버 작업) · **전문가** = 변호사·세무사·변리사

## 2. 추천 진행 순서 (주 단위)

```
1주차  상표 검색(1) → 도메인(15) → 서버 업체(16) → 개발: 서버 올리기·소개 화면(6)
       동시에: 법률 검토 의뢰(7), 세무 상담 예약(9), NIIMBOT 문의(21)
2주차  서치 콘솔 도메인 확인 → 구글 브랜드 확인(4) · 카카오 등록(17) · 네이버 등록(11, 테스트 아이디로)
       통신판매업 변경신고(12) · 포트원 가입·PG 신청(5) · 팝빌 신청(13) · 우체국 계약 문의(8)
       메타 앱 만들기·비즈니스 인증 시작(3)
       실제 테스트 방송(HG-3, 사장님 계정 = 구글 테스트 사용자)
3주차  법률 검토 결과로 방침·약관 고침 → 구글 민감 권한 신청(4) · 메타 검수 신청(3) · 네이버 검수(11)
       크롬 웹 스토어 등록(10, 감사 자동 게시 판단 뒤)
4주차~ 구글 승인 → 프로덕션 게시 → 판매자 여럿에게 열기
       사용량 보고 유튜브 할당량 신청(2)
```

## 3. 바로 알아 둘 것 (문서끼리 다른 곳)

- **인스타그램 웹훅 주소**: 코드·DEPLOY는 `https://<도메인>/webhooks/instagram`, OWNER-GUIDE 7장 5는 `/api/instagram/webhook` — **코드가 맞습니다**(`apps/server/src/instagram/routes.ts`). 메타에는 `/webhooks/instagram`을 넣으세요. (OWNER-GUIDE는 이 작업 범위 밖이라 고치지 않았습니다.)
- **구글 로그인 권한**: 코드는 `openid email`만 묻습니다. OWNER-GUIDE 5장 4의 `profile`은 동의 화면에 넣지 마세요.
- **구글 테스트 상태**: 유튜브 연결 토큰이 7일마다 끊깁니다 — 테스트 방송은 연결한 지 7일 안에.
