# 사장님이 직접 하실 일 — 자세한 안내

> **이 문서는 라이브지니를 운영하는 쪽(틈)용입니다. 판매자 사장님들은 이 일을 하지 않습니다.**
> 키 발급·앱 등록·구글/메타 심사·결제 계약은 운영자가 **한 번만** 하면 되고,
> 판매자는 라이브지니 설정에서 **[구글로 유튜브 연결하기]·[인스타그램 연결하기] 버튼 → 계정 선택 → 허용**만 하면 됩니다(카카오 로그인 수준).


> 라이브찜을 실제로 열기 위해 **사장님만 할 수 있는 일**(사업 서류, 외부 회사 계정·계약, 법률 검토)을 순서대로 정리했습니다.
> 화면 이름·수수료·기간은 회사 사정에 따라 바뀔 수 있습니다. 각 단계의 **공식 안내를 최종 기준**으로 삼아 주세요. 확실하지 않은 곳은 "확인 필요"라고 적어 두었습니다.
>
> **주의**: 받은 키·비밀번호·인증서는 대화창에 붙여 넣지 마세요. 서버의 환경 변수 파일(`.env`)에 직접 넣습니다([DEPLOY.md](DEPLOY.md)).

## 1. 사업자등록 ✅ 완료 (2026-10-22, 응용 소프트웨어 업종 추가)

- **어디서**: 국세청 홈택스(hometax.go.kr) → 신청·제출 → 사업자등록 신청(개인)
- **업종**: 응용 소프트웨어 개발·공급 계열 업종코드(앞서 안내한 722000). 홈택스 업종 검색에서 "소프트웨어"로 찾아 설명이 맞는지 한 번 더 확인해 주세요.
- **과세 유형**: 지금 **간이과세자**로 등록됨(2026-10-22 확인). 간이과세자는 매출이 적으면(직전 연도 공급대가 4,800만 원 미만·신규 등) 세금계산서를 발급할 수 없을 수 있어, 요금 증빙은 카드 영수증·현금영수증 위주가 됩니다. 판매자가 세금계산서를 많이 원하거나 매출이 늘면 "간이과세 포기 신고"로 일반과세자 전환을 검토 — **세무사·세무서 확인**.
- **사업장 주소**: 집 주소로 해도 됩니다(임대차계약서 대신 본인 소유·가족 소유 확인 등 홈택스 안내 따름).
- **결과물**: 사업자등록증(PDF) — 이후 거의 모든 단계에서 올립니다.
- **같이 하면 좋은 것**: 사업용 계좌 개설(은행), 사업용 카드 등록(홈택스).

## 2. 통신판매업 신고 ✅ 되어 있음 (2026-03) — 변경 신고만 필요

> 이미 신고되어 있습니다. 도메인을 산 뒤 **변경 신고**로 취급품목(소프트웨어 이용권·화초)과 새 도메인을 추가하세요(정부24 "통신판매업 변경신고" 또는 김천시 담당 부서). 아래는 처음 신고할 때의 안내입니다.


인터넷으로 요금(이용권)을 받으므로 필요합니다. 결제 PG 심사에서도 신고증을 요구합니다.

- **어디서**: 정부24(gov.kr) → "통신판매업 신고" 검색 → 온라인 신청 (또는 관할 시·군·구청)
- **준비물**: 사업자등록증, 신분증. **구매안전서비스 이용 확인증**을 요구하는 경우가 있는데, 요금처럼 현금성 결제가 아닌 카드 결제(PG)만 받는 경우 PG사에서 발급받거나 면제 사유를 적는 방식입니다 — **확인 필요**(신청 화면 안내를 따르세요).
- **비용**: 등록면허세(지역·규모에 따라 연 수만 원 수준) — 고지서로 나옵니다.
- **결과물**: 통신판매업 신고증. 신고번호는 웹사이트 아래쪽 사업자 정보에 적어야 합니다(라이브찜 설정의 사업자 정보에 넣으면 화면에 나옵니다).

## 3. 도메인 + 서버(호스팅)

간편 로그인·유튜브·인스타그램 모두 "돌아오는 주소"를 등록해야 해서 **도메인이 먼저 정해져야** 합니다.

### 3-1. 도메인
- **어디서**: 가비아, 후이즈, Cloudflare 등 (연 1~3만 원대)
- **이름 정하기 전**: 특허청 키프리스(kipris.or.kr)에서 "라이브찜" 같은 이름이 이미 상표로 있는지 확인(9장 참고).
- 정해지면 저에게 도메인만 알려 주세요. 돌아오는 주소(예: `https://도메인/api/auth/google/callback`)를 정확히 뽑아 드립니다.

### 3-2. 서버
라이브찜은 **컨테이너 하나 + PostgreSQL 데이터베이스**로 돌아가게 만들어 두었습니다([DEPLOY.md](DEPLOY.md)). 업체는 아직 정하지 않았습니다(D-001).

| 선택지 | 장점 | 생각할 점 |
|---|---|---|
| 국내 리전 클라우드(AWS 서울, 네이버 클라우드 등) | 개인정보가 **국내에 저장**돼 법적으로 단순 | 설정이 조금 복잡 |
| 해외 간편 호스팅 | 설정이 쉬움 | 개인정보 **국외 이전 고지**가 필요(9장) |

- 처음엔 작은 서버 1대 + 관리형 PostgreSQL이면 충분합니다(월 수만 원대부터 — 업체·사양에 따라 다름).
- 업체를 정하시면 실제 올리는 작업(컨테이너 빌드·배포·HTTPS·백업)은 제가 안내서대로 함께 하겠습니다.

## 4. 결제 — 포트원 + 토스페이먼츠

요금제(이용권) 결제와 환불에 씁니다. 지금은 가짜 결제 서버로 시험 중입니다.

1. **포트원 가입**: portone.io → 회원가입 → 관리자 콘솔
2. **결제대행(PG) 계약 신청**: 콘솔에서 토스페이먼츠 채널 신청(전자결제 신규 신청)
3. **심사 서류**(보통): 사업자등록증, 통신판매업 신고증, 대표자 신분증, 사업용 통장 사본, (법인이면 인감증명 등)
4. **심사에서 보는 웹사이트 조건**(보통): 실제 접속되는 사이트, 상품(이용권)과 **가격이 보이는 화면**, **이용약관·개인정보처리방침·환불 규정**, 화면 아래 **사업자 정보**(상호·대표·사업자번호·통신판매업 신고번호·주소·연락처). → 3장 서버를 먼저 올리고 9장 문서를 넣어야 심사가 수월합니다.
5. **심사 통과 뒤 받는 값** → 서버 환경 변수에 넣기:
   - `PORTONE_STORE_ID`(상점 ID), `PORTONE_CHANNEL_KEY`(채널 키), `PORTONE_API_SECRET`(API 비밀값), `PORTONE_WEBHOOK_SECRET`(웹훅 비밀값)
   - 포트원 콘솔에 웹훅 주소 등록: `https://도메인/api/billing/webhook` (정확한 주소는 배포 때 확인해 드림)
- **수수료**: 카드 결제 수수료(보통 몇 %대)와 초기 등록비 여부는 계약 조건에 따라 다릅니다 — **확인 필요**.

## 5. 구글 — 구글 로그인 + 유튜브 연결

한 구글 클라우드 프로젝트에서 둘 다 씁니다. **로그인에는 유튜브 권한을 묻지 않고**, 유튜브는 설정에서 따로 연결합니다(그렇게 만들었습니다).

1. **프로젝트 만들기**: console.cloud.google.com → 새 프로젝트("livejjim")
2. **API 켜기**: "YouTube Data API v3" 사용 설정
3. **OAuth 동의 화면**(Google Auth Platform → 브랜딩·대상):
   - 사용자 유형: 외부
   - 앱 이름 "라이브찜", 지원 이메일, 로고(선택)
   - **앱 홈페이지·개인정보처리방침·서비스 약관 주소**(3장 도메인 위 페이지)
   - **승인된 도메인**: 내 도메인 — 구글 서치 콘솔(search.google.com/search-console)에서 도메인 소유 확인이 필요합니다.
4. **권한(범위)**:
   - 로그인: `openid`, `email`, `profile` — 민감하지 않아 심사가 가볍습니다.
   - 유튜브: `youtube.readonly`(채팅 읽기), `youtube.force-ssl`(감사 댓글 쓰기) — **민감 권한이라 구글 앱 심사**가 필요합니다. 심사에서는 보통 권한을 왜 쓰는지 설명과 **실제 사용 장면 동영상**(유튜브 연결 → 채팅 → 감사 댓글)을 요구합니다. 심사 전에는 "테스트 사용자"로 등록한 계정(최대 100명)만 쓸 수 있으니, 사장님 계정을 테스트 사용자로 넣어 먼저 써 볼 수 있습니다.
5. **OAuth 클라이언트 만들기**(클라이언트 → 웹 애플리케이션):
   - 승인된 리디렉션 URI: 유튜브용·로그인용 두 개(정확한 값은 도메인이 정해지면 드림)
   - 받은 값: 클라이언트 ID, 클라이언트 보안 비밀 → `LIVEJJIM_GOOGLE_CLIENT_ID`, `LIVEJJIM_GOOGLE_CLIENT_SECRET`, `LIVEJJIM_GOOGLE_REDIRECT_URI` (간편 로그인용 변수 이름은 개발이 끝나면 DEPLOY.md에 추가)
6. **할당량**: 유튜브 API는 하루 기본 할당량이 있어 방송이 많아지면 **할당량 늘리기 신청**(감사 포함)이 필요할 수 있습니다. 처음 한두 판매자는 기본값으로 충분하도록 아껴 쓰게 만들어 두었습니다.
7. **유튜브 정책**: 유튜브 API 서비스 약관상 채팅 원문은 30일 안에 지우도록 되어 있어 그렇게 만들었습니다(30일 봉인). 심사 때 이 설명을 쓸 수 있습니다.

## 6. 카카오·네이버 로그인

지금 개발 중입니다(가짜 서버로 먼저 시험). 실제로 켜려면:

### 카카오
1. developers.kakao.com → 로그인 → 내 애플리케이션 → 애플리케이션 추가(앱 이름 "라이브찜", 사업자명)
2. 앱 설정 → 플랫폼 → **Web 사이트 도메인** 등록(내 도메인)
3. 제품 설정 → **카카오 로그인 활성화** → **Redirect URI** 등록(값은 드림)
4. 동의항목: 닉네임(필수) 정도. **이메일**은 "비즈 앱" 전환(사업자등록번호 필요) 뒤 받을 수 있는 경우가 많습니다 — 라이브찜은 이메일이 없어도 되게 만드는 중입니다.
5. 보안 → **Client Secret** 발급·사용 켜기
6. 받은 값: REST API 키, Client Secret → 서버 환경 변수(이름은 DEPLOY.md에 추가 예정)

### 네이버
1. developers.naver.com → Application → 애플리케이션 등록
2. 사용 API: **네이버 로그인**, 제공 정보: 이름 또는 별명(필수 최소)
3. 로그인 오픈 API 서비스 환경: PC 웹 — **서비스 URL**(내 도메인), **Callback URL**(값은 드림)
4. 받은 값: Client ID, Client Secret
5. **검수 요청**: 처음엔 "개발 중" 상태라 등록한 테스트 아이디만 로그인됩니다. 다른 판매자가 쓰려면 네이버에 검수(서비스 화면 캡처·설명)를 받아야 합니다.

## 6-1. AI 제안 (선택 — Anthropic)

옵션 방송에서 "확인 필요"로 모인 댓글 중 오타(예: `반바지 엠사이즈`)에 **"제안: 21번 반바지 M 1개"**를 붙여 주는 기능입니다. 제안은 주문이 아니라서, 사장님(판매자)이 [이대로 주문]을 눌러야 주문이 됩니다. 틀린 제안은 그냥 두면 아무 일도 없습니다.

- **키가 없어도 됩니다**: 비슷한 글자로 찾는 제안은 무료이고 늘 켜져 있습니다. AI 제안은 키를 넣었을 때만 더해집니다.
- **켜는 법(서버)**: console.anthropic.com 가입 → 결제 수단 등록(선불 크레딧) → **월 사용 한도를 작게 걸기**(예: 1만~3만 원어치) → API 키 만들기 → "AI 키 받았어요"라고만 알려 주세요. 키는 서버 환경 변수 `LIVEJJIM_ASSIST_API_KEY`에 직접 넣습니다([DEPLOY.md](DEPLOY.md) 4-5절).
- **켜는 법(판매자)**: 설정 → "AI 제안" → 안내를 읽고 "위 내용을 읽었고 동의해요"를 체크 → 켜기. 판매자마다 따로 켜고, 언제든 [끄기]로 끕니다. 번호로만 받는 판매자(다육)는 이 칸이 보이지 않습니다.
- **드는 비용 감**: 확인 필요 화면을 열 때 방송마다 한 번만 부르고, 같은 글은 다시 묻지 않습니다. 가장 싼 모델이라 한 번에 **몇 원 수준**입니다. 판매자 한 명은 하루 **20번**, 서버 전체는 하루 **500번**까지만 부릅니다(넘으면 그날은 무료 제안만). 정확한 단가는 Anthropic 요금표를 확인해 주세요.
- **고지 내용**: 켜면 확인 필요 댓글의 글이 AI 회사(Anthropic, 미국)로 보내져 읽힙니다. 닉네임·전화번호는 빼고 보내고, 가격·재고·가게 정보도 보내지 않습니다. 보낸 글은 따로 저장하지 않습니다. 개인정보처리방침에 "AI 제안(선택)" 문장이 들어갑니다 — **국외 이전·처리 위탁 문구는 법률 검토가 필요합니다**(9-1).

## 8-1. 우체국 택배 — 택배 자동 접수 (T1)

지금은 **가짜 택배(시험용)** 로만 접수 흐름을 확인할 수 있고, 실제 택배는 지금처럼 포장 모드에서 "배송 완료"와 송장번호를 손으로 적습니다. 실제로 자동 접수하려면:

1. **우체국 계약 소포 계약**: 가까운 우체국(또는 우체국 소포 계약 안내)에서 계약 소포를 맺고 **고객 번호**(계약 번호)와 **연동(API) 신청**으로 받은 키를 받습니다. 요금(상자 크기별 계약 요금)·방문 접수 조건은 **확인 필요**(우체국 안내).
2. **고객 번호**는 라이브찜 설정 "택배"의 고객 번호 칸에 직접 넣습니다(화면에는 끝 4자리만 보입니다). **연동 키**는 대화창에 붙이지 말고 "우체국 키 받았어요"만 알려 주세요 — 그 뒤 실제 응답을 보고 우체국 연결을 만들어 켭니다(`LIVEJJIM_EPOST_API_KEY` 자리는 지금 비워 둡니다).
3. **운송장 양식 승인**: 라이브찜의 운송장(100×150mm PDF, 바코드·받는 분 연락처 가림)이 우체국 표준 양식으로 인정되는지 우체국에 확인하고, 다르면 양식 견본을 받아 주세요.
4. **100×150 라벨 프린터 준비**: 운송장은 일반 프린터(A4에 맞춰 찍기)나 100×150mm(4×6인치) 라벨 프린터로 찍습니다. NIIMBOT B1(폭 50mm)으로는 찍지 않습니다. 찍은 바코드를 택배 기사님 단말기가 읽는지 한 번 확인해 주세요.
5. **개인정보처리방침 문장 검토**: 구매자 링크에서 받는 분·연락처·주소·배송 메모를 받고, 택배사에 넘기고, 주문 날짜 + 30일에 지웁니다 — 이 문장이 들어간 방침 초안(`/privacy`)을 9-1과 함께 검토받아 주세요.
