라이브지니(LiveGenie)는 이렇게 해결합니다
================================================

라이브지니는 전산 스탭이 하던 일을 판매자의 휴대폰과 컴퓨터 하나로 대신합니다.
별도 프로그램을 설치하지 않고 크롬에서 주소만 열면 바로 쓸 수 있고(앱처럼 홈 화면에 추가 가능),
판매자가 원래 하던 방송 흐름을 바꾸지 않는 것을 가장 중요한 원칙으로 삼았습니다.


1. 라방 흐름 그대로, 단계마다 자동으로
------------------------------------------------

[1] 상품 소개  →  말로 등록
  - 판매자가 평소처럼 "다음은 15번 상품입니다. 품종은 핑크프릴이고요, 가격은 만 원입니다."라고 말하면,
    음성 인식이 번호·품종·가격을 알아듣고 "15번 핑크프릴 10,000원 — 등록할까요?" 카드를 띄웁니다.
  - Enter 한 번(또는 설정한 시간 뒤 자동)으로 등록됩니다. 틀렸으면 카드에서 바로 고칩니다.
  - 판매자가 전에 판 품종과 기본 다육 품종 사전으로 비슷한 이름을 바로잡습니다("핑크 프릴" → "핑크프릴").
  - 손으로 치고 싶으면 "15 핑크프릴 10" 한 줄 입력도 됩니다. 방송 전에 미리 등록해 둘 수도 있습니다.
  - 같은 번호로 여러 개를 파는 상품은 개수를 정할 수 있습니다.

[2] 시청자 찜  →  채팅 자동 수집 + 선착순 자동 판정
  - 유튜브 라이브 채팅을 자동으로 받아 "15번 찜", "15", "15번이요" 같은 글을 찜으로 읽습니다.
    인스타그램 라이브 댓글도 함께 받을 수 있고, 틱톡은 베타로 준비되어 있습니다(여러 곳 동시 송출).
  - 가장 먼저 찜한 사람이 1등이 되고, 그다음 사람들은 대기 순번이 됩니다.
  - 1등이 취소하면 다음 대기자에게 자동으로 넘어갑니다(대기자가 없으면 다시 판매 중).
  - 상품을 등록하기 직전(30초 안)에 들어온 찜도 놓치지 않고, 등록하는 순간 먼저 온 순서대로 판정합니다.
  - 한참 전에 소개한 번호를 돌려보기 시청자가 늦게 올려도, 그 상품이 아직 판매 중이면 그대로 찜으로 잡습니다.
    이미 팔린 상품이면 대기 순번으로 들어가 취소가 생기면 이어받습니다.
  - 판매자 개인 문자로 온 주문은 '문자찜'으로 넣습니다. 지금은 화면에서 번호를 넣고,
    판매자가 문자를 보며 "165번 문자찜, 끝자리 1234"라고 말하면 자동으로 들어가는 음성 문자찜을 만들고 있습니다(개발 중).
  - 모든 판정은 사람이 아닌 정해진 규칙이 하므로, 같은 상황이면 늘 같은 결과가 나옵니다(분쟁 예방).

[3] 라벨  →  1등이 정해지는 순간 자동 출력
  - 상품번호·품종·가격·닉네임이 찍힌 라벨이 바로 나옵니다.
  - 전용 프린터를 살 필요가 없습니다. 이미 많이 쓰는 휴대용 라벨 프린터(NIIMBOT B1, Marklife, 바우아토)를
    블루투스나 USB로 연결합니다.
  - 1등이 바뀌면(취소·승계) 새 1등의 라벨이 자동으로 나옵니다. 프린터가 끊기면 화면 위 "다시 연결" 한 번으로
    쌓인 라벨이 순서대로 이어서 나옵니다.
  - 라벨이 필요 없는 판매자는 라벨 기능을 끄고 나머지 기능만 쓸 수 있습니다.

[4] 명세서  →  방송이 끝나는 순간 자동 정리
  - 구매자별 찜 내역, 총액, 배송비(무료 배송 기준 포함), 할인·추가 금액, 날짜, 방송 회차가 자동으로 모입니다.
  - 같은 사람이 유튜브·문자 등 여러 이름으로 산 경우 하나로 합칠 수 있고, 같은 날 여러 회차를 한 묶음으로 정산합니다.
  - 구매자 확인서(PDF·이미지)와 판매대장(엑셀)이 정해진 표준 양식으로 바로 나옵니다.

[5] 감사 채팅  →  자동 게시
  - 1등이 확정되면 "15번 핑크프릴 10,000원 홍길동님 구매 감사합니다." 메시지를 유튜브 채팅에 자동으로 남깁니다
    (판매자가 처음 한 번 동의한 뒤). 인스타그램은 구매자에게 감사 메시지(DM)를 보냅니다.
  - 짧은 시간에 여러 건이 확정되면 묶어서 올려 채팅창을 도배하지 않습니다.

[6] 영수증·주소  →  방송 직후 바로 링크로
  - 방송이 끝나면 "영수증 보내기" 화면에서 구매자마다 영수증 링크를 바로 만들 수 있습니다.
    판매자는 그 링크를 문자·카카오톡으로 보내기만 하면 됩니다. 밤늦게 끝난 방송도 다음 날 아침까지 기다릴 필요가 없습니다.
  - 구매자는 링크에서 구매 품목·금액·입금 계좌를 확인합니다.
  - 같은 링크에서 받는 사람·주소를 직접 입력받는 기능을 만들고 있습니다(개발 중, 택배 자동 접수와 함께).

[7] 입금 확인·포장·발송  →  체크리스트 대신 자동 대조
  - 은행 앱의 입금 내역을 복사해 붙여 넣으면, 금액과 입금자명이 맞는 구매자를 자동으로 찾아 입금 완료로 표시합니다.
    애매한 건은 판매자가 확인만 누르면 됩니다(은행 계좌 자동 조회 연동도 준비되어 있습니다).
  - 포장 모드: 휴대폰에서 구매자별로 담아야 할 상품 번호를 크게 보여 주고 하나씩 체크하며 포장합니다.
  - 택배 자동 접수: 입금·포장이 끝난 묶음을 한 번에 택배사에 접수하고 송장번호와 운송장을 받아,
    구매자 영수증 링크에서 배송 조회까지 이어지게 만들고 있습니다(개발 중, 실제 연결은 택배사 계약 필요).


2. 전산 스탭의 단점을 이렇게 풉니다
------------------------------------------------

[일정을 맞춰야 함]
  - 사람이 아니라 프로그램이므로 일정을 잡을 필요가 없습니다. 급방이 잡혀도, 라방이 취소돼도 판매자 혼자 바로 시작하고 끝냅니다.
  - 리허설(연습 방송)은 언제든 무료로 해 볼 수 있습니다.

[비용이 비쌈]
  - 기본 10만 원 + 시간당 2만 원 대신, 월정액(정액제)과 방송한 날만 쓰는 방송 일권 중에서 고릅니다.
    (제안가: 정액제 월 2.9만 원, 방송 일권 9,900원 — 가격은 출시 전 확정)
  - 방송 시간이 길어져도 추가 요금이 없습니다. 방송 중에 이용권이 떨어져도 그 방송은 끝까지 그대로 진행됩니다.
  - 전용 프린터 구매가 필요 없습니다.

[사람마다 양식이 다름]
  - 라벨, 영수증(확인서), 명세서, 판매대장이 늘 같은 표준 양식으로 나옵니다.
  - 입금 확인 체크리스트를 따로 부탁할 필요가 없습니다. 입금 확인 화면 자체가 체크리스트입니다.
  - 필요한 자료는 판매자가 직접, 언제든 엑셀·PDF·이미지로 내려받습니다.

[즉각적이지 않음]
  - 찜이 들어오는 순간 판정·라벨·감사 메시지가 처리되고, 방송이 끝나는 순간 정산과 영수증이 준비됩니다.
  - 모든 화면(PC·휴대폰·보조 기기)에 1초 안에 같은 내용이 반영됩니다.


3. 다육이를 넘어 라벨이 필요한 모든 라방으로
------------------------------------------------

  - "상품명·옵션도 받기" 판매 방식을 켜면 번호뿐 아니라 상품 이름과 옵션이 담긴 댓글도 알아듣습니다.
      예) "반바지 M" → 사이즈 M / "초코 과자 3" → 수량 3 / "아이폰 17 프로" → 기종 / "흰색 대형 2개" → 색·크기·수량
  - 옵션(사이즈·색·기종 등)마다 재고와 선착순을 따로 관리하고, 남은 수량보다 많이 주문하면 일부만 확정하지 않고 확인을 받습니다.
  - 오타·애매한 댓글은 자동으로 정하지 않고 "확인 필요"에 모아 두어, 판매자가 방송 뒤 바로잡거나 주문 아님으로 처리합니다.
  - 업종 템플릿(의류 사이즈, 식품 수량, 화분 색·크기, 휴대폰 케이스 기종 등)으로 옵션을 빠르게 등록합니다.
  - 라벨·확인서·판매대장·포장 목록에 옵션과 수량이 함께 표시됩니다("21번 반바지 L 2개").
  - 그래서 반품 특가(종류·유통기한·용량이 제각각), 랜덤 과자 박스, 화분, 옷, 수공예품, 재고 정리 방송까지
    같은 흐름으로 쓸 수 있습니다. 다육이 판매 방식(번호로만 받기)은 그대로 기본값입니다.


4. 기존 서비스와 비교
------------------------------------------------

  도움봇
    - 전용 프린터 45만 원 필요         → 라이브지니: 쓰던 휴대용 라벨 프린터 그대로(추가 장비 0원)
    - 회당 결제만(AI 하루 4만 원~)    → 라이브지니: 월정액과 방송 일권 중 선택
    - 늦게 올라온 과거 번호 주문 놓침  → 라이브지니: 판매 중이면 몇 분 뒤에 와도 찜으로 처리, 팔렸으면 대기로

  라방ERP + 위잉치킨
    - 설치 80만 원 + 월 18.7만 원     → 라이브지니: 설치비 없음
    - 취소 시 다음 대기자 자동 승계 없음 → 라이브지니: 취소하면 다음 대기자에게 자동으로 넘기고 라벨까지 다시 출력

  PAYGENT / 라이브마켓
    - 라벨 출력 없음                    → 라이브지니: 1등 확정 즉시 라벨 자동 출력
    - 매출에 비례하는 수수료            → 라이브지니: 매출과 상관없는 이용권 방식

  LiveChatOrder
    - 사람이 채팅을 골라 주문으로 등록  → 라이브지니: 채팅을 자동으로 읽고 자동으로 판정(사람 조작 없음)
    - 월 20만 원 고정비                 → 라이브지니: 그보다 훨씬 낮은 월정액(제안가)

  LiveOrder
    - 라벨 출력 없음                    → 라이브지니: 라벨 자동 출력 + 라벨 없이 쓰는 모드도 지원


5. 믿고 맡길 수 있게 만든 장치
------------------------------------------------

  - 입력 우선 기록: 들어온 채팅·조작은 판정하기 전에 먼저 저장하므로, 문제가 생겨도 기록을 다시 재생해 그대로 복원합니다.
  - 돈과 순서는 규칙이 정합니다: 금액은 원 단위 정수로만 계산하고, 선착순 판정은 언제나 같은 결과가 나오는 규칙으로 합니다.
    AI는 말 알아듣기처럼 입력을 돕는 데만 씁니다.
  - 실수 되돌리기: 등록·취소 같은 조치는 몇 초 동안 되돌릴 수 있습니다.
  - 개인정보 보호: 구매자 전화번호·주소는 암호화해 저장하고 기록(로그)에 남기지 않습니다.
    유튜브 채팅 원문은 정책에 맞춰 30일 뒤 지우고 판매 장부만 남깁니다.
  - 매일 자동 백업과 복구를 제공합니다.
  - 연습 모드: 실제 유튜브 계정이나 프린터 없이도 처음부터 끝까지 따라 해 보며 익힐 수 있습니다.
  - 판매자가 혼자 운영하는 것을 기본으로 하되, 필요하면 가족·직원에게 일부 권한만 주는 보조자 계정을 만들 수 있습니다.

* 표시 안내: '개발 중'이라고 적은 기능(음성 문자찜, 택배 자동 접수와 주소 입력)은 현재 만들고 있는 기능입니다.
  가격은 제안가이며, 결제·외부 플랫폼(유튜브·인스타그램·택배사) 실제 연결은 각 회사 심사·계약 뒤 열립니다.
