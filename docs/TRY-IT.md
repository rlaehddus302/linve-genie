# 라이브찜 직접 해 보기 (연습 모드)

내 맥북에서 라이브찜을 켜고 상품 등록부터 포장까지 처음부터 끝까지 따라 해 보는 안내입니다.

- **연습 모드**는 진짜 유튜브·진짜 프린터·진짜 돈과 연결되지 않습니다.
  - 유튜브는 **가짜 유튜브**(연습 채널, "연습 라이브")를 씁니다.
  - 프린터는 **시험용 프린터**를 씁니다. 종이는 나오지 않고 화면에만 "출력됨"으로 적힙니다.
  - 입금은 은행 거래내역을 **붙여넣는 연습**을 합니다.
- 인스타그램·틱톡·계좌 자동 연동(팝빌)·요금 결제는 연습 모드에 없습니다.
- 연습 기록은 끄면 **모두 지워집니다**. 마음껏 눌러 보세요.

---

## 1. 준비물 (처음 한 번만)

준비물은 맥북, 같은 와이파이에 연결된 휴대폰(있으면), 개발 쪽에서 받은 **라이브찜 폴더**입니다.
압축 파일로 받았다면 더블클릭해서 풀어 두세요.

### 1-1. 터미널 열기

**터미널**은 글자로 명령을 넣는 맥 기본 앱입니다.
`Command(⌘) + Space`를 누르고 `터미널`을 입력한 뒤 Enter를 누르세요.

아래부터 `회색 상자` 안의 글자는 터미널에 그대로 입력하고 Enter를 누르면 됩니다.

### 1-2. Node 확인하기

```
node -v
```

- `v24.`로 시작하는 숫자(예: `v24.20.0`)가 나오면 다음으로 넘어가세요.
- `command not found`가 나오거나 숫자가 24보다 작으면 Node를 설치해야 합니다.
  1. 사파리에서 **nodejs.org**를 엽니다.
  2. **24**로 시작하는 LTS 버전의 macOS 설치 파일(.pkg)을 받습니다.
  3. 받은 파일을 더블클릭하고 "계속"을 눌러 설치합니다.
  4. 터미널을 닫았다가 다시 연 뒤 `node -v`를 다시 확인합니다.

### 1-3. pnpm 켜기

pnpm은 라이브찜을 설치하고 켜 주는 도구입니다.

```
sudo corepack enable
```

- `Password:`가 나오면 **맥 로그인 비밀번호**를 입력하고 Enter를 누르세요.
  입력하는 동안 화면에 글자가 보이지 않는 것이 정상입니다.

아래 명령으로 확인합니다.

```
pnpm -v
```

- 처음에 `Do you want to continue? [Y/n]`가 나오면 `Y`를 누르고 Enter를 누르세요.
- `12.`로 시작하는 숫자가 나오면 됩니다.

### 1-4. 라이브찜 폴더로 들어가서 설치하기

1. 터미널에 `cd `를 입력합니다. **cd 뒤에 띄어쓰기 한 칸**을 꼭 넣으세요.
2. Finder에서 **라이브찜 폴더**를 끌어다 터미널 창에 놓습니다. 폴더 위치가 자동으로 입력됩니다.
3. Enter를 누릅니다.
4. 이제 설치합니다. 몇 분 걸릴 수 있습니다.

```
pnpm install
```

마지막에 빨간 `ERR`가 없으면 설치가 끝난 것입니다.

## 2. 켜기

라이브찜 폴더에 들어간 터미널에서 아래 명령을 입력합니다.
터미널을 새로 열었다면 1-4의 1~3번(`cd` 후 폴더 끌어 놓기)을 먼저 하세요.

```
pnpm try
```

처음에는 1~2분 걸립니다. 다 켜지면 이런 안내가 나옵니다.

```
 라이브찜 연습 모드가 켜졌어요. (끄려면 이 창에서 Control + C)

 1) 이 컴퓨터 크롬에서 열기 : http://localhost:7700
    아이디   : practice
    비밀번호 : (켤 때마다 새로 만든 글자)

 2) 연습용 시청자 채팅     : http://localhost:7700/_try/chat

 3) 같은 와이파이 휴대폰  : https://192.168.○.○:7701
```

- **비밀번호는 켤 때마다 바뀌고 이 터미널 창에만 보입니다.** 어디에 적어 둘 필요가 없습니다.
- 숫자 7700은 컴퓨터 사정에 따라 7702, 7704처럼 바뀔 수 있습니다. **터미널에 나온 주소를 그대로** 쓰세요.
- 맥에 "node가 들어오는 네트워크 연결을 허용하겠습니까?" 창이 뜨면 **허용**을 누르세요. 휴대폰 접속에 필요합니다.
- **터미널 창은 끄지 말고 그대로 두세요.** 창을 닫으면 라이브찜도 꺼집니다.

## 3. 따라 해 보기

맥에서는 **크롬**으로 여는 것이 가장 확실합니다.

### 3-1. 로그인

1. 크롬 주소창에 `http://localhost:7700`을 입력합니다.
2. 아이디 칸에 `practice`를 넣고, 비밀번호 칸에는 **터미널에 나온 비밀번호**를 넣습니다.
3. **로그인**을 누릅니다.

→ **시작 마법사** 화면이 나오고, 단계 목록(1/5 가게 이름 ~ 5/5 리허설 해 보기)이 보입니다.

### 3-2. 시작 마법사

1. **1/5 가게 이름**: "연습 가게"가 이미 들어 있습니다. 원하면 바꾸고 **다음**을 누르세요.
2. **2/5 판매 규칙 확인**: 대기 인원, 가격 단위(천원: 10이라고 쓰면 10,000원), 기본 배송비(4,000원) 같은 규칙이 보입니다. **다음**을 누르세요.
3. **3/5 유튜브 연결**
   1. **구글로 유튜브 연결하기**를 누릅니다. 진짜 구글 대신 가짜 유튜브로 잠깐 다녀옵니다.
   2. → "유튜브 채널을 연결했어요." "연결한 채널: **연습 채널**"이 보입니다.
   3. **다음**을 누릅니다.
4. **4/5 프린터 연결**
   1. **시험용 프린터 — 실제로 출력되지 않아요**를 누릅니다. → "이 기기의 프린터: **연결됨** (시험용 프린터)"가 보입니다.
   2. **테스트 인쇄**를 누릅니다. → "테두리와 한글이 또렷하게 보이나요?"라고 물으면 **예**를 누릅니다.
   3. **이 기기에서 출력**을 누릅니다. → "**이 기기가 출력 기기예요**"가 보입니다.
   4. **다음**을 누릅니다.
5. **5/5 리허설 해 보기**: **리허설 시작하기**를 누릅니다.

> 화면을 새로 고치면 시험용 프린터 연결이 끊깁니다. 그러면 화면 위쪽 "출력 멈춤" 옆의 **다시 연결**을 한 번 누르세요.
> 쌓여 있던 라벨이 순서대로 나옵니다.

### 3-3. 리허설 (연습 중의 연습)

화면 위에 "리허설 중 — 실제 판매가 아니에요"가 보입니다.
리허설은 정산·포장에 들어가지 않는, 손에 익히기 위한 방송입니다.

1. **빠른 입력** 칸에 `1 하월시아 15`를 쓰고 Enter를 누릅니다(번호, 품종, 가격 순서).
   - → 상품 보드에 "1번 하월시아 15,000원 판매 중"이 생깁니다.
   - 몇 초 동안 **되돌리기** 버튼이 보입니다. 잘못 넣었을 때 누르면 됩니다.
2. 오른쪽 **리허설 조작판**의 "시청자로 보내기"를 씁니다. 닉네임에 `초록이`, 채팅 한 줄에 `1번 찜`을 넣고 **시청자로 보내기**를 누릅니다.
   - → 채팅에 "1번 1등"이 붙고, 보드가 "1등 초록이"로 바뀝니다.
   - 같은 방법으로 다른 닉네임이 `1번 찜`을 보내면 "대기 1번"이 됩니다.
3. 원하면 **가짜 채팅 시작**을 눌러 가짜 채팅이 저절로 쏟아지는 것도 구경해 보세요.
4. 다 했으면 **방송 끝내기** → **끝내기**를 누르고, **방송 목록**을 누릅니다.

### 3-4. 연습 방송 시작하기 (정산까지 이어지는 방송)

1. 방송 목록에서 **새 방송 시작**을 누릅니다.
2. 제목에 `연습 방송`을 쓰고 **이 방송 시작하기**를 누릅니다.
3. 오른쪽 **유튜브** 칸에서 **내 라이브 목록에서 고르기**를 누릅니다.
4. **연습 라이브 (방송 중)**를 고르고 그 아래 **이 방송에 잇기**를 누릅니다.
   - → "**채팅을 받는 중**"이 보이면 성공입니다.
5. 빠른 입력으로 상품 세 개를 등록합니다. 한 줄씩 쓰고 Enter를 누르세요.
   - `1 하월시아 15`
   - `2 에케베리아 8`
   - `3 리톱스 5`

### 3-5. 시청자 채팅으로 찜 받기 (선착순)

1. 위쪽에 "출력 멈춤"이 보이면 프린터부터 다시 연결합니다.
   1. 메뉴 **라벨**을 누릅니다.
   2. **시험용 프린터 — 실제로 출력되지 않아요**를 누릅니다.
   3. **이 기기에서 출력** 버튼이 보이면 누르고, "출력 기기 바꾸기"가 나오면 **바꾸기**를 누릅니다.
   4. 메뉴 **방송** → **연습 방송**으로 돌아갑니다.
2. 크롬에서 새 탭(`Command + T`)을 열고 `http://localhost:7700/_try/chat`을 엽니다. **연습용 시청자 채팅** 화면입니다.
3. "여러 사람이 한꺼번에 찜"에서 상품 번호 `1`, 몇 명 `3`을 넣고 **한꺼번에 찜 보내기**를 누릅니다.
4. "한 사람이 채팅 쓰기"에서 시청자 하나를 고르고 `2번 찜`을 쓴 뒤 **채팅 보내기**를 누릅니다.
5. 라이브찜 탭으로 돌아갑니다.
   - → 채팅 칸에 "1번 1등", "1번 대기 1번", "1번 대기 2번"이 붙습니다. 가장 먼저 온 사람이 1등입니다.
   - → 상품 보드의 1번·2번이 "판매 완료"로 바뀌고 1등 이름이 보입니다.

### 3-6. 라벨 (시험용 프린터)

1등이 정해지면 라벨이 저절로 출력됩니다.

1. 메뉴 **라벨**을 누릅니다.
2. → **출력 이력**에 "1번 · (1등 이름) 라벨 출력됨"이 보입니다. 종이는 나오지 않습니다.
3. 아직 **출력 대기열**에 남아 있다면 3-5의 1번처럼 프린터를 다시 연결하세요.

### 3-7. 문자찜 넣기

문자(카톡)로 받은 주문을 손으로 넣는 화면입니다.

1. 메뉴 **문자찜 입력**을 누릅니다. "고른 방송: 연습 방송 · 진행 중"이 보입니다.
2. 번호 칸에 `3`, 메모 칸에 `김씨`를 넣습니다. 전화번호는 비워 두어도 됩니다.
3. **문자찜 넣기**를 누릅니다.
   - → "3번 · 문자찜(김씨) · **1등**"이 보입니다.

### 3-8. 정산

1. 메뉴 **정산**을 누릅니다.
2. → 구매자마다 한 줄씩(이름, 상품 합계, 배송비 4,000원, 최종 금액, **미입금**)이 보입니다.
3. 이름을 누르면 품목과 "상품 합계 + 배송비 = 최종"이 자세히 나옵니다.

### 3-9. 입금 확인

1. 메뉴 **입금 확인** → **붙여넣기** 탭을 누릅니다.
2. **입금 내역** 칸에 아래처럼 적습니다.
   - 첫 줄은 꼭 이대로 씁니다.
   - 둘째 줄부터 날짜와 시각은 **지금 시각**으로 쓰고, 이름·금액은 정산 화면에서 본 대로 바꿉니다.

   ```
   거래일시,입금자명,입금액
   2026-10-22 13:05,꽃집언니,19000
   2026-10-22 13:05,김씨,9000
   2026-10-22 13:05,이영희,12000
   ```

   - 줄마다 넣는 것:
     - 첫째 줄: 시청자 1등 이름과 그 사람의 최종 금액
     - 둘째 줄: 문자찜 메모(김씨)와 그 금액
     - 셋째 줄: 일부러 **다른 이름**(이영희)과 다른 1등의 금액
3. **읽어 보기**를 누르면 읽은 입금 3건이 표로 보입니다. **입금 내역 넣기**를 누릅니다.
   - → "새 입금 3건 — 자동 확인 2건, 확인 필요 1건"이 나옵니다. 이름과 금액이 꼭 맞는 입금은 저절로 맞춰집니다.
4. **확인 필요** 탭을 누릅니다.
   - → "금액은 맞는데 이름이 달라요"와 맞을 것 같은 구매자가 보입니다.
   - **확정**을 누르고, 다시 나오는 창에서 **확정**을 누릅니다.
5. 메뉴 **정산**으로 갑니다.
   - → "미입금 0 · 입금 완료 3"이 보입니다.

### 3-10. 구매 내역 확인서 (영수증)

1. 정산 화면에서 구매자 이름을 누릅니다.
2. 아래쪽 **구매 내역 확인서**에 미리 보기가 나타날 때까지 몇 초 기다립니다.
3. **PDF 내려받기**를 누르면 `확인서-날짜-이름.pdf` 파일이 내려받아집니다.
   - 구매자에게 보내는 확인서입니다.
   - 같은 화면에서 **포장 라벨 출력**과 **PDF로 저장**도 해 볼 수 있습니다.
4. 정산 목록 위의 **전원 확인서 PDF**와 **판매대장 엑셀**도 눌러 보세요.

### 3-11. 포장

1. 메뉴 **포장**을 누릅니다.
   - → "포장할 것" 탭에 "상품 1개 포장 대기"가 보입니다.
2. 구매자 하나를 누릅니다.
3. **담을 상품**의 체크 칸에 모두 체크합니다. 실제 상자에 담았다는 뜻입니다.
4. **포장 완료**를 누릅니다.
   - → "포장 완료로 적었어요."가 보입니다.
   - 이어서 **배송 완료로 적기**와 **다음 구매자**도 눌러 보세요.

### 3-12. 옵션 방송 해 보기 (의류·식품·휴대폰 케이스)

다육이는 "1번 찜"처럼 번호로 받습니다.
옷·과자·폰케이스는 시청자가 `반바지 M`, `초코 과자 3`처럼 **상품 이름·옵션·수량**으로 씁니다.
이런 방송은 판매 방식을 **상품명·옵션도 받기**로 고르고 시작합니다.

- 3-2 시작 마법사(유튜브 연결·시험용 프린터)를 마친 뒤에 하세요.
- 3-4의 연습 방송이 "진행 중"이면 먼저 그 방송 화면에서 **방송 끝내기** → **끝내기**를 누르세요.
  가짜 유튜브 "연습 라이브"는 한 번에 한 방송에만 이어집니다.
- 판매 방식은 방송마다 고릅니다. 다음 방송은 다시 "번호로만 받기"가 기본입니다.

#### 1) 옵션 방송 시작하기

1. 메뉴 **방송** → **새 방송 시작**을 누릅니다.
2. **판매 방식**에서 **상품명·옵션도 받기 (의류·식품·케이스 등)**를 고릅니다.
3. 제목에 `옷·간식 방송`을 쓰고 **이 방송 시작하기**를 누릅니다.
   - → 제목 아래에 "**상품명·옵션도 받기**"가 보입니다.
   - → "지금 상품 없음 — 상품 이름을 쓴 댓글만 받아요"가 보입니다.
4. 3-4의 3~4번처럼 유튜브를 잇습니다.
   1. **내 라이브 목록에서 고르기**를 누릅니다.
   2. **연습 라이브 (방송 중)**를 고르고 **이 방송에 잇기**를 누릅니다.
   - → "**채팅을 받는 중**"이 보이면 됩니다.

> 같은 창의 **이 판매 방식으로 리허설 시작**을 누르면 옵션 리허설이 됩니다.
> 리허설은 유튜브와 이어지지 않습니다. 그래서 아래 4)의 연습용 시청자 채팅 대신 오른쪽 **리허설 조작판**의 "시청자로 보내기"로 같은 글을 보냅니다.

#### 2) 업종 템플릿으로 옵션 상품 등록하기

옵션은 Enter를 누르기 **전에** 붙입니다.
순서는 늘 같습니다.
1. 빠른 입력 칸에 번호·품종·가격을 씁니다.
2. 옆의 **옵션 추가**를 누르고 옵션을 채운 뒤 **옵션 넣기**를 누릅니다.
3. 빠른 입력 칸에서 Enter를 누릅니다.

옵션 추가 창에는 **옵션별 재고** 표가 있습니다. 옵션마다 재고 칸이 하나씩 있고, 처음에는 모두 1입니다.

**의류 — 반바지 (사이즈 S·M·L)**

1. 빠른 입력에 `21 반바지 10`을 씁니다.
2. **옵션 추가** → **템플릿에서 고르기** → **의류**의 **사이즈**를 누릅니다.
   - → 선택지 S·M·L·XL이 채워집니다.
3. 넷째 선택지(XL) 줄의 **빼기**를 누릅니다.
4. 옵션별 재고 표에서 S 재고 `3`, M 재고 `1`, L 재고 `2`를 넣습니다.
   - → 창 아래에 "옵션: 사이즈 S/M/L · 변형 3개"가 보입니다.
5. **옵션 넣기**를 누릅니다.
   - → 빠른 입력 아래에 "Enter로 등록하면 함께 들어가요"가 보입니다.
6. 빠른 입력 칸을 누르고 Enter를 누릅니다.
   - → 상품 보드에 "21번 반바지 10,000원 판매 중 · 1등 변형별 · 변형 3개 · 남은 6"이 생깁니다.
   - → 위쪽에 "**지금 상품: 21번 반바지**"가 보입니다.

**식품 — 초코 과자 (수량으로 사는 상품)**

옵션이 없는 상품은 재고가 1개입니다.
과자처럼 여러 개를 파는 상품은 선택지 하나짜리 옵션을 만들어 재고를 넣습니다.

1. 빠른 입력에 `11 초코 과자 2`를 쓰고 **옵션 추가**를 누릅니다.
2. **상품 별칭** 칸에 `초코`를 씁니다. 댓글에 "초코 2개"라고 써도 알아듣습니다.
3. **항목 더하기**를 누르고 **항목 이름**에 `구성`, **선택지**에 `1봉`을 씁니다.
4. 옵션별 재고 표의 1봉 재고에 `5`를 넣고 **옵션 넣기**를 누릅니다.
5. Enter를 누릅니다.
   - → "11번 초코 과자 2,000원 · 변형 1개 · 남은 5"가 생깁니다.

**휴대폰 케이스 — 폰케이스 (기종)**

1. 빠른 입력에 `41 폰케이스 12`를 쓰고 **옵션 추가**를 누릅니다.
2. **상품 별칭**에 `케이스`를 씁니다.
3. **템플릿에서 고르기** → **휴대폰 케이스**의 **기종**을 누릅니다.
   - → 아이폰 16 ~ 갤럭시 S25 울트라 여섯 기종이 채워집니다.
   - → "아이폰 17 프로"에는 별칭 "17프로"가 이미 들어 있습니다.
4. **모두 같은 수로** 칸에 `2`를 쓰고 **모두 바꾸기**를 누릅니다.
5. **옵션 넣기** → Enter를 누릅니다.
   - → "41번 폰케이스 12,000원 · 변형 6개 · 남은 12"가 생깁니다.

**옵션 두 개 — 화분 (색상 × 크기)**

1. 빠른 입력에 `31 화분 8`을 쓰고 **옵션 추가**를 누릅니다.
2. **템플릿에서 고르기** → **의류**의 **색상**을 누릅니다.
3. 회색·네이비·베이지는 필요 없습니다. 각 줄의 **빼기**를 눌러 흰색·검정색만 남깁니다.
4. 둘째 옵션을 만듭니다.
   1. **항목 더하기**를 누릅니다.
   2. 새 항목(항목 2)의 **항목 이름**에 `크기`를 씁니다.
   3. 첫 **선택지**에 `소형`을 씁니다.
   4. 항목 2의 **선택지 더하기**를 누르고 `대형`을 씁니다.
   - → 재고 표에 흰색/소형·흰색/대형·검정색/소형·검정색/대형 네 줄이 생깁니다.
5. 흰색/대형 재고에 `3`을 넣고 **옵션 넣기** → Enter를 누릅니다.
   - → 위쪽이 "**지금 상품: 31번 화분**"으로 바뀝니다.
   - → 그 아래 "15초 동안 상품 이름 없는 댓글은 확인 필요로 모아요"가 보입니다.

> **지금 상품**은 가장 나중에 등록한(또는 **지금 상품으로**를 누른) 상품입니다.
> `흰색 대형 2개`처럼 상품 이름 없이 옵션만 쓴 댓글은 지금 상품의 주문으로 읽습니다.
> 지금 상품이 바뀐 뒤 15초 동안은 헷갈리지 않게 "확인 필요"로 보냅니다. 그러니 **15초 넘게 기다린 뒤** 다음으로 가세요.

#### 3) 시청자 채팅 보내기

1. 새 탭에서 `http://localhost:7700/_try/chat`(연습용 시청자 채팅)을 엽니다.
2. "한 사람이 채팅 쓰기"를 씁니다.
   1. 시청자 이름을 고릅니다.
   2. 채팅 내용을 지우고 아래 글을 씁니다.
   3. **채팅 보내기**를 누릅니다.
   - 한 줄씩 보내고, 라이브찜 탭에 그 줄이 나온 뒤 다음 줄을 보내세요. 2~3초면 나옵니다.
   - "여러 사람이 한꺼번에 찜"은 `1번 찜` 같은 번호 글만 보냅니다. 옵션 방송에서는 쓰지 않습니다.

| 시청자 | 채팅 내용 | 라이브찜 채팅 칸에 붙는 것 |
|---|---|---|
| 초록이네 | `반바지 M` | 주문 21번 M → **21번 M 1등** |
| 다육사랑 | `반바지 M` | 주문 21번 M → **21번 M 대기 1번** (M은 1장뿐) |
| 밤톨맘 | `초코 과자 3` | 주문 11번 1봉 ×3 → **11번 1봉 ×3 1등** (3은 수량) |
| 선인장할매 | `케이스 17프로` | 주문 41번 아이폰 17 프로 → **41번 아이폰 17 프로 1등** |
| 꽃집언니 | `흰색 대형 2개` | 주문 31번 흰색/대형 ×2 → **31번 흰색/대형 ×2 1등** (지금 상품) |
| 물주기담당 | `반바지` | **확인 필요 · 옵션 빠짐** (사이즈가 없음) |
| 햇살창가 | `반바지 XL` | **확인 필요 · 모르는 말** (XL은 없는 사이즈) |

- → 콘솔 위쪽에 "**확인 필요 2건**" 버튼이 생깁니다.
- → 상품 보드의 1등이 생긴 상품에 "라벨 출력됨"(프린터가 끊겨 있으면 "라벨 대기")이 붙습니다.
- 애매한 댓글은 주문이 아닙니다. 재고·합계·라벨에 들어가지 않고, 판매자가 고를 때까지 기다립니다.

#### 4) "확인 필요"에서 바로잡기 / 주문 아님

1. 콘솔 위쪽의 **확인 필요 2건**을 누릅니다. 채팅 줄의 "확인 필요에서 고르기"를 눌러도 됩니다.
   - → **확인 필요** 화면에 댓글이 들어온 순서대로 두 줄이 보입니다.
   - 줄마다 시각·이름·사유("옵션 빠짐", "모르는 말")·댓글 글과 상품·사이즈·수량 칸이 있습니다.
   - 상품 칸은 읽은 상품(21번 반바지)으로 미리 골라져 있습니다.
   - 사이즈 칸에는 "S (남은 3개) · M (남은 0개) · L (남은 2개)"처럼 남은 수량이 함께 보입니다.
   - 둘째 줄("반바지 XL")에는 "혹시: L?"이 보입니다.
2. 첫째 줄(물주기담당 "반바지")을 바로잡습니다.
   1. **사이즈**에서 `L`을 고릅니다.
   2. **수량** 칸에 `1`을 씁니다. 처음엔 비어 있으니 꼭 적으세요.
   3. **주문으로**를 누릅니다.
   - → "5초 뒤 보내요: 물주기담당 "반바지" 주문으로"와 **되돌리기**가 보입니다. 5초가 지나면 줄이 사라집니다.
3. 둘째 줄(햇살창가 "반바지 XL")의 **주문 아님**을 누릅니다.
   - → 5초 뒤 "보냈어요: 햇살창가 "반바지 XL" 주문 아님", "확인할 댓글이 없어요."가 보입니다.
   - 여러 줄을 고르는 칸에 체크하고 **고른 줄 주문으로** / **고른 줄 주문 아님**으로 한 번에 처리할 수도 있습니다.
4. **콘솔로**를 누릅니다.
   - → 채팅 칸이 바뀝니다.
     - 물주기담당 줄: "주문 21번 L … **21번 L 1등**"
     - 햇살창가 줄: "언급"
   - 상품 보드의 **21번 반바지**를 누르면 **21번 자세히**가 열립니다. 변형마다 1등·대기가 보입니다.
     - "M · 판매 완료 · 남은 0개 (재고 1)", "M 1등 1명 초록이네", "M 대기 1명 다육사랑"
     - "L · 판매 중 · 남은 1개 (재고 2)", "L 1등 1명 물주기담당"
     - 라벨 칸: "1등 초록이네 M 라벨", "1등 물주기담당 L 라벨"

#### 5) 라벨·확인서·포장에서 옵션·수량 보기

**라벨**

1. 메뉴 **라벨**을 누릅니다.
   - 위쪽에 "출력 멈춤"이 있거나 출력 대기열에 남아 있으면 3-5의 1번대로 시험용 프린터를 다시 연결합니다.
   - 대기열에 "대기 중인 라벨 n장이 있어요"가 보이면 **출력 시작**을 누릅니다.
2. → **출력 이력**에 옵션 글과 수량(2개 이상일 때만)이 붙어 보입니다.
   - "11번 1봉 3개 · 밤톨맘 라벨 출력됨"
   - "21번 M · 초록이네 라벨 출력됨"
   - "21번 L · 물주기담당 라벨 출력됨"
   - "31번 흰색/대형 2개 · 꽃집언니 라벨 출력됨"
   - "41번 아이폰 17 프로 · 선인장할매 라벨 출력됨"

**정산·구매 내역 확인서**

1. 메뉴 **정산**을 누릅니다.
   - → **상품 수**는 수량을 더한 수입니다.
     - 밤톨맘 "3개 · 6,000원"
     - 꽃집언니 "2개 · 16,000원"
     - 나머지는 "1개"
2. **꽃집언니**를 누릅니다.
   - → 품목: "31번 화분 흰색/대형 2개 16,000원"
   - → "상품 합계 16,000원 + 배송비 4,000원 + 조정 0원 = 최종 20,000원"
   - → **포장 라벨** 미리 보기: "31 흰색/대형 ×2", "상품 2개 상품 합계 16,000원"
   - → **구매 내역 확인서** 미리 보기 품종 칸: "화분 흰색/대형 (8,000원 × 2개)", 가격 16,000원, 상품 수 2개
3. **정산 목록으로** → **밤톨맘**을 누릅니다.
   - → 품목: "11번 초코 과자 1봉 3개 6,000원"
   - → 확인서: "초코 과자 1봉 (2,000원 × 3개)"
   - → 포장 라벨: "11 1봉 ×3"

**포장**

1. 메뉴 **포장**을 누르고 **꽃집언니**("상품 2개 · 포장 대기")를 누릅니다.
   - → 담을 상품 줄에 "31번 화분 흰색/대형"과 큰 글씨 "**2개**"가 보입니다.
   - → 아래에 "0/1 담음"이 보입니다. 줄 수를 세므로 2개여도 한 줄입니다.
2. 그 줄의 체크 칸에 체크하고 **포장 완료**를 누릅니다.
   - → "1/1 담음", "포장 완료로 적었어요."가 보입니다.

> 이번 방송을 끝내려면 콘솔에서 **방송 끝내기** → **끝내기**를 누르세요.

### 3-13. 간편 로그인 (카카오·네이버·구글)

연습 모드의 카카오·네이버·구글은 **연습용 가짜 화면**입니다. 진짜 카카오 계정이 필요 없습니다.

1. 메뉴 **설정** → **로그인 방법** 칸에서 카카오 줄의 **연결하기**를 누릅니다.
   - → "연습용 가짜 화면이에요. 실제 카카오가 아니에요."가 위에 보이는 화면이 열립니다.
2. 연습 계정 하나를 고르고 **동의하고 계속하기**를 누릅니다.
   - → 설정 화면으로 돌아오고 "카카오 계정을 연결했어요. 다음부터 "카카오로 계속하기"로 로그인할 수 있어요."가 보입니다.
3. 로그아웃합니다.
4. 로그인 화면 아래 **카카오로 계속하기**를 누르고, 같은 연습 계정을 골라 **동의하고 계속하기**를 누릅니다.
   - → 비밀번호 없이 홈으로 들어옵니다.
   - 다른 연습 계정을 고르면 "이 카카오 계정에 연결된 라이브찜 계정이 없어요…"가 보입니다(가입은 받지 않습니다).
5. 다시 **설정** → **로그인 방법**에서 **연결 끊기**를 누르면 끊깁니다. 아이디 로그인은 그대로입니다.

## 4. 휴대폰으로 열기

휴대폰과 맥북이 **같은 와이파이**에 연결되어 있어야 합니다.

1. 휴대폰 사파리(또는 크롬) 주소창에 터미널의 **3) 같은 와이파이 휴대폰** 주소를 그대로 넣습니다(`https://`로 시작).
2. 처음 한 번 "안전하지 않음" 경고가 나옵니다. 연습용 주소라서 나오는 경고이니 아래처럼 넘어가세요.
   - **아이폰 사파리**
     1. "이 연결은 비공개 연결이 아닙니다"가 나오면 **세부사항 보기**를 누릅니다.
     2. **이 웹 사이트 방문**을 누릅니다.
     3. 한 번 더 물으면 **웹 사이트 방문**을 누릅니다.
   - **안드로이드 크롬**
     1. "연결이 비공개로 설정되어 있지 않습니다"가 나오면 **고급**을 누릅니다.
     2. **…(으)로 이동(안전하지 않음)**을 누릅니다.
3. 같은 아이디(`practice`)와 터미널의 비밀번호로 로그인합니다.
4. 화면 맨 아래에 메뉴 막대가 있습니다: **방송 · 문자찜 입력 · 구매자 · 정산 · 더보기**.
   - **더보기**를 누르면 **입금 확인 · 포장 · 라벨 · 설정**이 위로 펼쳐집니다.
5. 휴대폰에서 문자찜을 하나 넣어 보세요. 맥북 화면에도 바로 나타납니다.
   반대로 맥북에서 채팅 찜을 보내면 휴대폰 방송 화면에도 바로 보입니다.

> 휴대폰에서 하지 않는 것:
> - 유튜브 연결은 **맥북에서** 하세요.
> - 출력 기기(프린터)는 맥북 하나로 두는 것이 편합니다.

## 5. 끄는 법

- 터미널 창을 누르고 `Control + C`를 누릅니다.
  → "껐어요. 다시 켜려면 pnpm try"가 나오면 꺼진 것입니다.
- 터미널 창을 그냥 닫아도 꺼집니다.
- 끄면 연습 기록이 모두 지워집니다. 다시 켜면 처음 상태가 되고, 비밀번호도 새로 바뀝니다.

## 6. 문제가 생기면

| 보이는 것 | 할 일 |
|---|---|
| `command not found: pnpm` | 1-3을 다시 하세요. 그래도 안 되면 `pnpm` 대신 `npx pnpm@12.14.0`을 앞에 붙여 실행합니다(예: `npx pnpm@12.14.0 install`, `npx pnpm@12.14.0 try`). |
| `Node 24 이상이 필요해요` | 1-2대로 Node 24를 설치하세요. |
| `먼저 설치가 필요해요` | 라이브찜 폴더에서 `pnpm install`을 한 번 하세요. |
| `화면을 만들지 못했어요` | 그 위에 나온 글자를 사진으로 찍어 개발 쪽에 보내 주세요. |
| 포트 번호가 7700이 아님 | 다른 프로그램이 7700을 쓰고 있어 옆 번호로 옮긴 것입니다. 터미널에 나온 주소를 쓰세요. 번호를 직접 정하려면 `pnpm try --port 8800`처럼 입력합니다. |
| 로그인했는데 다시 로그인 화면이 나옴 (특히 맥 사파리) | 크롬으로 여세요. 사파리를 써야 한다면 `https://localhost:7701`로 열고 4번의 경고 넘기기를 따라 하세요(포트가 바뀌었다면 휴대폰 주소의 끝 번호를 씁니다). |
| 비밀번호를 모르겠음 | 켜 둔 터미널 창에 있습니다. 창을 닫았다면 다시 켜고 새 비밀번호를 쓰세요. |
| 위쪽에 "출력 멈춤" 또는 "끊김" / 라벨이 "대기"에 머묾 | 3-5의 1번대로 시험용 프린터를 다시 연결하고 **이 기기에서 출력**을 누르세요. 유튜브 연결 뒤나 화면을 새로 고친 뒤에 생깁니다. |
| 시청자 채팅을 보내도 방송 화면에 안 나옴 | 3-4의 3~4번대로 방송 화면 유튜브 칸이 "채팅을 받는 중"인지 보세요. **리허설 방송**은 유튜브와 이어지지 않습니다. |
| 휴대폰에서 주소가 안 열림 | 같은 와이파이인지 보세요. 맥북이 잠자기 상태가 아닌지 보세요. 맥의 "들어오는 연결 허용" 창에서 **허용**을 눌렀는지도 보세요. 와이파이를 바꿨다면 라이브찜을 껐다 켜고 새 주소를 쓰세요. |
| 입금 붙여넣기에서 "표의 첫 줄(거래일시·입금액 같은 칸 이름)을 함께 붙여 넣어 주세요." | 첫 줄 `거래일시,입금자명,입금액`을 꼭 넣으세요. |
| 입금이 "확인 필요"로 가지 않고 맞춰지지도 않음 | 날짜·시각이 판매보다 이르면 맞추지 않습니다. 지금 시각으로 적으세요. |
