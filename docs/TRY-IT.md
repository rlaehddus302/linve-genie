# 라이브찜 직접 해 보기 (연습 모드)

내 맥북에서 라이브찜을 켜고 상품 등록부터 포장까지 처음부터 끝까지 따라 해 보는 안내입니다.

- **연습 모드**는 진짜 유튜브·진짜 프린터·진짜 돈과 연결되지 않습니다.
  - 유튜브는 **가짜 유튜브**(연습 채널, "연습 라이브")를 씁니다.
  - 프린터는 **시험용 프린터**를 씁니다. 종이는 나오지 않고 화면에만 "출력됨"으로 적힙니다.
  - 입금은 은행 거래내역을 **붙여넣는 연습**을 합니다.
- 인스타그램·틱톡·계좌 자동 연동(팝빌)·요금 결제는 연습 모드에 없습니다.
- 연습 기록은 끄면 **모두 지워집니다**. 마음껏 눌러 보세요.

---

## 1. 준비물 (처음 한 번만)

준비물은 맥북, 같은 와이파이에 연결된 휴대폰(있으면), 개발 쪽에서 받은 **라이브찜 폴더**입니다.
압축 파일로 받았다면 더블클릭해서 풀어 두세요.

### 1-1. 터미널 열기

**터미널**은 글자로 명령을 넣는 맥 기본 앱입니다.
`Command(⌘) + Space`를 누르고 `터미널`을 입력한 뒤 Enter를 누르세요.

아래부터 `회색 상자` 안의 글자는 터미널에 그대로 입력하고 Enter를 누르면 됩니다.

### 1-2. Node 확인하기

```
node -v
```

- `v24.`로 시작하는 숫자(예: `v24.20.0`)가 나오면 다음으로 넘어가세요.
- `command not found`가 나오거나 숫자가 24보다 작으면 Node를 설치해야 합니다.
  1. 사파리에서 **nodejs.org**를 엽니다.
  2. **24**로 시작하는 LTS 버전의 macOS 설치 파일(.pkg)을 받습니다.
  3. 받은 파일을 더블클릭하고 "계속"을 눌러 설치합니다.
  4. 터미널을 닫았다가 다시 연 뒤 `node -v`를 다시 확인합니다.

### 1-3. pnpm 켜기

pnpm은 라이브찜을 설치하고 켜 주는 도구입니다.

```
sudo corepack enable
```

- `Password:`가 나오면 **맥 로그인 비밀번호**를 입력하고 Enter를 누르세요.
  입력하는 동안 화면에 글자가 보이지 않는 것이 정상입니다.

아래 명령으로 확인합니다.

```
pnpm -v
```

- 처음에 `Do you want to continue? [Y/n]`가 나오면 `Y`를 누르고 Enter를 누르세요.
- `12.`로 시작하는 숫자가 나오면 됩니다.

### 1-4. 라이브찜 폴더로 들어가서 설치하기

1. 터미널에 `cd `를 입력합니다. **cd 뒤에 띄어쓰기 한 칸**을 꼭 넣으세요.
2. Finder에서 **라이브찜 폴더**를 끌어다 터미널 창에 놓습니다. 폴더 위치가 자동으로 입력됩니다.
3. Enter를 누릅니다.
4. 이제 설치합니다. 몇 분 걸릴 수 있습니다.

```
pnpm install
```

마지막에 빨간 `ERR`가 없으면 설치가 끝난 것입니다.

## 2. 켜기

라이브찜 폴더에 들어간 터미널에서 아래 명령을 입력합니다.
터미널을 새로 열었다면 1-4의 1~3번(`cd` 후 폴더 끌어 놓기)을 먼저 하세요.

```
pnpm try
```

처음에는 1~2분 걸립니다. 다 켜지면 이런 안내가 나옵니다.

```
 라이브찜 연습 모드가 켜졌어요. (끄려면 이 창에서 Control + C)

 1) 이 컴퓨터 크롬에서 열기 : http://localhost:7700
    아이디   : practice
    비밀번호 : (켤 때마다 새로 만든 글자)

 2) 연습용 시청자 채팅     : http://localhost:7700/_try/chat

 3) 같은 와이파이 휴대폰  : https://192.168.○.○:7701
```

- **비밀번호는 켤 때마다 바뀌고 이 터미널 창에만 보입니다.** 어디에 적어 둘 필요가 없습니다.
- 숫자 7700은 컴퓨터 사정에 따라 7702, 7704처럼 바뀔 수 있습니다. **터미널에 나온 주소를 그대로** 쓰세요.
- 맥에 "node가 들어오는 네트워크 연결을 허용하겠습니까?" 창이 뜨면 **허용**을 누르세요. 휴대폰 접속에 필요합니다.
- **터미널 창은 끄지 말고 그대로 두세요.** 창을 닫으면 라이브찜도 꺼집니다.

## 3. 따라 해 보기

맥에서는 **크롬**으로 여는 것이 가장 확실합니다.

### 3-1. 로그인

1. 크롬 주소창에 `http://localhost:7700`을 입력합니다.
2. 아이디 칸에 `practice`를 넣고, 비밀번호 칸에는 **터미널에 나온 비밀번호**를 넣습니다.
3. **로그인**을 누릅니다.

→ **시작 마법사** 화면이 나오고, 단계 목록(1/5 가게 이름 ~ 5/5 리허설 해 보기)이 보입니다.

### 3-2. 시작 마법사

1. **1/5 가게 이름**: "연습 가게"가 이미 들어 있습니다. 원하면 바꾸고 **다음**을 누르세요.
2. **2/5 판매 규칙 확인**: 대기 인원, 가격 단위(천원: 10이라고 쓰면 10,000원), 기본 배송비(4,000원) 같은 규칙이 보입니다. **다음**을 누르세요.
3. **3/5 프린터 연결**
   1. **시험용 프린터 — 실제로 출력되지 않아요**를 누릅니다. → "이 기기의 프린터: **연결됨** (시험용 프린터)"가 보입니다.
   2. **테스트 인쇄**를 누릅니다. → "테두리와 한글이 또렷하게 보이나요?"라고 물으면 **예**를 누릅니다.
   3. **이 기기에서 출력**을 누릅니다. → "**이 기기가 출력 기기예요**"가 보입니다.
   4. **다음**을 누릅니다.
4. **4/5 유튜브 연결**
   1. **구글로 유튜브 연결하기**를 누릅니다. 진짜 구글 대신 가짜 유튜브로 잠깐 다녀옵니다.
   2. → "유튜브 채널을 연결했어요." "연결한 채널: **연습 채널**"이 보입니다.
   3. **다음**을 누릅니다.
5. **5/5 리허설 해 보기**: **리허설 시작하기**를 누릅니다.

> 유튜브 연결을 하고 돌아오면 시험용 프린터 연결이 끊깁니다.
> 화면 위쪽에 "출력 멈춤"이나 "끊김"이 보이면 3-5를 시작하기 전에 **라벨** 메뉴에서 다시 연결하세요.
> 연결하는 방법은 3-5의 1번에 있습니다. 화면을 새로 고쳤을 때도 똑같이 하면 됩니다.

### 3-3. 리허설 (연습 중의 연습)

화면 위에 "리허설 중 — 실제 판매가 아니에요"가 보입니다.
리허설은 정산·포장에 들어가지 않는, 손에 익히기 위한 방송입니다.

1. **빠른 입력** 칸에 `1 하월시아 15`를 쓰고 Enter를 누릅니다(번호, 품종, 가격 순서).
   - → 상품 보드에 "1번 하월시아 15,000원 판매 중"이 생깁니다.
   - 몇 초 동안 **되돌리기** 버튼이 보입니다. 잘못 넣었을 때 누르면 됩니다.
2. 오른쪽 **리허설 조작판**의 "시청자로 보내기"를 씁니다. 닉네임에 `초록이`, 채팅 한 줄에 `1번 찜`을 넣고 **시청자로 보내기**를 누릅니다.
   - → 채팅에 "1번 1등"이 붙고, 보드가 "1등 초록이"로 바뀝니다.
   - 같은 방법으로 다른 닉네임이 `1번 찜`을 보내면 "대기 1번"이 됩니다.
3. 원하면 **가짜 채팅 시작**을 눌러 가짜 채팅이 저절로 쏟아지는 것도 구경해 보세요.
4. 다 했으면 **방송 끝내기** → **끝내기**를 누르고, **방송 목록**을 누릅니다.

### 3-4. 연습 방송 시작하기 (정산까지 이어지는 방송)

1. 방송 목록에서 **새 방송 시작**을 누릅니다.
2. 제목에 `연습 방송`을 쓰고 **이 방송 시작하기**를 누릅니다.
3. 오른쪽 **유튜브** 칸에서 **내 라이브 목록에서 고르기**를 누릅니다.
4. **연습 라이브 (방송 중)**를 고르고 그 아래 **이 방송에 잇기**를 누릅니다.
   - → "**채팅을 받는 중**"이 보이면 성공입니다.
5. 빠른 입력으로 상품 세 개를 등록합니다. 한 줄씩 쓰고 Enter를 누르세요.
   - `1 하월시아 15`
   - `2 에케베리아 8`
   - `3 리톱스 5`

### 3-5. 시청자 채팅으로 찜 받기 (선착순)

1. 위쪽에 "출력 멈춤"이 보이면 프린터부터 다시 연결합니다.
   1. 메뉴 **라벨**을 누릅니다.
   2. **시험용 프린터 — 실제로 출력되지 않아요**를 누릅니다.
   3. **이 기기에서 출력** 버튼이 보이면 누르고, "출력 기기 바꾸기"가 나오면 **바꾸기**를 누릅니다.
   4. 메뉴 **방송** → **연습 방송**으로 돌아갑니다.
2. 크롬에서 새 탭(`Command + T`)을 열고 `http://localhost:7700/_try/chat`을 엽니다. **연습용 시청자 채팅** 화면입니다.
3. "여러 사람이 한꺼번에 찜"에서 상품 번호 `1`, 몇 명 `3`을 넣고 **한꺼번에 찜 보내기**를 누릅니다.
4. "한 사람이 채팅 쓰기"에서 시청자 하나를 고르고 `2번 찜`을 쓴 뒤 **채팅 보내기**를 누릅니다.
5. 라이브찜 탭으로 돌아갑니다.
   - → 채팅 칸에 "1번 1등", "1번 대기 1번", "1번 대기 2번"이 붙습니다. 가장 먼저 온 사람이 1등입니다.
   - → 상품 보드의 1번·2번이 "판매 완료"로 바뀌고 1등 이름이 보입니다.

### 3-6. 라벨 (시험용 프린터)

1등이 정해지면 라벨이 저절로 출력됩니다.

1. 메뉴 **라벨**을 누릅니다.
2. → **출력 이력**에 "1번 · (1등 이름) 라벨 출력됨"이 보입니다. 종이는 나오지 않습니다.
3. 아직 **출력 대기열**에 남아 있다면 3-5의 1번처럼 프린터를 다시 연결하세요.

### 3-7. 문자찜 넣기

문자(카톡)로 받은 주문을 손으로 넣는 화면입니다.

1. 메뉴 **문자찜 입력**을 누릅니다. "고른 방송: 연습 방송 · 진행 중"이 보입니다.
2. 번호 칸에 `3`, 메모 칸에 `김씨`를 넣습니다. 전화번호는 비워 두어도 됩니다.
3. **문자찜 넣기**를 누릅니다.
   - → "3번 · 문자찜(김씨) · **1등**"이 보입니다.

### 3-8. 정산

1. 메뉴 **정산**을 누릅니다.
2. → 구매자마다 한 줄씩(이름, 상품 합계, 배송비 4,000원, 최종 금액, **미입금**)이 보입니다.
3. 이름을 누르면 품목과 "상품 합계 + 배송비 = 최종"이 자세히 나옵니다.

### 3-9. 입금 확인

1. 메뉴 **입금 확인** → **붙여넣기** 탭을 누릅니다.
2. **입금 내역** 칸에 아래처럼 적습니다.
   - 첫 줄은 꼭 이대로 씁니다.
   - 둘째 줄부터 날짜와 시각은 **지금 시각**으로 쓰고, 이름·금액은 정산 화면에서 본 대로 바꿉니다.

   ```
   거래일시,입금자명,입금액
   2026-10-22 13:05,꽃집언니,19000
   2026-10-22 13:05,김씨,9000
   2026-10-22 13:05,이영희,12000
   ```

   - 줄마다 넣는 것:
     - 첫째 줄: 시청자 1등 이름과 그 사람의 최종 금액
     - 둘째 줄: 문자찜 메모(김씨)와 그 금액
     - 셋째 줄: 일부러 **다른 이름**(이영희)과 다른 1등의 금액
3. **읽어 보기**를 누르면 읽은 입금 3건이 표로 보입니다. **입금 내역 넣기**를 누릅니다.
   - → "새 입금 3건 — 자동 확인 2건, 확인 필요 1건"이 나옵니다. 이름과 금액이 꼭 맞는 입금은 저절로 맞춰집니다.
4. **확인 필요** 탭을 누릅니다.
   - → "금액은 맞는데 이름이 달라요"와 맞을 것 같은 구매자가 보입니다.
   - **확정**을 누르고, 다시 나오는 창에서 **확정**을 누릅니다.
5. 메뉴 **정산**으로 갑니다.
   - → "미입금 0 · 입금 완료 3"이 보입니다.

### 3-10. 구매 내역 확인서 (영수증)

1. 정산 화면에서 구매자 이름을 누릅니다.
2. 아래쪽 **구매 내역 확인서**에 미리 보기가 나타날 때까지 몇 초 기다립니다.
3. **PDF 내려받기**를 누르면 `확인서-날짜-이름.pdf` 파일이 내려받아집니다.
   - 구매자에게 보내는 확인서입니다.
   - 같은 화면에서 **포장 라벨 출력**과 **PDF로 저장**도 해 볼 수 있습니다.
4. 정산 목록 위의 **전원 확인서 PDF**와 **판매대장 엑셀**도 눌러 보세요.

### 3-11. 포장

1. 메뉴 **포장**을 누릅니다.
   - → "포장할 구매자" 목록에 "상품 1개 포장 대기"가 보입니다.
2. 구매자 하나를 누릅니다.
3. **담을 상품**의 체크 칸에 모두 체크합니다. 실제 상자에 담았다는 뜻입니다.
4. **포장 완료**를 누릅니다.
   - → "포장 완료로 적었어요."가 보입니다.
   - 이어서 **배송 완료로 적기**와 **다음 구매자**도 눌러 보세요.

## 4. 휴대폰으로 열기

휴대폰과 맥북이 **같은 와이파이**에 연결되어 있어야 합니다.

1. 휴대폰 사파리(또는 크롬) 주소창에 터미널의 **3) 같은 와이파이 휴대폰** 주소를 그대로 넣습니다(`https://`로 시작).
2. 처음 한 번 "안전하지 않음" 경고가 나옵니다. 연습용 주소라서 나오는 경고이니 아래처럼 넘어가세요.
   - **아이폰 사파리**
     1. "이 연결은 비공개 연결이 아닙니다"가 나오면 **세부사항 보기**를 누릅니다.
     2. **이 웹 사이트 방문**을 누릅니다.
     3. 한 번 더 물으면 **웹 사이트 방문**을 누릅니다.
   - **안드로이드 크롬**
     1. "연결이 비공개로 설정되어 있지 않습니다"가 나오면 **고급**을 누릅니다.
     2. **…(으)로 이동(안전하지 않음)**을 누릅니다.
3. 같은 아이디(`practice`)와 터미널의 비밀번호로 로그인합니다.
4. 화면 맨 아래에 메뉴 막대가 있습니다: **방송 · 문자찜 입력 · 구매자 · 정산 · 더보기**.
   - **더보기**를 누르면 **입금 확인 · 포장 · 라벨 · 설정**이 위로 펼쳐집니다.
5. 휴대폰에서 문자찜을 하나 넣어 보세요. 맥북 화면에도 바로 나타납니다.
   반대로 맥북에서 채팅 찜을 보내면 휴대폰 방송 화면에도 바로 보입니다.

> 휴대폰에서 하지 않는 것:
> - 유튜브 연결은 **맥북에서** 하세요.
> - 출력 기기(프린터)는 맥북 하나로 두는 것이 편합니다.

## 5. 끄는 법

- 터미널 창을 누르고 `Control + C`를 누릅니다.
  → "껐어요. 다시 켜려면 pnpm try"가 나오면 꺼진 것입니다.
- 터미널 창을 그냥 닫아도 꺼집니다.
- 끄면 연습 기록이 모두 지워집니다. 다시 켜면 처음 상태가 되고, 비밀번호도 새로 바뀝니다.

## 6. 문제가 생기면

| 보이는 것 | 할 일 |
|---|---|
| `command not found: pnpm` | 1-3을 다시 하세요. 그래도 안 되면 `pnpm` 대신 `npx pnpm@12.14.0`을 앞에 붙여 실행합니다(예: `npx pnpm@12.14.0 install`, `npx pnpm@12.14.0 try`). |
| `Node 24 이상이 필요해요` | 1-2대로 Node 24를 설치하세요. |
| `먼저 설치가 필요해요` | 라이브찜 폴더에서 `pnpm install`을 한 번 하세요. |
| `화면을 만들지 못했어요` | 그 위에 나온 글자를 사진으로 찍어 개발 쪽에 보내 주세요. |
| 포트 번호가 7700이 아님 | 다른 프로그램이 7700을 쓰고 있어 옆 번호로 옮긴 것입니다. 터미널에 나온 주소를 쓰세요. 번호를 직접 정하려면 `pnpm try --port 8800`처럼 입력합니다. |
| 로그인했는데 다시 로그인 화면이 나옴 (특히 맥 사파리) | 크롬으로 여세요. 사파리를 써야 한다면 `https://localhost:7701`로 열고 4번의 경고 넘기기를 따라 하세요(포트가 바뀌었다면 휴대폰 주소의 끝 번호를 씁니다). |
| 비밀번호를 모르겠음 | 켜 둔 터미널 창에 있습니다. 창을 닫았다면 다시 켜고 새 비밀번호를 쓰세요. |
| 위쪽에 "출력 멈춤" 또는 "끊김" / 라벨이 "대기"에 머묾 | 3-5의 1번대로 시험용 프린터를 다시 연결하고 **이 기기에서 출력**을 누르세요. 유튜브 연결 뒤나 화면을 새로 고친 뒤에 생깁니다. |
| 시청자 채팅을 보내도 방송 화면에 안 나옴 | 3-4의 3~4번대로 방송 화면 유튜브 칸이 "채팅을 받는 중"인지 보세요. **리허설 방송**은 유튜브와 이어지지 않습니다. |
| 휴대폰에서 주소가 안 열림 | 같은 와이파이인지 보세요. 맥북이 잠자기 상태가 아닌지 보세요. 맥의 "들어오는 연결 허용" 창에서 **허용**을 눌렀는지도 보세요. 와이파이를 바꿨다면 라이브찜을 껐다 켜고 새 주소를 쓰세요. |
| 입금 붙여넣기에서 "표의 첫 줄(거래일시·입금액 같은 칸 이름)을 함께 붙여 넣어 주세요." | 첫 줄 `거래일시,입금자명,입금액`을 꼭 넣으세요. |
| 입금이 "확인 필요"로 가지 않고 맞춰지지도 않음 | 날짜·시각이 판매보다 이르면 맞추지 않습니다. 지금 시각으로 적으세요. |
