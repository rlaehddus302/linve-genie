# 라이브지니 직접 해 보기 (연습 모드)

내 맥북에서 라이브지니를 켜고 상품 등록부터 포장까지 처음부터 끝까지 따라 해 보는 안내입니다.
윈도우 노트북이라면 1번 대신 아래 **"1-W. 윈도우에서"**를 따라 하고, 2번부터는 같습니다.

- **연습 모드**는 진짜 유튜브·진짜 프린터·진짜 돈과 연결되지 않습니다.
  - 유튜브는 **가짜 유튜브**(연습 채널, "연습 라이브")를 씁니다.
  - 프린터는 **시험용 프린터**를 씁니다. 종이는 나오지 않고 화면에만 "출력됨"으로 적힙니다.
  - 입금은 은행 거래내역을 **붙여넣는 연습**을 합니다.
- 인스타그램·틱톡·계좌 자동 연동(팝빌)·요금 결제는 연습 모드에 없습니다.
- 연습 기록은 끄면 **모두 지워집니다**. 마음껏 눌러 보세요.

위 내용은 기본 `pnpm try` 기준입니다. `LIVEGENIE_DATA_DIR`을 명시해 실행하면 연습 DB와 로그인·암호화 키가 해당 폴더에 저장되어 다시 켜도 유지됩니다. 이 폴더는 비밀 정보가 포함되므로 공유하지 말고 DB와 키를 함께 안전하게 백업하세요. 기존 메모리 연습 기록이 자동으로 이관되지는 않습니다. 휴대폰용 인증서를 직접 제공할 때는 `LIVEGENIE_PHONE_TLS_KEY`와 `LIVEGENIE_PHONE_TLS_CERT`를 둘 다 지정합니다.

## 1. 준비물 (처음 한 번만)

준비물은 맥북, 같은 와이파이에 연결된 휴대폰(있으면), 개발 쪽에서 받은 **라이브지니 폴더**(폴더 이름 `livejjim`)입니다.
압축 파일로 받았다면 더블클릭해서 풀어 두세요.

### 1-1. 터미널 열기

**터미널**은 글자로 명령을 넣는 맥 기본 앱입니다.
`Command(⌘) + Space`를 누르고 `터미널`을 입력한 뒤 Enter를 누르세요.

아래부터 `회색 상자` 안의 글자는 터미널에 그대로 입력하고 Enter를 누르면 됩니다.

### 1-2. Node 확인하기

```
node -v
```

- `v24.`로 시작하는 숫자(예: `v24.20.0`)가 나오면 다음으로 넘어가세요.
- `command not found`가 나오거나 숫자가 24보다 작으면 Node를 설치해야 합니다.
  1. 사파리에서 **nodejs.org**를 엽니다.
  2. **24**로 시작하는 LTS 버전의 macOS 설치 파일(.pkg)을 받습니다.
  3. 받은 파일을 더블클릭하고 "계속"을 눌러 설치합니다.
  4. 터미널을 닫았다가 다시 연 뒤 `node -v`를 다시 확인합니다.

### 1-3. pnpm 켜기

pnpm은 라이브지니를 설치하고 켜 주는 도구입니다.

```
sudo corepack enable
```

- `Password:`가 나오면 **맥 로그인 비밀번호**를 입력하고 Enter를 누르세요.
  입력하는 동안 화면에 글자가 보이지 않는 것이 정상입니다.

아래 명령으로 확인합니다.

```
pnpm -v
```

- 처음에 `Do you want to continue? [Y/n]`가 나오면 `Y`를 누르고 Enter를 누르세요.
- `12.`로 시작하는 숫자가 나오면 됩니다.

### 1-4. 라이브지니 폴더로 들어가서 설치하기

1. 터미널에 `cd `를 입력합니다. **cd 뒤에 띄어쓰기 한 칸**을 꼭 넣으세요.
2. Finder에서 **라이브지니 폴더**를 끌어다 터미널 창에 놓습니다. 폴더 위치가 자동으로 입력됩니다.
3. Enter를 누릅니다.
4. 이제 설치합니다. 몇 분 걸릴 수 있습니다.

```
pnpm install
```

마지막에 빨간 `ERR`가 없으면 설치가 끝난 것입니다.

### 1-W. 윈도우에서

1. **Node 설치**: 크롬에서 **nodejs.org**를 열고 **24**로 시작하는 LTS 버전의 Windows 설치 파일(.msi)을 받아 "Next"로 설치합니다.
2. **명령 프롬프트 열기**: 키보드의 윈도우 키를 누르고 `cmd`를 입력한 뒤 Enter. (터미널 대신 이 창을 씁니다)
3. `node -v`를 입력해 `v24.`로 시작하는지 봅니다.
4. **pnpm 설치**:

   ```
   npm install -g pnpm@12.14.0
   ```

   다 되면 명령 프롬프트를 닫았다가 다시 열고 `pnpm -v`로 `12.`가 나오는지 봅니다.
5. **폴더는 짧은 경로에** 둡니다. 압축을 `C:\livegenie`처럼 C 드라이브 바로 밑에 푸세요.
   바탕 화면·다운로드처럼 긴 경로나 한글이 든 경로에서는 설치가 실패할 수 있습니다.
6. 폴더로 들어가서 설치합니다.

   ```
   cd C:\livegenie
   pnpm install
   ```

7. 2번 "켜기"부터 똑같이 하면 됩니다. 처음 켤 때 **"Windows 보안 경고 — 방화벽"** 창이 뜨면
   **개인 네트워크**에 체크하고 **액세스 허용**을 누르세요. 휴대폰 접속에 필요합니다.
   - 와이파이가 "공용 네트워크"로 잡혀 있으면 휴대폰이 못 들어올 수 있습니다.
     설정 → 네트워크 및 인터넷 → Wi-Fi → 연결된 와이파이 → **개인 네트워크**로 바꾸세요.
8. 끌 때는 `Ctrl + C`를 누릅니다. `일괄 작업을 끝내시겠습니까 (Y/N)?`가 나오면 `Y`를 누르고 Enter.

## 2. 켜기

라이브지니 폴더에 들어간 터미널에서 아래 명령을 입력합니다.
터미널을 새로 열었다면 1-4의 1~3번(`cd` 후 폴더 끌어 놓기)을 먼저 하세요.

```
pnpm try
```

처음에는 1~2분 걸립니다. 다 켜지면 이런 안내가 나옵니다.

```
 라이브지니 연습 모드가 켜졌어요. (끄려면 이 창에서 Ctrl + C)

 1) 이 컴퓨터 크롬에서 열기 : http://localhost:7700
    아이디   : practice
    비밀번호 : (켤 때마다 새로 만든 글자)

 2) 연습용 시청자 채팅     : http://localhost:7700/_try/chat

 3) 같은 와이파이 휴대폰  : https://192.168.○.○:7701
```

- **비밀번호는 켤 때마다 바뀌고 이 터미널 창에만 보입니다.** 어디에 적어 둘 필요가 없습니다.
- 숫자 7700은 컴퓨터 사정에 따라 7702, 7704처럼 바뀔 수 있습니다. **터미널에 나온 주소를 그대로** 쓰세요.
- 맥에 "node가 들어오는 네트워크 연결을 허용하겠습니까?" 창이 뜨면 **허용**을 누르세요. 휴대폰 접속에 필요합니다.
- **터미널 창은 끄지 말고 그대로 두세요.** 창을 닫으면 라이브지니도 꺼집니다.

## 3. 따라 해 보기

맥에서는 **크롬**으로 여는 것이 가장 확실합니다.

### 3-1. 로그인

1. 크롬 주소창에 `http://localhost:7700`을 입력합니다.
2. 아이디 칸에 `practice`를 넣고, 비밀번호 칸에는 **터미널에 나온 비밀번호**를 넣습니다.
3. **로그인**을 누릅니다.

→ **시작 마법사** 화면이 나오고, 단계 목록(1/5 가게 이름 ~ 5/5 리허설 해 보기)이 보입니다.

### 3-2. 시작 마법사

1. **1/5 가게 이름**: "연습 가게"가 이미 들어 있습니다. 원하면 바꾸고 **다음**을 누르세요.
2. **2/5 판매 규칙 확인**: 대기 인원, 가격 단위(천원: 10이라고 쓰면 10,000원), 기본 배송비(4,000원) 같은 규칙이 보입니다. **다음**을 누르세요.
3. **3/5 유튜브 연결**
   1. **구글로 유튜브 연결하기**를 누릅니다. 진짜 구글 대신 가짜 유튜브로 잠깐 다녀옵니다.
   2. → "유튜브 채널을 연결했어요." "연결한 채널: **연습 채널**"이 보입니다.
   3. **다음**을 누릅니다.
4. **4/5 프린터 연결**
   1. **시험용 프린터 — 실제로 출력되지 않아요**를 누릅니다. → "이 기기의 프린터: **연결됨** (시험용 프린터)"가 보입니다.
   2. **테스트 인쇄**를 누릅니다. → "테두리와 한글이 또렷하게 보이나요?"라고 물으면 **예**를 누릅니다.
   3. **이 기기에서 출력**을 누릅니다. → "**이 기기가 출력 기기예요**"가 보입니다.
   4. **다음**을 누릅니다.
5. **5/5 리허설 해 보기**: **리허설 시작하기**를 누릅니다.

> 화면을 새로 고치면 시험용 프린터 연결이 끊깁니다. 그러면 화면 위쪽 "출력 멈춤" 옆의 **다시 연결**을 한 번 누르세요.
> 쌓여 있던 라벨이 순서대로 나옵니다.

### 3-3. 리허설 (연습 중의 연습)

화면 위에 "리허설 중 — 실제 판매가 아니에요"가 보입니다.
리허설은 정산·포장에 들어가지 않는, 손에 익히기 위한 방송입니다.

1. **빠른 입력** 칸에 `1 하월시아 15`를 쓰고 Enter를 누릅니다(번호, 품종, 가격 순서).
   - → 상품 보드에 "1번 하월시아 15,000원 판매 중"이 생깁니다.
   - 몇 초 동안 **되돌리기** 버튼이 보입니다. 잘못 넣었을 때 누르면 됩니다.
2. 오른쪽 **리허설 조작판**의 "시청자로 보내기"를 씁니다. 닉네임에 `초록이`, 채팅 한 줄에 `1번 찜`을 넣고 **시청자로 보내기**를 누릅니다.
   - → 채팅에 "1번 1등"이 붙고, 보드가 "1등 초록이"로 바뀝니다.
   - 같은 방법으로 다른 닉네임이 `1번 찜`을 보내면 "대기 1번"이 됩니다.
3. 원하면 **가짜 채팅 시작**을 눌러 가짜 채팅이 저절로 쏟아지는 것도 구경해 보세요.
4. 다 했으면 **방송 끝내기** → **끝내기**를 누르고, **방송 목록**을 누릅니다.

### 3-4. 연습 방송 시작하기 (정산까지 이어지는 방송)

1. 방송 목록에서 **새 방송 시작**을 누릅니다.
2. 제목에 `연습 방송`을 쓰고 **이 방송 시작하기**를 누릅니다.
3. 오른쪽 **유튜브** 칸에서 **내 라이브 목록에서 고르기**를 누릅니다.
4. **연습 라이브 (방송 중)**를 고르고 그 아래 **이 방송에 잇기**를 누릅니다.
   - → "**채팅을 받는 중**"이 보이면 성공입니다.
5. 빠른 입력으로 상품 세 개를 등록합니다. 한 줄씩 쓰고 Enter를 누르세요.
   - `1 하월시아 15`
   - `2 에케베리아 8`
   - `3 리톱스 5`

### 3-5. 시청자 채팅으로 찜 받기 (선착순)

1. 위쪽에 "출력 멈춤"이 보이면 프린터부터 다시 연결합니다.
   1. 메뉴 **라벨**을 누릅니다.
   2. **시험용 프린터 — 실제로 출력되지 않아요**를 누릅니다.
   3. **이 기기에서 출력** 버튼이 보이면 누르고, "출력 기기 바꾸기"가 나오면 **바꾸기**를 누릅니다.
   4. 메뉴 **방송** → **연습 방송**으로 돌아갑니다.
2. 크롬에서 새 탭(`Command + T`)을 열고 `http://localhost:7700/_try/chat`을 엽니다. **연습용 시청자 채팅** 화면입니다.
3. "여러 사람이 한꺼번에 찜"에서 상품 번호 `1`, 몇 명 `3`을 넣고 **한꺼번에 찜 보내기**를 누릅니다.
4. "한 사람이 채팅 쓰기"에서 시청자 하나를 고르고 `2번 찜`을 쓴 뒤 **채팅 보내기**를 누릅니다.
5. 라이브지니 탭으로 돌아갑니다.
   - → 채팅 칸에 "1번 1등", "1번 대기 1번", "1번 대기 2번"이 붙습니다. 가장 먼저 온 사람이 1등입니다.
   - → 상품 보드의 1번·2번이 "판매 완료"로 바뀌고 1등 이름이 보입니다.

### 3-6. 라벨 (시험용 프린터)

1등이 정해지면 라벨이 저절로 출력됩니다.

1. 메뉴 **라벨**을 누릅니다.
2. → **출력 이력**에 "1번 · (1등 이름) 라벨 출력됨"이 보입니다. 종이는 나오지 않습니다.
3. 아직 **출력 대기열**에 남아 있다면 3-5의 1번처럼 프린터를 다시 연결하세요.

### 3-7. 문자찜 넣기

문자(카톡)로 받은 주문을 손으로 넣는 화면입니다.

1. 메뉴 **문자찜 입력**을 누릅니다. "고른 방송: 연습 방송 · 진행 중"이 보입니다.
2. 번호 칸에 `3`, 메모 칸에 `김씨`를 넣습니다. 전화번호는 비워 두어도 됩니다.
3. **문자찜 넣기**를 누릅니다.
   - → "3번 · 문자찜(김씨) · **1등**"이 보입니다.

### 3-8. 정산

1. 메뉴 **정산**을 누릅니다.
2. → 구매자마다 한 줄씩(이름, 상품 합계, 배송비 4,000원, 최종 금액, **미입금**)이 보입니다.
3. 이름을 누르면 품목과 "상품 합계 + 배송비 = 최종"이 자세히 나옵니다.

### 3-9. 입금 확인

1. 메뉴 **입금 확인** → **붙여넣기** 탭을 누릅니다.
2. **입금 내역** 칸에 아래처럼 적습니다.
   - 첫 줄은 꼭 이대로 씁니다.
   - 둘째 줄부터 날짜와 시각은 **지금 시각**으로 쓰고, 이름·금액은 정산 화면에서 본 대로 바꿉니다.

   ```
   거래일시,입금자명,입금액
   2026-10-22 13:05,꽃집언니,19000
   2026-10-22 13:05,김씨,9000
   2026-10-22 13:05,이영희,12000
   ```

   - 줄마다 넣는 것:
     - 첫째 줄: 시청자 1등 이름과 그 사람의 최종 금액
     - 둘째 줄: 문자찜 메모(김씨)와 그 금액
     - 셋째 줄: 일부러 **다른 이름**(이영희)과 다른 1등의 금액
3. **읽어 보기**를 누르면 읽은 입금 3건이 표로 보입니다. **입금 내역 넣기**를 누릅니다.
   - → "새 입금 3건 — 자동 확인 2건, 확인 필요 1건"이 나옵니다. 이름과 금액이 꼭 맞는 입금은 저절로 맞춰집니다.
4. **확인 필요** 탭을 누릅니다.
   - → "금액은 맞는데 이름이 달라요"와 맞을 것 같은 구매자가 보입니다.
   - **확정**을 누르고, 다시 나오는 창에서 **확정**을 누릅니다.
5. 메뉴 **정산**으로 갑니다.
   - → "미입금 0 · 입금 완료 3"이 보입니다.

### 3-10. 구매 내역 확인서 (영수증)

4. 정산 목록 위의 **전원 확인서 PDF**와 **판매대장 엑셀**도 눌러 보세요.

### 3-12. 옵션 방송 해 보기 (의류·식품·휴대폰 케이스)

다육이는 "1번 찜"처럼 번호로 받습니다.
옷·과자·폰케이스는 시청자가 `반바지 M`, `초코 과자 3`처럼 **상품 이름·옵션·수량**으로 씁니다.
이런 방송은 판매 방식을 **상품명·옵션도 받기**로 고르고 시작합니다.

- 3-2 시작 마법사(유튜브 연결·시험용 프린터)를 마친 뒤에 하세요.
- 3-4의 연습 방송이 "진행 중"이면 먼저 그 방송 화면에서 **방송 끝내기** → **끝내기**를 누르세요.
  가짜 유튜브 "연습 라이브"는 한 번에 한 방송에만 이어집니다.
- 판매 방식은 방송마다 고릅니다. 다음 방송은 다시 "번호로만 받기"가 기본입니다.

#### 1) 옵션 방송 시작하기

1. 메뉴 **방송** → **새 방송 시작**을 누릅니다.
2. **판매 방식**에서 **상품명·옵션도 받기 (의류·식품·케이스 등)**를 고릅니다.
3. 제목에 `옷·간식 방송`을 쓰고 **이 방송 시작하기**를 누릅니다.
   - → 제목 아래에 "**상품명·옵션도 받기**"가 보입니다.
   - → "지금 상품 없음 — 상품 이름을 쓴 댓글만 받아요"가 보입니다.
4. 3-4의 3~4번처럼 유튜브를 잇습니다.
   1. **내 라이브 목록에서 고르기**를 누릅니다.
   2. **연습 라이브 (방송 중)**를 고르고 **이 방송에 잇기**를 누릅니다.
   - → "**채팅을 받는 중**"이 보이면 됩니다.

> 같은 창의 **이 판매 방식으로 리허설 시작**을 누르면 옵션 리허설이 됩니다.
> 리허설은 유튜브와 이어지지 않습니다. 그래서 아래 4)의 연습용 시청자 채팅 대신 오른쪽 **리허설 조작판**의 "시청자로 보내기"로 같은 글을 보냅니다.

#### 2) 업종 템플릿으로 옵션 상품 등록하기

옵션은 Enter를 누르기 **전에** 붙입니다.
순서는 늘 같습니다.
1. 빠른 입력 칸에 번호·품종·가격을 씁니다.
2. 옆의 **옵션 추가**를 누르고 옵션을 채운 뒤 **옵션 넣기**를 누릅니다.
3. 빠른 입력 칸에서 Enter를 누릅니다.

옵션 추가 창에는 **옵션별 재고** 표가 있습니다. 옵션마다 재고 칸이 하나씩 있고, 처음에는 모두 1입니다.

**의류 — 반바지 (사이즈 S·M·L)**

1. 빠른 입력에 `21 반바지 10`을 씁니다.
2. **옵션 추가** → **템플릿에서 고르기** → **의류**의 **사이즈**를 누릅니다.
   - → 선택지 S·M·L·XL이 채워집니다.
3. 넷째 선택지(XL) 줄의 **빼기**를 누릅니다.
4. 옵션별 재고 표에서 S 재고 `3`, M 재고 `1`, L 재고 `2`를 넣습니다.
   - → 창 아래에 "옵션: 사이즈 S/M/L · 변형 3개"가 보입니다.
5. **옵션 넣기**를 누릅니다.
   - → 빠른 입력 아래에 "Enter로 등록하면 함께 들어가요"가 보입니다.
6. 빠른 입력 칸을 누르고 Enter를 누릅니다.
   - → 상품 보드에 "21번 반바지 10,000원 판매 중 · 1등 변형별 · 변형 3개 · 남은 6"이 생깁니다.
   - → 위쪽에 "**지금 상품: 21번 반바지**"가 보입니다.

**식품 — 초코 과자 (수량으로 사는 상품)**

옵션이 없는 상품은 재고가 1개입니다.
과자처럼 여러 개를 파는 상품은 선택지 하나짜리 옵션을 만들어 재고를 넣습니다.

1. 빠른 입력에 `11 초코 과자 2`를 쓰고 **옵션 추가**를 누릅니다.
2. **상품 별칭** 칸에 `초코`를 씁니다. 댓글에 "초코 2개"라고 써도 알아듣습니다.
3. **항목 더하기**를 누르고 **항목 이름**에 `구성`, **선택지**에 `1봉`을 씁니다.
4. 옵션별 재고 표의 1봉 재고에 `5`를 넣고 **옵션 넣기**를 누릅니다.
5. Enter를 누릅니다.
   - → "11번 초코 과자 2,000원 · 변형 1개 · 남은 5"가 생깁니다.

**휴대폰 케이스 — 폰케이스 (기종)**

1. 빠른 입력에 `41 폰케이스 12`를 쓰고 **옵션 추가**를 누릅니다.
2. **상품 별칭**에 `케이스`를 씁니다.
3. **템플릿에서 고르기** → **휴대폰 케이스**의 **기종**을 누릅니다.
   - → 아이폰 16 ~ 갤럭시 S25 울트라 여섯 기종이 채워집니다.
   - → "아이폰 17 프로"에는 별칭 "17프로"가 이미 들어 있습니다.
4. **모두 같은 수로** 칸에 `2`를 쓰고 **모두 바꾸기**를 누릅니다.
5. **옵션 넣기** → Enter를 누릅니다.
   - → "41번 폰케이스 12,000원 · 변형 6개 · 남은 12"가 생깁니다.

**옵션 두 개 — 화분 (색상 × 크기)**

1. 빠른 입력에 `31 화분 8`을 쓰고 **옵션 추가**를 누릅니다.
2. **템플릿에서 고르기** → **의류**의 **색상**을 누릅니다.
3. 회색·네이비·베이지는 필요 없습니다. 각 줄의 **빼기**를 눌러 흰색·검정색만 남깁니다.
4. 둘째 옵션을 만듭니다.
   1. **항목 더하기**를 누릅니다.
   2. 새 항목(항목 2)의 **항목 이름**에 `크기`를 씁니다.
   3. 첫 **선택지**에 `소형`을 씁니다.
   4. 항목 2의 **선택지 더하기**를 누르고 `대형`을 씁니다.
   - → 재고 표에 흰색/소형·흰색/대형·검정색/소형·검정색/대형 네 줄이 생깁니다.
5. 흰색/대형 재고에 `3`을 넣고 **옵션 넣기** → Enter를 누릅니다.
   - → 위쪽이 "**지금 상품: 31번 화분**"으로 바뀝니다.
   - → 그 아래 "15초 동안 상품 이름 없는 댓글은 확인 필요로 모아요"가 보입니다.

> **지금 상품**은 가장 나중에 등록한(또는 **지금 상품으로**를 누른) 상품입니다.
> `흰색 대형 2개`처럼 상품 이름 없이 옵션만 쓴 댓글은 지금 상품의 주문으로 읽습니다.
> 지금 상품이 바뀐 뒤 15초 동안은 헷갈리지 않게 "확인 필요"로 보냅니다. 그러니 **15초 넘게 기다린 뒤** 다음으로 가세요.

#### 3) 시청자 채팅 보내기

1. 새 탭에서 `http://localhost:7700/_try/chat`(연습용 시청자 채팅)을 엽니다.
2. "한 사람이 채팅 쓰기"를 씁니다.
   1. 시청자 이름을 고릅니다.
   2. 채팅 내용을 지우고 아래 글을 씁니다.
   3. **채팅 보내기**를 누릅니다.
   - 한 줄씩 보내고, 라이브지니 탭에 그 줄이 나온 뒤 다음 줄을 보내세요. 2~3초면 나옵니다.
   - "여러 사람이 한꺼번에 찜"은 `1번 찜` 같은 번호 글만 보냅니다. 옵션 방송에서는 쓰지 않습니다.

| 시청자 | 채팅 내용 | 라이브지니 채팅 칸에 붙는 것 |
|---|---|---|
| 초록이네 | `반바지 M` | 주문 21번 M → **21번 M 1등** |
| 다육사랑 | `반바지 M` | 주문 21번 M → **21번 M 대기 1번** (M은 1장뿐) |
| 밤톨맘 | `초코 과자 3` | 주문 11번 1봉 ×3 → **11번 1봉 ×3 1등** (3은 수량) |
| 선인장할매 | `케이스 17프로` | 주문 41번 아이폰 17 프로 → **41번 아이폰 17 프로 1등** |
| 꽃집언니 | `흰색 대형 2개` | 주문 31번 흰색/대형 ×2 → **31번 흰색/대형 ×2 1등** (지금 상품) |
| 물주기담당 | `반바지` | **확인 필요 · 옵션 빠짐** (사이즈가 없음) |
| 햇살창가 | `반바지 XL` | **확인 필요 · 모르는 말** (XL은 없는 사이즈) |

- → 콘솔 위쪽에 "**확인 필요 2건**" 버튼이 생깁니다.
- → 상품 보드의 1등이 생긴 상품에 "라벨 출력됨"(프린터가 끊겨 있으면 "라벨 대기")이 붙습니다.
- 애매한 댓글은 주문이 아닙니다. 재고·합계·라벨에 들어가지 않고, 판매자가 고를 때까지 기다립니다.

#### 4) "확인 필요"에서 바로잡기 / 주문 아님

1. 콘솔 위쪽의 **확인 필요 2건**을 누릅니다. 채팅 줄의 "확인 필요에서 고르기"를 눌러도 됩니다.
   - → **확인 필요** 화면에 댓글이 들어온 순서대로 두 줄이 보입니다.
   - 줄마다 시각·이름·사유("옵션 빠짐", "모르는 말")·댓글 글과 상품·사이즈·수량 칸이 있습니다.
   - 상품 칸은 읽은 상품(21번 반바지)으로 미리 골라져 있습니다.
   - 사이즈 칸에는 "S (남은 3개) · M (남은 0개) · L (남은 2개)"처럼 남은 수량이 함께 보입니다.
   - 둘째 줄("반바지 XL")에는 "혹시: L?"이 보입니다.
2. 첫째 줄(물주기담당 "반바지")을 바로잡습니다.
   1. **사이즈**에서 `L`을 고릅니다.
   2. **수량** 칸에 `1`을 씁니다. 처음엔 비어 있으니 꼭 적으세요.
   3. **주문으로**를 누릅니다.
   - → "5초 뒤 보내요: 물주기담당 "반바지" 주문으로"와 **되돌리기**가 보입니다. 5초가 지나면 줄이 사라집니다.
3. 둘째 줄(햇살창가 "반바지 XL")의 **주문 아님**을 누릅니다.
   - → 5초 뒤 "보냈어요: 햇살창가 "반바지 XL" 주문 아님", "확인할 댓글이 없어요."가 보입니다.
   - 여러 줄을 고르는 칸에 체크하고 **고른 줄 주문으로** / **고른 줄 주문 아님**으로 한 번에 처리할 수도 있습니다.
4. **콘솔로**를 누릅니다.
   - → 채팅 칸이 바뀝니다.
     - 물주기담당 줄: "주문 21번 L … **21번 L 1등**"
     - 햇살창가 줄: "언급"
   - 상품 보드의 **21번 반바지**를 누르면 **21번 자세히**가 열립니다. 변형마다 1등·대기가 보입니다.
     - "M · 판매 완료 · 남은 0개 (재고 1)", "M 1등 1명 초록이네", "M 대기 1명 다육사랑"
     - "L · 판매 중 · 남은 1개 (재고 2)", "L 1등 1명 물주기담당"
     - 라벨 칸: "1등 초록이네 M 라벨", "1등 물주기담당 L 라벨"

#### 5) 라벨·확인서·포장에서 옵션·수량 보기

**라벨**

1. 메뉴 **라벨**을 누릅니다.
   - 위쪽에 "출력 멈춤"이 있거나 출력 대기열에 남아 있으면 3-5의 1번대로 시험용 프린터를 다시 연결합니다.
   - 대기열에 "대기 중인 라벨 n장이 있어요"가 보이면 **출력 시작**을 누릅니다.
2. → **출력 이력**에 옵션 글과 수량(2개 이상일 때만)이 붙어 보입니다.
   - "11번 1봉 3개 · 밤톨맘 라벨 출력됨"
   - "21번 M · 초록이네 라벨 출력됨"
   - "21번 L · 물주기담당 라벨 출력됨"
   - "31번 흰색/대형 2개 · 꽃집언니 라벨 출력됨"
   - "41번 아이폰 17 프로 · 선인장할매 라벨 출력됨"

**정산·구매 내역 확인서**

1. 메뉴 **정산**을 누릅니다.
   - → **상품 수**는 수량을 더한 수입니다.
     - 밤톨맘 "3개 · 6,000원"
     - 꽃집언니 "2개 · 16,000원"
     - 나머지는 "1개"
2. **꽃집언니**를 누릅니다.
   - → 품목: "31번 화분 흰색/대형 2개 16,000원"
   - → "상품 합계 16,000원 + 배송비 4,000원 + 조정 0원 = 최종 20,000원"
   - → **포장 라벨** 미리 보기: "31 흰색/대형 ×2", "상품 2개 상품 합계 16,000원"
   - → **구매 내역 확인서** 미리 보기 품종 칸: "화분 흰색/대형 (8,000원 × 2개)", 가격 16,000원, 상품 수 2개
3. **정산 목록으로** → **밤톨맘**을 누릅니다.
   - → 품목: "11번 초코 과자 1봉 3개 6,000원"
   - → 확인서: "초코 과자 1봉 (2,000원 × 3개)"
   - → 포장 라벨: "11 1봉 ×3"

**포장**

1. 메뉴 **포장**을 누르고 **꽃집언니**("상품 2개 · 포장 대기")를 누릅니다.
   - → 담을 상품 줄에 "31번 화분 흰색/대형"과 큰 글씨 "**2개**"가 보입니다.
   - → 아래에 "0/1 담음"이 보입니다. 줄 수를 세므로 2개여도 한 줄입니다.
2. 그 줄의 체크 칸에 체크하고 **포장 완료**를 누릅니다.
   - → "1/1 담음", "포장 완료로 적었어요."가 보입니다.

> 이번 방송을 끝내려면 콘솔에서 **방송 끝내기** → **끝내기**를 누르세요.

### 3-13. 간편 로그인 (카카오·네이버·구글)

연습 모드의 카카오·네이버·구글은 **연습용 가짜 화면**입니다. 진짜 카카오 계정이 필요 없습니다.

1. 메뉴 **설정** → **로그인 방법** 칸에서 카카오 줄의 **연결하기**를 누릅니다.
   - → "연습용 가짜 화면이에요. 실제 카카오가 아니에요."가 위에 보이는 화면이 열립니다.
2. 연습 계정 하나를 고르고 **동의하고 계속하기**를 누릅니다.
   - → 설정 화면으로 돌아오고 "카카오 계정을 연결했어요. 다음부터 "카카오로 계속하기"로 로그인할 수 있어요."가 보입니다.
3. 로그아웃합니다.
4. 로그인 화면 아래 **카카오로 계속하기**를 누르고, 같은 연습 계정을 골라 **동의하고 계속하기**를 누릅니다.
   - → 비밀번호 없이 홈으로 들어옵니다.
   - 다른 연습 계정을 고르면 "이 카카오 계정에 연결된 라이브지니 계정이 없어요…"가 보입니다(가입은 받지 않습니다).
5. 다시 **설정** → **로그인 방법**에서 **연결 끊기**를 누르면 끊깁니다. 아이디 로그인은 그대로입니다.

## 4. 휴대폰으로 열기

휴대폰과 맥북이 **같은 와이파이**에 연결되어 있어야 합니다.

1. 휴대폰 사파리(또는 크롬) 주소창에 터미널의 **3) 같은 와이파이 휴대폰** 주소를 그대로 넣습니다(`https://`로 시작).
2. 처음 한 번 "안전하지 않음" 경고가 나옵니다. 연습용 주소라서 나오는 경고이니 아래처럼 넘어가세요.
   - **아이폰 사파리**
     1. "이 연결은 비공개 연결이 아닙니다"가 나오면 **세부사항 보기**를 누릅니다.
     2. **이 웹 사이트 방문**을 누릅니다.
     3. 한 번 더 물으면 **웹 사이트 방문**을 누릅니다.
   - **안드로이드 크롬**
     1. "연결이 비공개로 설정되어 있지 않습니다"가 나오면 **고급**을 누릅니다.
     2. **…(으)로 이동(안전하지 않음)**을 누릅니다.
3. 같은 아이디(`practice`)와 터미널의 비밀번호로 로그인합니다.
4. 화면 맨 아래에 메뉴 막대가 있습니다: **방송 · 문자찜 · 구매자 · 정산 · 더보기**.
   - **더보기**를 누르면 **입금 확인 · 포장 · 라벨 · 택배 · 설정**이 위로 펼쳐집니다. 맨 끝에 **로그아웃** 버튼이 있습니다.
   - 끝내지 않은 방송이 있을 때 로그아웃을 누르면 "로그아웃할까요?"라고 한 번 묻습니다. **로그인 유지**를 누르면 그대로입니다.
5. 휴대폰에서 문자찜을 하나 넣어 보세요. 맥북 화면에도 바로 나타납니다.
   반대로 맥북에서 채팅 찜을 보내면 휴대폰 방송 화면에도 바로 보입니다.

> 유튜브 연결:
> - 연습 모드(`pnpm try`)에서는 휴대폰에서도 **설정 → 유튜브 → 구글로 유튜브 연결하기**를 해 볼 수 있습니다. 연습 채널로 바로 연결됩니다.
> - 실제 유튜브(`pnpm try --real-youtube`)는 **맥북에서 먼저** 연결하세요. 휴대폰에서 누르면 "휴대폰에서는 유튜브를 연결할 수 없어요."가 나옵니다. 맥북에서 연결하면 휴대폰에서도 그대로 씁니다.
>
> 휴대폰에서 하지 않는 것:
> - 출력 기기(프린터)는 맥북 하나로 두는 것이 편합니다.

  - 인터넷 주소(도메인)와 서버(호스팅)
  - 구글 클라우드에 유튜브 연동 등록

- **실제 판매 기록 보관**: 연습 모드는 끄면 지워집니다. 실제 판매는 데이터베이스와 백업이 있는 운영 서버에서 합니다([DEPLOY](DEPLOY.md)).

## 실제 유튜브로 시험하기 (개발자용)

1. 구글 클라우드 콘솔에서 프로젝트를 만들고 **YouTube Data API v3**를 켭니다.
2. OAuth 동의 화면(외부·테스트)을 만들고, 라이브를 켤 구글 계정을 **테스트 사용자**로 넣습니다.
3. OAuth 클라이언트(웹 애플리케이션)를 만들고, 승인된 리디렉션 URI에 `http://localhost:7700/api/youtube/oauth/callback` 을 넣습니다.
4. 저장소 맨 위 폴더에 `.env.youtube.local` 파일을 만들고 아래 두 줄을 적습니다(이 파일은 깃에 올라가지 않습니다. 값을 대화창에 붙이지 마세요).
   ```
   LIVEJJIM_GOOGLE_CLIENT_ID=받은 클라이언트 ID
   LIVEJJIM_GOOGLE_CLIENT_SECRET=받은 클라이언트 보안 비밀
   ```
5. `pnpm try --real-youtube` 로 켜고 설정 → 유튜브에서 **구글로 유튜브 연결하기**를 누릅니다("확인되지 않은 앱" 경고는 고급 → 계속).
6. 유튜브에서 **일부 공개** 라이브를 켜고, 라이브지니 방송에서 그 방송을 잇습니다. 다른 계정으로 채팅에 "15번 찜"을 쳐 봅니다.

## 실제 간편 로그인으로 시험하기 (개발자용)

도메인 없이 이 컴퓨터에서 **진짜 카카오·네이버·구글 계정**으로 간편 로그인을 해 봅니다. 각 회사에 "돌아오는 주소"를 `http://localhost:7700/…`으로 등록하고, `.env.login.local` 파일에 받은 값을 적은 뒤 `pnpm try --real-login`으로 켭니다.

- **받은 값(키·Secret)은 대화창·메신저·이슈에 절대 붙이지 마세요.** `.env.login.local` 파일에만 적습니다. 이 파일은 깃에 올라가지 않고, 라이브지니는 값을 화면·로그에 내지 않습니다.
- 값을 적은 회사만 진짜로 켜지고, 적지 않은 회사는 **꺼집니다**(이 모드에서는 연습용 가짜 화면이 나오지 않습니다). 셋 다 할 필요 없이 하나만 해도 됩니다.
- 라이브지니가 각 회사에서 받는 정보는 **계정 번호뿐**이고, 주면 이메일·닉네임을 받아 가린 이름(예: `se***@gmail.com`, `초***`)만 남깁니다. 구글은 `openid email`만 묻고(유튜브 권한은 묻지 않음), 카카오·네이버는 따로 권한을 더 묻지 않습니다. 회사가 준 토큰은 저장하지 않습니다.
- 아래 주소의 `7700`은 `pnpm try`의 기본 포트입니다. 다른 번호로 켜지면 터미널에 경고가 나오니, 그 번호로 다시 등록하거나 7700을 쓰는 프로그램을 끄세요.

### 카카오 (developers.kakao.com)

1. [developers.kakao.com](https://developers.kakao.com)에 카카오 계정으로 로그인 → **내 애플리케이션** → **애플리케이션 추가하기**(앱 이름 예: 라이브지니 연습, 회사명은 아무거나).
2. 앱 설정 → **플랫폼** → **Web 플랫폼 등록** → 사이트 도메인에 `http://localhost:7700`.
3. 제품 설정 → **카카오 로그인** → 활성화 설정을 **켜기(ON)**.
4. 같은 화면의 **Redirect URI**에 `http://localhost:7700/api/auth/kakao/callback` 을 글자 그대로 등록합니다.
5. 카카오 로그인 → **동의항목** → **닉네임**을 "선택 동의"(또는 필수)로 둡니다. 라이브지니가 꼭 필요한 것은 회원 번호뿐이라 닉네임이 없어도 로그인은 되지만, 있으면 설정 화면에 가린 닉네임이 보입니다. 이메일은 필요 없습니다(비즈 앱만 받을 수 있음 — 없으면 "카카오 계정"으로 보입니다).
6. 앱 설정 → **앱 키**의 **REST API 키**를 복사해 `LIVEJJIM_LOGIN_KAKAO_REST_API_KEY`에 적습니다.
7. 제품 설정 → 카카오 로그인 → **보안**의 **Client Secret**이 "사용함"이면 그 코드를 `LIVEJJIM_LOGIN_KAKAO_CLIENT_SECRET`에 적습니다. "사용 안 함"이면 이 줄은 적지 않습니다(빈 값으로 두지 말고 줄을 지우세요).

### 네이버 (developers.naver.com/apps)

1. [developers.naver.com/apps](https://developers.naver.com/apps)에 네이버 아이디로 로그인 → **Application** → **애플리케이션 등록**.
2. 애플리케이션 이름(예: 라이브지니 연습), **사용 API**는 **네이버 로그인**.
3. 제공 정보: 네이버가 하나 이상 고르라고 하면 **별명**(또는 이메일 주소)을 고릅니다. 라이브지니가 꼭 필요한 것은 회원 ID뿐이고, 별명·이메일은 설정 화면의 가린 이름에만 씁니다.
4. 로그인 오픈 API 서비스 환경에서 **PC 웹** → 서비스 URL `http://localhost:7700`, 네이버 로그인 **Callback URL** `http://localhost:7700/api/auth/naver/callback`.
5. 등록 후 나오는 **Client ID**를 `LIVEJJIM_LOGIN_NAVER_CLIENT_ID`에, **Client Secret**을 `LIVEJJIM_LOGIN_NAVER_CLIENT_SECRET`에 적습니다.
6. 검수 전("개발 중")에는 앱을 만든 아이디와 **멤버관리**에 넣은 테스트 아이디만 로그인됩니다.

### 구글 (console.cloud.google.com/auth/clients)

1. [console.cloud.google.com/auth/clients](https://console.cloud.google.com/auth/clients)에서 프로젝트를 고르거나 만듭니다(유튜브 시험과 같은 프로젝트여도 됩니다). 처음이면 "Google 인증 플랫폼" 시작(앱 이름·지원 이메일, 대상은 **외부**).
2. **클라이언트 만들기** → 애플리케이션 유형 **웹 애플리케이션**.
3. **승인된 리디렉션 URI**에 `http://localhost:7700/api/auth/google/callback` 추가(유튜브 시험용 클라이언트를 같이 써도 되며, 그때는 두 주소를 다 넣습니다).
4. 만든 뒤 나오는 **클라이언트 ID**를 `LIVEJJIM_LOGIN_GOOGLE_CLIENT_ID`에, **클라이언트 보안 비밀번호**를 `LIVEJJIM_LOGIN_GOOGLE_CLIENT_SECRET`에 적습니다.
5. **대상**(Audience) 화면에서 게시 상태가 "테스트 중"이면, 로그인해 볼 구글 계정을 **테스트 사용자**로 추가합니다.

### `.env.login.local` 만들기와 켜기

1. 저장소 맨 위 폴더(`package.json`이 있는 곳)에 `.env.login.local` 파일을 만들고, 쓸 회사의 줄만 적습니다. 한 줄에 `이름=값`, 앞뒤 따옴표는 없어도 됩니다. `#`으로 시작하는 줄은 무시합니다.
   ```
   # 카카오 (Client Secret을 "사용함"으로 켰을 때만 두 번째 줄)
   LIVEJJIM_LOGIN_KAKAO_REST_API_KEY=여기에-REST-API-키
   LIVEJJIM_LOGIN_KAKAO_CLIENT_SECRET=여기에-Client-Secret
   # 네이버
   LIVEJJIM_LOGIN_NAVER_CLIENT_ID=여기에-Client-ID
   LIVEJJIM_LOGIN_NAVER_CLIENT_SECRET=여기에-Client-Secret
   # 구글
   LIVEJJIM_LOGIN_GOOGLE_CLIENT_ID=여기에-클라이언트-ID
   LIVEJJIM_LOGIN_GOOGLE_CLIENT_SECRET=여기에-클라이언트-보안-비밀번호
   ```
   예시 글(한글)을 그대로 두면 켜지지 않고 몇 번째 줄인지 알려 줍니다. 이름 오타·빈 값·같은 이름 두 번·반만 적기(구글·네이버는 ID와 Secret 둘 다, 카카오는 REST API 키 필수)도 마찬가지입니다.
2. `pnpm try --real-login` 으로 켭니다. 유튜브도 진짜로 보려면 `pnpm try --real-login --real-youtube`.
3. 터미널의 "실제 간편 로그인 시험" 칸에서 회사마다 **켜져 있어요 / 꺼져 있어요**와 등록할 주소를 확인합니다.
4. **이 컴퓨터 크롬**에서 `http://localhost:7700` → 아이디 `practice`로 로그인 → **설정** → **로그인 방법** → 켜진 회사의 **연결하기** → 그 회사 화면에서 동의 → 설정으로 돌아와 "연결했어요"를 확인합니다.
5. 로그아웃 → 로그인 화면 아래 **카카오로 계속하기**(또는 네이버·구글) → 비밀번호 없이 들어오면 성공입니다.

- **휴대폰(https 주소)으로는 간편 로그인이 안 됩니다.** 각 회사에 등록한 돌아오는 주소가 이 컴퓨터(`localhost`)라서, 휴대폰은 로그인 뒤 돌아올 곳을 찾지 못합니다. 간편 로그인은 이 컴퓨터 크롬에서만 해 보세요(아이디 로그인은 휴대폰에서도 됩니다).
- 연습 모드는 끄면 기록이 지워지므로, 다시 켜면 **연결하기부터 다시** 합니다.
- 회사 화면에서 "redirect_uri가 맞지 않아요" 같은 오류가 나오면 등록한 주소와 터미널에 나온 주소가 글자까지 같은지(포트 번호, `http`, 끝의 `/callback`) 확인하세요.

## 실제 틱톡 라이브로 시험하기 (개발자용, 베타)

키나 계정 없이 **지금 방송 중인 틱톡 라이브의 댓글을 읽기만** 해 봅니다. 틱톡에 로그인하지 않고, 글을 올리지도 않아요.

1. `pnpm try --real-tiktok` 으로 켭니다. (다른 옵션과 함께 써도 돼요)
2. 로그인한 뒤 **설정 → 틱톡 라이브(베타)** 에서 안내를 읽고 동의한 다음 **켜기**를 누릅니다.
3. 방송 중인 틱톡 아이디(예: `@아이디`)를 넣고 **저장**합니다.
4. **새 방송 시작** → 방송 화면의 틱톡 칸에서 **틱톡 잇기**를 누르면 몇 초 뒤 채팅 칸에 `틱톡` 표시가 붙은 댓글이 들어와요.
5. 다 보면 **끊기**를 누르고 연습 모드를 끕니다.

- 비공식 방법이라 틱톡이 막거나 바꾸면 갑자기 안 될 수 있어요. 연결을 돕는 다른 회사 서비스로 넣은 아이디가 전달돼요.
- 서명 서비스 키가 있으면 `LIVEJJIM_TIKTOK_SIGN_API_KEY` 환경 변수로 넘겨요(없어도 돼요, 횟수 제한만 있어요). 키를 대화나 파일에 붙여 넣지 마세요.
- 다른 사람 방송은 짧게 읽기만 하는 시험에만 쓰고, 그 댓글을 따로 모아 두지 마세요.

## 문자 자동 수신 시험하기 (개발자용, 실험)

시청자가 **사장님 원래 번호**로 보낸 문자가, 사장님이 손대지 않아도 **저절로 연습 서버까지** 오는지 실제 휴대폰으로 시험합니다. "몇 초 안에, 빠짐없이, 보낸 차례대로" 오는지를 시험 화면이 세어 줍니다.

- 이 도구는 시험용입니다. 실제 문자찜을 어떻게 자동으로 받을지는 아직 정하지 않았습니다(이 시험 결과를 보고 사장님이 정합니다).
- 받은 문자는 찜·문자찜·정산에 **들어가지 않고**, 시험 화면에 보이기만 합니다.
- 받은 것은 최근 50건만 들고 있고, 연습 모드를 끄면 모두 사라집니다.
- 보낸 사람 번호는 **끝 4자리만** 남기고 나머지는 받자마자 지웁니다. 연락처 이름으로 오면 "번호 대신 이름이 왔어요"라고만 보입니다.
- 내용은 앞 200자까지만 남깁니다.

### 준비

1. 맥북과 휴대폰을 **같은 와이파이**에 연결하고 `pnpm try`로 켭니다.
2. 두 휴대폰(받는 휴대폰·보내는 휴대폰)과 맥북 모두 **날짜 및 시간 자동 설정**을 켭니다. 시계가 서로 다르면 "늦은 정도"가 틀리게 나옵니다.
   - 아이폰: 설정 → 일반 → 날짜 및 시간 → **자동으로 설정**
   - 갤럭시: 설정 → 일반 → 날짜 및 시간 → **자동 날짜 및 시간**
   - 맥북: 시스템 설정 → 일반 → 날짜 및 시간 → **시간 및 날짜 자동으로 설정**
3. 터미널에 아래 줄들이 나옵니다. 사진으로 찍어 두세요.
   - **문자 자동 수신 시험 주소**: `https://<맥북 주소>:7701/_try/sms-test` 같은 주소
   - **문자 자동 수신 시험 토큰**: `abcd-efgh-jk23` 같은 글자(켤 때마다 바뀝니다)
   - **https가 안 되면 이 주소(http)를 쓰세요**: `http://<맥북 주소>:7702/_try/sms-test` 같은 주소. 단축어·MacroDroid가 자체 서명 https 주소를 거절하면 시험 주소 대신 이 주소를 넣습니다(토큰은 같고, 문자 시험만 받습니다).
4. 휴대폰 사파리(또는 크롬)로 `시험 주소?t=토큰`을 엽니다(예: `https://192.168.0.10:7701/_try/sms-test?t=abcd-efgh-jk23`). "안전하지 않음" 경고는 넘어갑니다. 받은 문자가 이 화면에 5초마다 새로 보입니다.
5. 연습 모드를 껐다 켜면 토큰이 바뀝니다. 휴대폰의 단축어·매크로에 넣은 토큰도 새것으로 고쳐야 합니다. 시험만 다시 하려면 껐다 켜지 말고 화면의 **처음부터 다시 세기**를 쓰세요(토큰이 그대로입니다).

- 메뉴 이름은 휴대폰 기종·버전에 따라 조금 다를 수 있습니다. 비슷한 이름을 고르세요.

### (가) 아이폰: 단축어 자동화

**1단계 — 보내는 단축어 만들기**

1. **단축어** 앱을 열고 아래 **단축어** 탭에서 오른쪽 위 **+**를 누릅니다.
2. 이름을 `문자 시험 보내기`로 바꿉니다.
3. **동작 추가** → 검색창에 `URL 내용 가져오기`를 넣고 고릅니다.
4. 파란 `URL` 자리에 **시험 주소**를 그대로 넣습니다(`?t=…`는 붙이지 않습니다).
5. 동작 옆 **>** (펼치기)를 누르고 아래처럼 정합니다.
   - **방법**: `POST`
   - **헤더**: **새로운 헤더 추가** → 키 `X-Try-Token`, 값 = **시험 토큰**
   - **요청 본문**: `JSON`
     - **새로운 필드 추가** → 텍스트 → 키 `from`, 값은 **단축어 입력**을 고른 뒤 그것을 눌러 **보낸 사람**으로 바꿉니다.
     - **새로운 필드 추가** → 텍스트 → 키 `body`, 값은 **단축어 입력** → **내용**.
     - **새로운 필드 추가** → 텍스트 → 키 `device`, 값 `iPhone`.
     - **새로운 필드 추가** → 텍스트 → 키 `receivedAt`, 값은 **현재 날짜**를 고릅니다. 그것을 눌러 **날짜 형식**을 **ISO 8601**로 바꾸고 **시간 포함**을 켭니다. (휴대폰이 문자를 받은 시각이라, 화면이 "몇 초 늦었는지"를 잽니다.)
6. **완료**를 누릅니다.

**2단계 — 문자가 오면 저절로 돌게 하기**

1. 아래 **자동화** 탭 → 오른쪽 위 **+** (또는 **새로운 자동화**) → **메시지**를 고릅니다.
2. **메시지에 포함**을 누르고 `시험`을 넣습니다.
3. **즉시 실행**을 고르고, **실행 시 알림**은 꺼 둡니다.
4. **다음** → 1단계에서 만든 `문자 시험 보내기`를 고릅니다.
5. (선택) 실제 주문 같은 문자(`165번주세요`)까지 보려면 2~4를 숫자 `0`부터 `9`까지 하나씩 넣어 자동화를 10개 더 만듭니다.
   - 문자 하나에 숫자가 여러 개 있으면 여러 자동화가 같이 돌아 **같은 문자가 여러 번** 올 수 있습니다. 시험 화면은 겹쳐 온 것을 **한 번으로 세고** "3번 왔어요"처럼 따로 보여 줍니다.
   - **주의**: 숫자 자동화를 켜면 숫자가 든 **모든 문자**(은행·카드 인증번호, 결제 알림, 택배, 가족 문자)가 맥북으로 넘어가 시험 화면에 내용이 그대로 보입니다. http 주소를 쓰면 같은 와이파이에 그대로 흐릅니다. 꼭 필요할 때만, **시험하는 동안만** 켜고 끝나면 바로 지우세요(맨 아래 "시험이 끝나면 꼭 끄기"). 그동안 인증번호 받을 일은 미뤄 두세요.

**자체 서명 주소를 거절할 때**

- 연습 주소는 맥북이 직접 만든 인증서를 써서, 단축어가 "서버에 연결할 수 없음", "인증서가 유효하지 않음" 같은 글로 거절할 수 있습니다.
- 그러면 1단계 4번의 주소를 **https가 안 되면 쓰는 주소(http)**로 바꿉니다(토큰은 같습니다).
- 그래도 안 되면 **그 글을 그대로 사진으로** 찍어 개발 쪽에 보내 주세요. 그것도 시험 결과입니다. (사파리에서 경고를 넘긴 것과 단축어는 따로라서, 사파리가 열려도 단축어는 거절할 수 있습니다.)

### (나) 갤럭시: MacroDroid

1. **Play 스토어**에서 `MacroDroid`를 설치하고 엽니다. 처음 묻는 권한 안내는 따라 갑니다.
2. **매크로 추가**를 누르고 이름을 `문자 시험 보내기`로 정합니다.
3. **트리거** **+** → **장치 이벤트**(또는 **알림**) → **알림 받음** → 앱 고르기에서 **메시지**(삼성)를 고릅니다.
   - "알림 접근 허용"을 물으면 **MacroDroid**를 켜 줍니다.
   - 글자 조건은 **글자 포함** → `시험`으로 둡니다(아이폰과 같게). **모든 알림**으로 두지 마세요. 그러면 은행·카드 인증번호, 결제 알림, 택배, 가족 문자까지 모두 맥북으로 넘어가 시험 화면에 내용이 그대로 보입니다.
4. **동작** **+** → **웹 연동**(또는 **연결**) → **HTTP 요청**을 고릅니다.
   - **주소(URL)**: **시험 주소**(`?t=…` 없이). 거절되면 **https가 안 되면 쓰는 주소(http)**.
   - **방법**: `POST`
   - **헤더**: 이름 `X-Try-Token`, 값 = **시험 토큰**
   - **본문 형식**: `application/json`, 본문에 아래를 넣습니다. `[…]` 자리는 오른쪽 **…** (마법의 글자)에서 고릅니다.
     ```
     {"from":"[알림 제목]","body":"[알림 내용]","device":"Galaxy","receivedAt":"[시스템 시간]"}
     ```
     - 알림 제목 = 보낸 사람, 알림 내용 = 문자 본문입니다.
     - `[시스템 시간]`은 마법의 글자에서 **밀리초 숫자로 된 시스템 시간**을 고릅니다. 이름이 다르면 비슷한 것(예: 시스템 시간(밀리초))을 고르고, 없으면 `,"receivedAt":"[시스템 시간]"` 부분을 빼도 됩니다(그때는 "늦은 정도"가 "-"로 보입니다).
   - 인증서 확인을 끄는 칸(예: **안전하지 않은 인증서 허용**)이 있으면 켭니다. 없는데 거절되면 그 글을 사진으로 남깁니다.
5. 오른쪽 아래 **저장**을 누릅니다.
6. **설정 → 애플리케이션 → MacroDroid → 배터리 → 제한 없음**으로 바꿉니다(화면이 꺼져도 돌게).

### (다) 시험 순서

다른 휴대폰에서 사장님 번호로 아래 차례대로 보냅니다. 문자 내용 앞에 꼭 `시험 번호`를 붙이세요. 시험 화면이 번호로 빠진 문자와 순서를 셉니다. 무엇을 보낼지 모르겠으면 화면의 **다음에 보낼 글**을 보면 됩니다.

| 회차 | 보내는 글 | 어떻게 |
|---|---|---|
| ① | `시험 1` ~ `시험 5` | 하나씩 보내고, 보낼 때마다 시험 화면에 나왔는지 봅니다 |
| ② | `시험 6` ~ `시험 10` | 10초 안에 몰아서 보냅니다 |
| ③ | `시험 11` | 받는 휴대폰을 **잠근** 상태에서 |
| ④ | `시험 12` | 받는 휴대폰 화면을 끄고 **30분** 둔 뒤 |
| ⑤ | `시험 13 165번주세요` | 띄어쓰기 없는 주문 모양이 그대로 오는지 |
| ⑥ | `시험 14`, `시험 15` | `시험 14`는 받는 휴대폰 연락처에 **저장된** 번호에서, `시험 15`는 **없는** 번호에서 |
| ⑦ | (적기) | 회차마다 보내는 쪽이 일반 문자·채팅+(RCS)·아이메시지 중 무엇이었는지 적어 둡니다 |

- 다 보냈으면 **기기마다** 결과 화면의 **요약 부분만** 사진으로 찍어 개발 쪽에 보냅니다. 아래 받은 문자 카드에는 문자 내용이 나오니 사진에 넣지 마세요. 시험 문자가 아닌 문자가 카드에 보이면 그 부분은 꼭 빼고 찍습니다.
- 아이폰과 갤럭시를 같이 시험해도 됩니다. 요약이 기기마다 따로 나옵니다.

### (라) 결과 읽기

시험 화면 맨 위 **요약**에 기기마다 아래 문장이 나옵니다.

- **받은 문자 n건**: 겹쳐 온 것을 뺀 문자 수입니다.
- **늦은 정도: 평균 · 가장 늦은 것**: 휴대폰이 문자를 받은 뒤 서버까지 오는 데 걸린 시간입니다. "1초 안"은 1초보다 빨랐다는 뜻입니다. 휴대폰이 받은 시각(`receivedAt`)을 보내지 않으면 "잴 수 없어요"로 나오고, 카드의 "늦은 정도"는 "-"입니다. 그때는 문자를 보낸 시각과 "서버가 받은 시각"을 비교하세요.
- **빠진 번호**: 서버까지 오지 않은 문자입니다. 1부터 받은 가장 큰 번호까지 중 안 온 번호를 보여 줍니다.
- **늦게 온 번호**: 뒤에 보낸 것보다 늦게 도착한 문자입니다.
- **겹쳐 온 것**: 같은 문자가 여러 번 온 것입니다. 한 번으로 셉니다.
- **시계 차이**: 휴대폰 시계와 맥북 시계가 다릅니다. 준비 2번(날짜 및 시간 자동 설정)을 확인하세요. 이런 문자는 평균에서 뺍니다.
- 가장 큰 번호 **뒤에** 보낸 문자가 안 왔는지는 화면이 알 수 없습니다. 마지막으로 보낸 번호와 비교하세요.
- 최근 50건 안에서만 셉니다. 50건이 넘으면 화면이 알려 줍니다.

**처음부터 다시 세기**: 화면의 **처음부터 다시 세기** → **네, 지우고 처음부터 셀게요**를 누르면 받은 시험 문자가 모두 지워지고 `시험 1`부터 다시 셉니다. 지우면 되돌릴 수 없으니 결과 사진을 먼저 찍어 두세요. 토큰이 바뀌지 않아 단축어·매크로를 고칠 필요가 없습니다.

### 시험이 끝나면 꼭 끄기

- **아이폰**: 단축어 앱 → **자동화** 탭 → 만든 자동화를 하나씩 왼쪽으로 밀어 **삭제**(또는 눌러서 **자동화 활성화** 끄기). `문자 시험 보내기` 단축어도 길게 눌러 **삭제**합니다.
- **갤럭시**: MacroDroid → **매크로** → `문자 시험 보내기`의 스위치를 끄거나 길게 눌러 **삭제**합니다. 더 쓰지 않으면 앱을 지우고, 설정 → 알림 접근에서 MacroDroid를 끕니다.
- 연습 모드를 끄면(`Control + C`) 받은 시험 문자도 모두 사라집니다.
