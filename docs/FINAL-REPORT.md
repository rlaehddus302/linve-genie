## 2. 직접 써 보기 (연습 모드)

외부 계정·프린터 없이 처음부터 끝까지 써 볼 수 있습니다. 자세한 따라 하기: [TRY-IT.md](TRY-IT.md)

```bash
cd ~/livejjim && pnpm install && pnpm try
```

- 컴퓨터: 터미널에 나온 `http://localhost:7700` (크롬 권장). 아이디 `practice`, 비밀번호는 켤 때마다 새로 정해져 터미널에만 보임.
- 휴대폰: 같은 와이파이에서 터미널에 나온 `https://…:7701` (처음 한 번 "안전하지 않음" 경고 → 안내서대로 넘어가기).
- 연습용 시청자 채팅 화면(`/_try/chat`)에서 "N번" 찜을 여러 명이 동시에 보내 선착순을 볼 수 있음.
- 끄기: 터미널에서 `Ctrl + C` (연습 데이터는 사라짐).

### 들어간 기능

- **방송**: 상품 등록(번호·품종·가격, 음성 제안 카드), 찜 접수(유튜브·인스타그램·틱톡 동시 송출, 문자찜), 선착순 판정·대기·취소·승계, 리허설
- **라벨**: NIIMBOT B1 / Marklife / 바우아토, 시험용 프린터, 라벨 끄기, 끊기면 위 줄 "다시 연결"
- **정산**: 구매자 합치기, 입금 확인(붙여넣기·자동 맞춤), 확인서 PDF·그림, 구매자 공유 링크(바로 영수증), 판매대장 엑셀
- **포장**: 휴대폰 포장 모드, 포장 라벨
- **운영**: 시작 마법사, 보조자 계정, 요금제(이용권), 매일 백업·복구, 유튜브 원문 30일 봉인
- **휴대폰 화면**: 아래 메뉴 다섯 칸(방송·문자찜 입력·구매자·정산·더보기)

## 3. 사장님이 직접 하셔야 하는 일

제가 대신할 수 없는 외부 계정·계약·법률·실물 확인입니다. 급한 순서입니다.

| 순서 | 할 일 | 왜 필요한가 |
|---|---|---|
| 1 | **사업자등록** (홈택스, 업종 722000, 일반과세자) — 진행 중 | 결제·통신판매업·세금계산서의 출발점 |
| 2 | **통신판매업 신고** (정부24 또는 구청) | 요금 결제를 받으려면 필요 |
| 3 | **포트원 가입 + 토스페이먼츠 PG 심사** | 실제 결제(요금제). 지금은 가짜 결제 서버 |
| 4 | **도메인 구입 + 서버(호스팅) 선택** | 인터넷에 서비스 열기 |
| 5 | **구글 클라우드 프로젝트 + OAuth 동의 화면 심사** | 실제 유튜브 채팅 받기·감사 댓글. 지금은 가짜 구글 서버 |
| 6 | 메타 개발자 앱·권한 심사 | 실제 인스타그램 라이브 댓글·감사 DM |
| 7 | 팝빌 계약(계좌조회·세금계산서) | 입금 자동 확인·증빙 발행. 지금은 붙여넣기로 대신 |
| 8 | 개인정보처리방침·이용약관·환불 규정 법률 검토 | 초안 페이지만 있음 |
| 9 | 틱톡 연결의 약관 위험 판단 | 틱톡은 공식 API가 없어 베타(기본 꺼짐) |

### 실물로 확인해 주셔야 하는 것 (기기·실제 방송)

- **실제 B1 프린터**: 연결(블루투스·USB), 한글, 30장 연속, 라벨 크기, 마법사에서 유튜브 연결 뒤 끊기지 않는지·"다시 연결" 한 번으로 이어지는지
- **Marklife·바우아토 프린터**: 모델별 연결·테스트 라벨 (바이트는 참고 구현의 추정)
- **실제 유튜브 비공개 테스트 방송**: 연결 → 채팅 → 판정 → 감사 댓글
- **실제 목소리 음성 인식 정확도**(크롬)
- **실제 휴대폰**: 아이폰·안드로이드에서 홈 화면 앱, 느린 통신에서 문자찜 입력 잠금 시간이 거슬리지 않는지
- **리허설 1회 직접**: PC 방송 화면 + 휴대폰 문자찜·구매자·정산

## 4. 제가 판매자에게 안전한 쪽으로 스스로 정한 것 (검토 부탁)

묻지 않고 진행하면서 정한 결정은 모두 [DECISIONS.md](DECISIONS.md)에 `AUTO`로 근거와 함께 남겼습니다. 특히 한번 보셨으면 하는 것:

- 오타·애매한 댓글은 **자동으로 정하지 않고** "확인 필요"로 보냄 (옵션 방송)
- 남은 수량이 모자라면 **일부만 확정하지 않음**
- 찜 판정은 서버 도착 순서(접수순)가 기본
- 문자찜은 5초 대기 없이 바로 들어감(잘못 넣으면 찜 취소)
- 입금 자동 확인은 금액과 입금자명이 **정확히 같을 때만**
- 요금제 가격(회당권 9,900원, 기간권 2.9만/5.9만)과 7일 환불 규칙
- 라벨 장권을 다 써도 막지 않고 알림만
