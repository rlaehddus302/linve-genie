## 사용자 유형

| 사용자 | 설명 |
|---|---|
| 판매자 | 방송하는 사장님. 상품 등록·판정 확인·정산·포장까지 하는 주 사용자. 컴퓨터에 익숙하지 않을 수 있고 방송 중엔 손이 바쁘다. |
| 보조자 | 판매자가 만들어 준 계정으로 휴대폰에서 문자찜만 넣는 사람(가족·직원). |

| 운영자 | 서비스를 운영하는 쪽. 판매자 계정 만들기, 백업·복구, 요금 켜기, 서버 지켜보기. |
