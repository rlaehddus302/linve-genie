## A. 번호·가격 — 틀린 값이 확정되지 않게

| # | 무엇을 | 어떻게 |
|---|---|---|
| A1 | 일꾼을 "확인 중" 등록에 잇기 | 만들어 둔 가지를 합친다. 번호와 금액을 말하면 바로 "확인 중"으로 올리고 근거가 모이면 확정한다. 근거가 모자란 상품도 버리지 않고 올린다 (124·272번) |
| A2 | 금액 고치기 안전장치 | 고친 값이 5배 넘게 다르거나 가격대를 벗어나면 고치지 않고 묻는다. 한 줄에 다른 번호가 같이 있으면 그 줄의 금액은 쓰지 않는다 (189번 500만 → 5,500원) |
| A3 | 번호 바로잡기 | 등록 응답을 받은 뒤에 보낸다. 번호와 가격을 여러 번 말한 상품은 옮기지 않는다 (620·107번, 6 → 17번) |
| A4 | 내린 값 받기 | 이미 있는 번호에 다른 값을 한 번이라도 또렷이 말하면 "6만 → 5만" 카드를 올린다 (83·262·299번) |
| A5 | 헷갈리는 금액 묻기 | 같은 상품에 2와 20처럼 열 배 다른 값이 같이 들리면 확정하지 않고 묻는다 (241번) |
| A6 | 거둔 상품 | "번호 떼", "이거 빼"가 들리면 "거둘까요?" 카드를 올린다 (153번) |

## B. 품종 — 전국 사전 대신 가게 장부

| # | 무엇을 | 어떻게 |
|---|---|---|
| B1 | 사전 거름 걷기 | LLM이 적은 이름을 기본으로 쓴다. 닉네임·인사말·재고·제곱 같은 확실히 품종이 아닌 말만 거른다 |
| B2 | 가게 장부 만들기 | 가게마다 품종 목록을 둔다. 영수증·손 수정·확정에서 자동으로 쌓는다. 먼저 11-12 정산서와 11-13 영수증으로 채운다 |
| B3 | 장부에 맞추기 | LLM 이름을 장부에서 소리가 가장 가까운 이름으로 바꾼다(자모 편집 거리). 11-13 기록으로 49% → 78.7% |
| B4 | 확인 중 품종 | 장부에 없는 이름은 버리지 않고 "확인 중"으로 올린다. 감사 채팅과 라벨에는 확정된 이름만 쓴다 |
| B5 | 이름 나눠 적기 | 품종 / 무늬(색금·녹금·수박·힘줄) / 형태(군생·통째·종자) / 개수로 나눈다. "○○색금"을 "색금"으로 줄이지 않는다 |
| B6 | 가게 말버릇 | "이름 없는 색금은 SP", "종자 = 종자용 SP"를 가게 설정으로 둔다 |
