# 맥 미니에 받아쓰기 일꾼 설치하기

방송 중 사장님 목소리를 글로 바꾸는 "받아쓰기 일꾼"을 맥 미니에 설치하고, 늘 켜 두는 방법이에요.
명령은 **터미널**(응용 프로그램 > 유틸리티 > 터미널)에 한 줄씩 붙여 넣고 Enter를 누르면 돼요.

일꾼은 맥 미니에서 라이브지니 서버로 **먼저 연결**해요. 그래서 공유기 설정이나 포트 열기, 공개 주소가 필요 없어요.

## 준비물

- 애플 실리콘(M1·M2·M3·M4) 맥 미니, 전원에 꽂아 두기, 인터넷 연결
- 빈 저장 공간 약 15GB (프로그램 약 3GB + 받아쓰기 모델 수 GB)
- **파이썬 3.12** — 아래 셋 중 하나가 있으면 돼요. 없으면 설치 명령이 무엇을 하면 되는지 알려 줘요.
  - `uv` (있으면 가장 편해요)
  - python.org에서 받은 Python 3.12 (macOS 64-bit universal2 installer)
  - 홈브루의 `python@3.12`
- **라이브지니 서버 주소** (예: `https://livejjim.example.com`)
- **일꾼 토큰** — 라이브지니 서버의 `LIVEJJIM_TRANSCRIBE_WORKER_TOKEN` 값. 서버를 관리하는 사람에게 받으세요. 남에게 보여 주지 마세요.
- (기본 모델 Cohere를 쓸 때) **허깅페이스 계정**
  1. https://huggingface.co/CohereLabs/cohere-transcribe-03-2026 에 로그인해 동의 단추를 눌러 승인받기
  2. https://huggingface.co/settings/tokens 에서 "Read" 토큰 하나 만들기
  - 이 토큰은 모델을 내려받을 때 한 번만 쓰고 저장하지 않아요. 다 받은 뒤 허깅페이스에서 지워도 돼요.
  - 허깅페이스 계정이 없으면 설정에서 모델을 "위스퍼 turbo"로 고르면 계정 없이 받아요.

## 설치 순서

1. 라이브찜 폴더를 맥 미니에 받기 (둘 중 하나)
   - git을 쓰면: `git clone git@github.com:unhoyeo/livegenie.git ~/livejjim`
   - 아니면 개발자에게 받은 압축 파일을 풀어 홈 폴더에 `livejjim`으로 두기
2. 설치하기:
   ```
   bash ~/livejjim/packages/voice/transcriber/macmini/install.sh
   ```
   차례대로 물어봐요.
   - 서버 주소 → 붙여 넣고 Enter
   - 모델 → 그냥 Enter(Cohere) 또는 2(위스퍼)
   - 일꾼 토큰 → 붙여 넣고 Enter. **화면에 아무것도 안 보이는 게 정상**이에요.
   - (Cohere) 허깅페이스 읽기 토큰 → 붙여 넣고 Enter. 역시 화면에 안 보여요.
   - "지금 일꾼을 켤까요?" → Enter
3. 끝. 처음 켤 때는 모델을 불러오느라 1~3분 걸려요.

설치되는 곳: `~/Library/Application Support/LiveJjim/transcriber` (설정·토큰은 나만 읽을 수 있는 파일로 저장돼요)

아래 명령에서 `일꾼폴더`는 `~/Library/Application\ Support/LiveJjim/transcriber/app/macmini`예요. 쓰기 편하게 한 번 적어 두세요:
```
W=~/Library/Application\ Support/LiveJjim/transcriber/app/macmini
```
(터미널 창을 새로 열면 이 줄을 다시 넣어야 해요)

## 잘 되는지 확인

```
bash "$W/status.sh"
```

이렇게 보이면 잘 되는 거예요:

- `일꾼 프로그램: 켜져 있어요`
- `서버 연결: 붙어 있어요 (… 부터)`
- `잠자기 막기: 일꾼이 도는 동안 맥이 저절로 잠들지 않아요`
- `받아쓰기 처리 시간: 100번 중 95번은 …ms 안에 끝났어요` — 방송 중 5분마다 새로 적혀요. 1000ms보다 많이 크면 개발자에게 알려 주세요.

라이브지니 운영 상태 화면에서도 받아쓰기 일꾼 수가 1 이상으로 보여야 해요.

## 평소 쓰는 명령

| 하고 싶은 것 | 명령 |
|---|---|
| 상태 보기 | `bash "$W/status.sh"` |
| 끄기 | `bash "$W/stop.sh"` (맥에 다시 로그인하면 다시 켜져요) |
| 켜기 / 다시 켜기 | `bash "$W/start.sh"` |
| 서버 주소·토큰·모델 바꾸기 | `bash "$W/configure.sh"` 다음 `bash "$W/start.sh"` |
| 모델을 바꾼 뒤 내려받기 | `bash "$W/download-model.sh"` |
| 업데이트 | `bash "$W/update.sh"` |

- **늘 켜 두기**: 맥에 로그인하면 저절로 켜지고, 꺼지면 30초 안에 다시 켜져요. 맥 미니가 켜질 때 로그인까지 되도록 "시스템 설정 > 사용자 및 그룹 > 자동 로그인"을 켜 두면 정전 뒤에도 돌아와요(이건 직접 골라 주세요).
- **잠자기**: 일꾼이 도는 동안만 맥이 저절로 잠들지 않게 막아요. 맥의 전원 설정은 바꾸지 않아요. 화면은 꺼져도 괜찮아요.
- **업데이트**: git으로 받은 폴더면 최신 코드를 받아 바꾸고, 압축 파일로 받았다면 새 압축 파일을 푼 폴더 안의 `macmini/update.sh`를 실행하세요. 프로그램 판은 정해진 판 그대로 설치돼요. 새 판 설치가 실패하면 원래 일꾼은 그대로 돌아요.

## 문제가 생겼을 때

| 상태 보기에 나온 말 | 할 일 |
|---|---|
| 서버가 일꾼 토큰을 받지 않아요 | 토큰이 서버 값과 다르다는 뜻이에요. `bash "$W/configure.sh"`로 토큰을 다시 넣고 `bash "$W/start.sh"` |
| 서버에 닿지 않아요 | 인터넷 연결과 서버 주소를 확인하세요. 서버가 다시 살아나면 저절로 붙어요(최대 30초 간격) |
| 서버가 연결을 받지 않아요 | 서버 주소가 맞는지 확인하세요(`https://`로 시작, 끝에 다른 글자 없이) |
| 모델을 불러오는 중이에요 (오래 계속) | 3분이 넘으면 `bash "$W/download-model.sh"`로 모델이 다 받아졌는지 확인 |
| 일꾼이 시작하지 못했어요 | 아래 "마지막 오류 기록"에 할 일이 적혀 있어요 |
| 일꾼 프로그램: 꺼져 있어요 | `bash "$W/start.sh"` |
| 다른 사람도 읽을 수 있어요 | 나온 `chmod 600 …` 명령을 그대로 붙여 넣기 |

- 설치 중 "파이썬 3.12를 찾지 못했어요"가 나오면, 안내대로 파이썬 3.12를 설치한 뒤 `install.sh`를 다시 실행하세요. 다시 실행해도 이미 된 것은 그대로 써요.
- 허깅페이스가 내려받기를 막았다고 나오면, 모델 페이지에서 동의했는지와 읽기 토큰이 맞는지 확인한 뒤 `bash "$W/download-model.sh"`.
- 기록 파일: `~/Library/Logs/livejjim-transcriber.log`. 연결 상태와 숫자(흐름 수·처리 시간)만 있고, 받아쓴 말·목소리·토큰은 남지 않아요. 5MB가 넘으면 저절로 정리돼요. 개발자에게 보낼 때는 이 파일을 보내면 돼요.
- 일꾼이 꺼져 있어도 방송은 계속돼요. 사장님 화면에 "받아쓰기 서버가 꺼져 있어요. 상품은 빠른 입력으로 넣어 주세요."가 보여요.

## 지우기

```
bash "$W/uninstall.sh"
```

자동 켜기를 끄고, 설치 폴더(프로그램·설정·토큰)와 기록을 지워요. 받은 모델(수 GB)은 지울지 한 번 더 물어봐요.
처음 받은 라이브찜 폴더(`~/livejjim`)는 그대로 있으니 필요 없으면 휴지통에 넣으세요.
